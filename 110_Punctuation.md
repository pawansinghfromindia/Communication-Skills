# Punctuation Marks 

> **Punctuation marks** are special symbols(signs) used in writing **to make the meaning clear and easy to understand**.

Punctuation marks tell the readers **`where to stop`, `where to pause`, `where to ask a question`, `where to show emotion`, `which words belong to someone's speech`, and `how different parts of a sentence are connected`**.

<details>
  <summary> <b> Classification of punctuation marks </b> </summary>

<br/>

Punctuation marks can be broadly classified according to their function.

| Category                         | Punctuation marks | Main purpose                       |
| -------------------------------- | ----------------- | ---------------------------------- |
| **1. End punctuation**           | `. ? !`           | End a sentence                     |
| **2. Pause/Separation marks**    | `, ; :`           | Show pauses or separate ideas      |
| **3. Quotation marks**           | `" "` `' '`       | Show spoken or quoted words        |
| **4. Parenthetical marks**       | `( ) [ ]`         | Add extra information              |
| **5. Joining/Connecting marks**  | `- – —`           | Join or connect words/ideas        |
| **6. Possession/Omission marks** | `'`               | Show possession or omitted letters |
| **7. Special marks**             | `... /`           | Show omission, alternatives, etc.  |

<details>
  <summary>  <b> 1. Fullstop/period <code>.</code> </b> </summary>

<br/>

> A **full stop(period)** is used **_at the end of a statement or ordinary sentence_**.

It can be postive/negative sentence.
```
I live in India.
She is a teacher.
The children are playing in the garden.
The train arrived late.
It's not a very sunny day.
I like mangoes.
```

<details>
  <summary>  <b> 2. Question mark <code>?</code> </b> </summary>

<br/>

> A question mark is used **_at the end of a question when we ask questions_**, instead of a fullstop.

```
What is your name?
Where do you live?
Are you ready?
Is he okay?
How many apples are left?
Is there someone knocking at the door?
Can you hear me, children?
Who is that man talking to Dad?
Where are you going? 
```

<details>
  <summary>  <b> 3. Exclamation mark <code>!</code> </b> </summary>

<br/>

> **Exclamation mark** is used **_to express strong feelings or emotions, such as surprise, excitement, happiness, anger, or fear_**.

```
Wow!
What a beautiful flower!
Be careful!
Hurray! We won the match!
What a silly thing to do!
What a shame!
How sad!
Help! A monster!
You're completely wrong!
```

**We can also use exclamation marks with strong orders.**
```
Sit down!	 
Be quiet!	 
Do it now!
Don't touch that knife!
Give me that ball!
Leave me alone!
```

**Exclamation marks are usually used after interjections** <br/>
People often use just one or two words to express a sudden feeling such as fear, happiness, surprise or anger, or in greeting somebody. These short expressions are called **interjections**. 
```
Hello!
Ouch!
Oh dear!
Hurray!
Well done!
Help!
Look out!
Good morning!
Good night!
Happy Birthday!
```

<details>
  <summary>  <b> 4. Comma <code>,</code> </b> </summary>

<br/>

> A **comma** is mostly used for **small pause and separation between items in a list**.

**To show a short pause**
```
After dinner, we went for a walk.
```

**To separate items in a list**
```
I bought apples, bananas, oranges, and grapes.
You need paper, scissors and glue.
She likes reading, swimming, playing basketball and going to the movies.
Ram, Mina, Shreya, Prince and Krish all went shopping together.
```

**To separate someone being addressed** means before or after the name of the person you are speaking to <br/>
```
Rahul, please come here.
Hello, Mr. Jaishankar.
Miss Shreya, can I borrow a pencil, please?
Goodbye, Andrew.
```

**Between certain parts of a sentence**
```
If you study hard, you will succeed.
```

**Use a comma after `yes` and `no`**
```
Do you like football?
- Yes, I like it very much.

Is this your house?
- Yes, it is.

Is it still snowing?
- No, it's stopped.

Has Sarah had breakfast yet?
- No, she hasn't.
```

**Commas are used before `please` and `thank you`**
```
Could you pass me that pencil, please?
I've had enough to eat, thank you.

Would you like some more orange juice, Dhiraj?
- Yes, please.

Would you like another cupcake, Shreya?
- No, thank you.
```

**A comma is also used between the parts of a place name.**
```
Mumbai, Delhi
Tower Bridge, London
the Lincoln Memorial, Washington DC
Sector-15, Chandigarh
```

<details>
  <summary>  <b> 5. Semicolon <code>;</code> </b> </summary>

<br/>

> A **semicolon** **_connects two closely related independent sentences_**.

```
I wanted to play outside; it was raining.
- I wanted to play outside.
- It was raining.

Both parts can stand as sentences.
But semicolon shows that the ideas are closely connected.
```

> **Full stop = stronger separation** <br/>
> **Semicolon = connected ideas**

<details>
  <summary>  <b> 6. Colon <code>:</code> </b> </summary>

<br/>

> A **colon** is commonly used **_before a list, explanation, example, or important information_**.

**Colon = Here comes more information**

```
I need three things: a pen, a notebook, and a ruler.   List
He had one goal: to win the competition.               Explanation
Numbers: 1, 2, 3, 4, 5. 
```

When you are **reading a playscript**, notice the colon **between the name of a character and the words that they speak**.
```
Jack  : What have you got in the bag?
Maggie: My swimming suit.
Jack  : When are you going swimming?
Maggie: This afternoon. Would you like to come?
```

<details>
  <summary>  <b> 7. Apostrophe <code>'</code> </b> </summary>

<br/>

> The **apostrophe** has two major uses: **_Possession, Contractions_**

```
Riya's book
John's bicycle
The dog's tail

do not -> don't
cannot -> can't
I am -> I'm
it is -> it's
You are -> You're

```

Use an apostrophe with s **to show who something belongs to i.e. Possession**
```
This is Mohan's room.
This is my Dad's desk.
Are you Ram's mom?
The teacher collects everyone's books at the end of the class.
```

You also use an apostrophe **to show where one or more letters are missing in a contraction**.
```
I'm (= am) the boy who lives next door.
She's (= is) my best friend.
He's (= has) been to Europe twice.
We're (= are) going to the zoo today
You're (= are) my favorite uncle.
I'd (= had) better go home now.
He'll (= will) lend you his bike.
```

<details>
  <summary>  <b> 8. Quotation marks <code>" "</code> </b> </summary>

<br/>

> **Quotation marks** are used **_to show someone's exact words_**.

**Quotation marks -> exact words/speech**

We put the mark `"` at the beginning of the words, and the mark `"` at the end. <br/>
Use a comma `,` before the last quotation mark, to separate the words from the rest of the sentence.
```
"This bike is mine," said Suraj.
"I would like some apple juice, please," said the little boy.
"Let's play computer games," said Ram.
```

Suppose the exact words that someone says come after the rest of the sentence. <br/>
In this case put a fullstop`.` before the last quotation mark.
```
Ram said, "I am ready."
Dad said, "Come inside and have lunch."
```

Put question marks`?` and exclamation marks`!` in the same place as fullstop`.`, before the last quotation mark
```
"Is this the way to the station?" the man asked.
Ram said, "Can I borrow your pencil?"
"Don't do that!" said Mom.
Rahul said, "What a great movie!"
```

<details>
  <summary>  <b> 12. Dash <code>—</code> </b> </summary>

<br/>

> A **dash** is used to **_creates a stronger break in a sentence or adds emphasis_**.

```
She had only one choice — to continue.
My brother — the youngest in our family — is very funny.
```

**Hyphen vs Dash**

| Hyphen `-`  | Dash `—`                   |
| ----------- | -------------------------- |
| Joins words | Creates a break            |
| well-known  | He had one choice — leave. |

<details>
  <summary>  <b> 13. Ellipsis <code>...</code> </b> </summary>

<br/>

> An **ellipsis** consists of three dots `...`. 

It can show:
- an unfinished thought
- hesitation
- omitted words in a quotation

**`...` -> something is left unfinished or omitted**

```
I was thinking...
Well... I'm not sure.
```

<details>
  <summary> <b> Conclusion : Punctuation cheatsheet </b> </summary>

<br/>

**Summary**

| Sn | Symbol| Definition                                       |
|----|-------|--------------------------------------------------|
| 1. | `.`   | **Full Stop** -> `Ends a statement`              |
| 2. | `?`   | **Question Mark** -> `Ends a question`           |
| 3. | `!`   | **Exclamation Mark** -> `Shows strong emotion`   |
| 4. | `,`   | **Comma** -> `Short pause/separates items`       |
| 5. | `;`   | **Semicolon** -> `Connects related sentences`    |
| 6. | `:`   | **Colon** -> `Introduces a list/explanation`     |
| 7. | `'`   | **Apostrophe** -> `Possession/contraction`       |
| 8. | `" "` | **Quotation Marks** -> `Shows exact speech/words`|
| 9. | `( )` | **Parentheses** -> `Extra information`           |
| 10.| `[ ]` | **Brackets** -> `Added/clarifying information`   |
| 11.| `-`   | **Hyphen** -> `Joins words`                      |
| 12.| `—`   | **Dash** -> `Strong break/emphasis`              |
| 13.| `...` | **Ellipsis** -> `Unfinished/omitted thought`     |
| 14.| `/`   | **Slash** -> `Alternative/separation`            |

> **Group 1 : Sentence Ending Marks**

| Mark | Name             | Use                  |
| ---- | ---------------- | -------------------- |
| `.`  | Full stop        | Statement(Tell)      |
| `?`  | Question mark    | Question(Ask)        |
| `!`  | Exclamation mark | Strong emotion(feel) |

> **Group 2 : Pause & Separation Marks**

| Mark | Name      | Use                        |
| ---- | --------- | -------------------------- |
| `,`  | Comma     | Short pause/separation     |
| `;`  | Semicolon | Connect related sentences  |
| `:`  | Colon     | Introduce list/explanation |

> **Group 3 : Speech & Possession**

| Mark  | Name            | Use                     |
| ----- | --------------- | ----------------------- |
| `'`   | Apostrophe      | Possession/contraction  |
| `" "` | Quotation marks | Direct speech/quotation |

> **Group 4 : Bracketing Marks**

| Mark  | Name        | Use                          |
| ----- | ----------- | ---------------------------- |
| `( )` | Parentheses | Extra information            |
| `[ ]` | Brackets    | Added/clarifying information |


> **Group 5 : Connecting & Special Marks**

| Mark  | Name     | Use                      |
| ----- | -------- | ------------------------ |
| `-`   | Hyphen   | Join words               |
| `—`   | Dash     | Strong break             |
| `...` | Ellipsis | Unfinished/omitted words |
| `/`   | Slash    | Alternatives/separation  |
