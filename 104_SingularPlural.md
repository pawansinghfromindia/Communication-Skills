**Singular and Plural**

## Level 1 - Foundation

<details>
  <summary> 1. What is singular? </summary>

<br/>

> **Singular means one**

Singular means **one person, one place, one thing, one animal, or one idea**.

| Singular noun            |
| ------------------------ |
| **boy**, means one boy   |
| **book**, means one book |
| **city**, means one city |
| **dog**, means one dog   |
| **idea**, means one idea |


Examples:
```
I have a book.
She has a dog.
Rahul is a student.
```


</details>
<!------------------------->


<details>
  <summary> 2. What is plural? </summary>

<br/>

> Plural means **more than one**.

| Singular | Plural |
| -------- | ------ |
| boy      | boys   |
| book     | books  |
| city     | cities |
| dog      | dogs   |
| idea     | ideas  |


Examples:
```
I have two books.
She has three dogs.
They are students.
```

</details>
<!------------------------->


<details>
  <summary> 3. Why is Singular/Plural important? </summary>

<br/>

Singular/plural affect many parts of English grammar like `Noun`, `Pronoun`, and `Verb`

This is extremely important because **subject–verb agreement** depends on singular/plural.

```
        Singular        Plural
       one student  |  two students   
       a student    |  students
       an apple     | apples
   The boy plays.   | The boys play.
```

</details>
<!------------------------->

<details>
  <summary> Conclusion : Foundations </summary>

<br/>

Plural is not simply adding `-s/es`.

It is a system of patterns + exceptions + grammatical behavior.

```
                      NOUN NUMBER
                           │
              ┌────────────┴────────────┐
              │                         │
          SINGULAR                    PLURAL
            (one)                 (more than one)
              │                         │
       ┌──────┴──────┐           ┌──────┴─────────┐
       │             │           │                │
     Regular      Irregular     Regular        Irregular
       │             │            │                │
      book          man          books            men
      box           child        boxes            children
      city          tooth        cities           teeth
      knife         mouse        knives           mice
```


</details>

## Level 2 - Regular Plurals

Basic rules to make Singular to Plural <br/>
**`-s`, `-es`, `y -> -ies`,  `f/fe -> -ves`,  `o -> -es/s`**

<details>
  <summary> <b> Rule 1 : For many words(nouns) </b> </summary>

<br/>

| Singular | Plural   |
| -------- | -------- |
| book     | books    |
| pen      | pens     |
| car      | cars     |
| table    | tables   |
| dog      | dogs     |
| student  | students |
| teacher  | teachers |
| apple    | apples   |

Examples:
```
I bought a book.
I bought three books.

The student is here.
The students are here.
```

</details>
<!------------------------->

<details>
  <summary> <b> Rule 2 : Words(nouns) ending in: <code> s, ss, sh, ch, x, z </code> add <code> -es </code></b> </summary>

<br/>

| Singular | Plural  |
| -------- | ------- |
| bus      | buses   |
| class    | classes |
| dish     | dishes  |
| brush    | brushes |
| watch    | watches |
| box      | boxes   |
| fox      | foxes   |
| quiz     | quizzes |

</details>
<!------------------------->

<details>
  <summary> <b> Rule 3 : Words(nouns) ending with <code> y , consonant + y -> ies, vowel + y -> s </code> </b> </summary>

<br/>

**Case 1: `consonant + y` then replace `y` to `-ies`**

If a consonants comes before y, then replace `y` with `-ies`.

| Singular | Plural    |
| -------- | --------- |
| baby     | babies    |
| city     | cities    |
| country  | countries |
| story    | stories   |
| family   | families  |
| party    | parties   |
| lady     | ladies    |


**Case 2: `vowel + y` then simply add `-s` at the end** 

If a vowel comes before y, simply add s.

| Singular | Plural   |
| -------- | -------- |
| boy      | boys     |
| toy      | toys     |
| key      | keys     |
| day      | days     |
| monkey   | monkeys  |
| journey  | journeys |

</details>
<!------------------------->

<details>
  <summary> <b> Rule 4: Words(nouns) ending in <code> f/fe </code> </b> </summary>

<br/>

> Some common `f/fe` nouns change to `ves`, while many others simply take `s`.

- Not all, some words change: `f/fe` -> `-ves`

| Singular | Plural  |
| -------- | ------- |
| leaf     | leaves  |
| knife    | knives  |
| wife     | wives   |
| life     | lives   |
| wolf     | wolves  |
| shelf    | shelves |
| half     | halves  |
| loaf     | loaves  |

- Some words which ends with `f/fe` simply add `-s` at the end.

| Singular | Plural  |
| -------- | ------- |
| roof     | roofs   |
| chief    | chiefs  |
| belief   | beliefs |
| chef     | chefs   |
| proof    | proofs  |
| cliff    | cliffs  |

</details>
<!------------------------->

<details>
  <summary> <b> Rule 5: Words(nouns) ending in <code> o </code> </b> </summary>

<br/>

- Not all, some words simple add `-es` at the end.

| Singular | Plural   |
| -------- | -------- |
| potato   | potatoes |
| tomato   | tomatoes |
| hero     | heroes   |
| echo     | echoes   |
| mango    | mangoes  |

But some words simply add only `-s` at the end.
| Singular | Plural |
| -------- | ------ |
| photo    | photos |
| piano    | pianos |
| radio    | radios |
| video    | videos |
| zoo      | zoos   |

</details>
<!------------------------->

<!--------Level 2 : Regular Plurals-------------->


## Level 3 - Irregular Plurals

<details>
  <summary> <b> Some words(nouns) don't follow the normal rules </b> </summary>

<br/>

Some words(nouns) don't follow the normal rules. The word changes completely.

| Singular | Plural   |
| -------- | -------- |
| man      | men      |
| woman    | women    |
| child    | children |
| person   | people   |
| mouse    | mice     |
| goose    | geese    |
| tooth    | teeth    |
| foot     | feet     |

```
One man is standing outside.
Two men are standing outside.

She has one child.
They have three children.

I saw a mouse.
I saw two mice.
```

</details>
<!----------------------------->

<details>
  <summary> <b> Singular and plural both look the same </b> </summary>

<br/>

Some words(nouns) have the same form for singular and plural.

| Singular | Plural   |
| -------- | -------- |
| sheep    | sheep    |
| deer     | deer     |
| fish     | fish     |
| aircraft | aircraft |
| species  | species  |
| series   | series   |

Examples:
```
I saw one sheep.
I saw five sheep.

I saw one fish.
I saw two fish.
```

Note : When we talk about different species/types of fish, then in that conditions we use `fishes`.

</details>
<!----------------------------->

<details>
  <summary> <b> Plurals borrowed from other languages (Lattin/Greek) </b> </summary>

<br/>

Some English words(nouns) have plural forms derived from Latin or Greek.

| Singular   | Plural    |
| ---------- | --------- |
| analysis   | analyses  |
| basis      | bases     |
| crisis     | crises    |
| thesis     | theses    |
| phenomenon | phenomena |
| criterion  | criteria  |
| bacterium  | bacteria  |
| medium     | media     |

Examples:
```
This is an interesting analysis.
These are several interesting analyses.

This is an important criterion.
These are important criteria.
```

Note: Don't assume every classical plural is mandatory in every situation rather think it according to context.

</details>
