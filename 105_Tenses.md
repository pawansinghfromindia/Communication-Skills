# Tense


<details>
  <summary> <b> Introduction: Tense </b> </summary>

<br/>

> Tense tells us **the time of an action or situation**.

**Timeline** 
```
PAST                      PRESENT                       FUTURE
  ●--------------------------│----------------------------●
```

```
I eat a mango.        -> Present : happening now / generally true
I ate a mango.        -> Past : happened before now
I will eat a mango.   -> Future : will happen after now
```

**Tense = Time + form of the verb**

There are three tenses:
1. **Present tense**
2. **Past tense**
3. **Future tense**

|                        |                                                                           |
|------------------------|---------------------------------------------------------------------------|
| **Simple**             | What happens? ( General/event )                                           |
| **Continuous**         | What is happening? ( _Action in progress_ )                               |
| **Perfect**            | What has happened? ( _Completed relative to a reference point_ )          |
| **Perfect Continuous** | How long has it been happening? ( _Duration of an ongoing/recent action_ )|

</details>

<details>
  <summary> Tense vs Time </summary>

<br/>

`Time` tells us **when something happens**.

`Tense` is the **grammatical form of the verb**.

Example:
```
I am meeting him tomorrow.
- This refers to the future, but the verb is in Present Continuous.

The train leaves tomorrow.
- This refers to the future, but uses Simple Present.
```

Don't think that "Future meaning = Future tense" or Past meaning = Past Tense only. English doesn't work that simply.

<details>
  <summary> Verb forms + Helping Verb  </summary>

<br/>

Before we learn individual tenses, we need to master two things:
1. **Verb forms** : `v1, v2, v3, v4(ing), v5(s/es)`
2. **Helping verbs** : `do/does/did, be(is/am/are, was/were, be, been, being), has/have/had, will/shall, etc`.

Once these are clear, tense formation becomes much easier.


#### Do/Does/Did

DO Forms(`do/does/did`) is  particularly important for negative sentences, questions, emphasis.
- do/does/did + V1
- do/does/did can also be main verb or helping verb
```
I do my work.             main verb = do, do means perform.
I do not work on Sundays. main verb = work, helping verb = do, helps main main verb
```

##### BE Family

BE family (` be(is/am/are, was/were, be, been, being`) is extremely important for continuous tenses.

- BE family + V4(ing)
- BE family can be a main verb or helping verb
```
I am tired.          main verb = am, itself carries the main meaning. 
She is happy.        main verb = is, itself carries the main meaning.
They are students.   main verb = are, itself carries the main meaning.

I am studying.      main verb = studying, helping verb = am, helps the main verb
She is working.     main verb = working, helping verb = is, helps the main verb
They are playing.   main verb = playing, helping verb = are, helps the main verb
```

##### Has/Have/Had
`has/have/had` is used especially for Perfect structures.
- `has/have/had` + V3
- `Has/have/had` can also be a main verb or helping Verb
```
I have a car.                     main verb = have bcuz possess
She has a pen.                    main verb = have bcuz possess
They had books.                   main verb = have bcuz possess

I have completed my work.         main verb = completed, helping verb = have, helps the main verb
He has finished his work.         main verb = finished, helping verb = has, helps the main verb
They had not read books.          main verb = read, helping verb = had, helps the main verb
```

#### will/shall
`will/shall` is a modal auxiliary verb which is used to talk about the future.
- `will/shall` + V1
```
I will work tomorrow.
She will call you.
They will come later.
```

<details>
  <summary> <b> Types of tenses </b> </summary>

<br/>

There are three tenses, each having four kinds:
|                     |                      |            |         |                    |
|---------------------|----------------------|------------|---------|--------------------|
| 1. **Present tense**| Simple or indefinite | Continuous | Perfect | Perfect Continuous |
| 2. **Past tense**   | Simple or indefinite | Continuous | Perfect | Perfect Continuous |
| 3. **Future tense** | Simple or indefinite | Continuous | Perfect | Perfect Continuous |

**4 forms of each tenses**

> **1. Simple** : Focuses on **_a fact, habit, routine, or completed event_**.
```
I study English.
```

> **2. Continuous** : Focuses on **_an action in progress_**.
```
I am studying English.
```

> **3. Perfect** : Focuses on **_an action that is completed in relation to another time/reference point_**.
```
I have studied English.
```

> **4. Perfect Continuous** : Focuses on **_an action that has been continuing for a period of time_**.
```
I have been studying English for two hours.
```

## Present Tense

<details>
  <summary> <b> 1. Simple Present (Present Indefinite) </b> </summary>

<br/>

> **Simple Present is commonly used for: _`habits, routines, facts, general truths, repeated actions, permanent/general situations, schedules/timetables, opinions, feelings, and states`_**

Examples:
```
I exercise every day.                     Habits
The Earth revolves around the Sun.        Facts
I wake up at 7 AM.                        Routines
He/She works in Delhi.                    Permanent/general situations
The train leaves at 8 AM.                 Timetables/Routines
```

| Sentence Type | Simple Present Structure                           |
|---------------|----------------------------------------------------|
| Affirmative   | `Subject + V1(s/es) + Object`                      |
| Negative      | `Subject + do/does + not + V1 + Object`            |
| Interrogative | `Do/Does + Subject + V1 + Object?`                 |
| Interrogative + Negative | `Do/Does + Subject + not + V1 + Object?`|
| WH Questions  | `WH word + do/does + subject + V1 + Object?`       |

```
Virat plays cricket.
Virat does not play cricket.
Does virat play cricket?
Does virat not play cricket?
Where does virat play cricket?
What do you do?
```

> Note: **`he/she/it/any name` with these subjects, we use `v5(s/es)`**.

> Note: **After `does`, use `v1` not `v5(e/es)`**.

> Note: Short forms of `do not` -> `don't` and `does not` -> `doesn't` 

> Note: WH words: `What, Where, When, Why, Who, Which, How, etc`

 

<details>
  <summary> When do we use Simple Present (Indefinite)? </summary>

<br/>

**Use 1 - Habit**: Something you do repeatedly. <br/>
Common Expression of Habits: every day, every morning, usually, often, sometimes, always, rarely, never
```
I drink tea every morning.
She exercises every day.
He reads before sleeping.
```

**Use 2 - Routine**
```
I wake up at 9 AM.
I have breakfast.
I study Python.
I exercise in the evening.
```

**Use  3 - General Truth** <br/>
They aren't necessarily happening right now. They are generally true. Therefore, Simple Present.
```
Water boils at 100°C.
The Earth revolves around the Sun.
Humans need oxygen.
```

**Use 4 - Permanent/Long-Term Situation**
```
I live in India.
She works for a company.
He speaks English.
```

**Use 5 - Preferences, Likes, Dislikes, Opinions, States**
```
I like coffee.
I love music.
I know the answer.
I understand the problem.
I believe you.
She wants a job.
```

**Use 6 - Timetables and Schedules** <br/>
Simple Present can refer to the future when talking about fixed schedules. <br/>
Although the event is in the future, Simple Present is natural because it's a fixed schedule.
```
The train leaves at 8 PM tomorrow.
The meeting starts at 10 AM tomorrow.
The flight arrives at 6 PM.
```

**Simple Present vs Present Continuous**

```
Simple Present     : I work from home.         This is my normal situation/routine.
Present Continuous : I am working from home.   This is happening now/around now, often temporarily.

Simple Present     : I study English.          generally study English.
Present Continuous : I am studying English.    studying it now/these days
```

**Simple Present with frequency** <br/>
We often use **_frequency adverbs_**. <br/>
Frequency scale :`always -> usually -> often -> sometimes -> rarely -> never`

`Subject + frequency adverb + main verb`
```
I always drink tea.
I usually study in the morning.
I often watch movies.
I sometimes play games.
I rarely eat outside.
I never smoke.
```

**ordinary affirmative BE** <br/>
Simple Present of be(`is/am/are`), the position changes.

`Subject + is/am/are + frequency adverb + state/Object`
```
I am always busy.
She is usually late.
They are often tired.
```

> Note: We don't use `do/does` in ordinary affirmative BE sentences.

> Note: Short forms of `is not` -> `isn't` and `are not` -> `aren't`

**Simple Present isn't always "Happening Now"** <br/>
This is one of the biggest misconceptions.
```
I work in an MNC.
- It doesn't necessarily mean I'm physically working at this exact second.  
- This is my general employment situation.
```

<details>
  <summary> <b> 2. Present Continuous </b> </summary>

<br/>

> **Present Continuous is commonly used for situation/event that is _Happening now, Temporary situation, Changing situation, Future arrangement_**


> Present Continuous is an action or situation that is in progress around the present time. basically **Something is happening/going on.**

```
He is studying English .                   Happening now
I am staying with my friend this week.     Temporary situation
Technology is changing rapidly.            Changing situation
I am meeting my manager tomorrow.          Future arrangement
```

**Present Continuous is used for an action in progress around now.**

| Sentence Type | Present Continuous Structure                            |   
|---------------|---------------------------------------------------------|
| Affirmative   | `Subject + is/am/are + V4(ing) + Object`                |
| Negative      | `Subject + is/am/are + not + V4(ing) + Object`          |
| Interrogative | `is/am/are + Subject + V4(ing) + Object?`               |
| Interrogative + Negative | `is/am/are + Subject + not V4(ing) + Object?`|
| WH Questions  | `WH-word + am/is/are + subject + V4(ing) + Object?`     |

```
I am studying Science.
He is not studying Science.
Are they studying Science?
Is Rohit not studying Science?
```

<details>
  <summary> When do we use Present Continuous? </summary>

<br/>

**Use 1: Something happening right now**
```
What are you doing?
I am studying English.
```

**Use 2: `Now` doesn't always mean this exact second**
```
I am learning Maths.
I am reading a book.
```

**Use 3: Temporary situations**
```
I work in Delhi.        - describe your general/permanent situation.
I am working in Delhi.  - emphasizes that the situation is temporary/current.

She lives with her parents.                - General situation
She is living with her parents this month. - Temporary situation.
```

**Use 4: Present Continuous for changing situations**
```
The weather is getting colder.
Technology is changing rapidly.
Your English is improving.
The company is growing.
Prices are increasing.

- The action isn't necessarily happening in one particular second.
- It is a developing process.
```

**Use 5: Present Continuous for future arrangements** <br/>
We can use Present Continuous for a planned arrangement in the near future.
```
I am meeting my friend tomorrow.
We are going to Delhi next week.
They are visiting us this weekend.

I am meeting Rahul tomorrow.  - It is already arranged
I will meet Rahul tomorrow.   - Not arraged or guranteed
```

<details>
  <summary> <b> 3. Present Perfect </b> </summary>

<br/>

> **Present Perfect is commonly used for An action happened in the past but is connected to now, Experience**

> Present Perfect is used when a past action has a connection with the present.

The action happened before now, but we are interested in its present result, experience, or relevance.


```
I have lost my phone.
- Idea is the current result : I don't have my phone now.
She has completed the project.
- Current result : The project is complete now.

I have visited Delhi.        Experience
```

| Sentence Type | Present Perfect Structure                           |
|---------------|-----------------------------------------------------|
| Affirmative   | `Subject + has/have + V3 + Object`                  |
| Negative      | `Subject + has/have + not + V3 + Object`            |
| Interrogative | `has/have + Subject + V3 + Object?`                 |
| Interrogative + Negative | `has/have + Subject + not + V3 + Object?`|
| WH Questions  | `WH Word + has/have + Subject + V3 + Object?`       |

```
You have finished your work.
You have not finished your work.
Have you finished your work?
Have you not finished your work?
```

**Don't use a finished past time expression with Present Perfect.**
```
I have visited Delhi yesterday.   Incorrect
I visited Delhi yesterday.        Correct, bcuz yesterday is a finished past time
```

<details>
  <summary> When to use Present Perfect?</summary>

<br/>

**Use 1: Life experience** <br/>
Present Perfect is used to talk about experiences.
```
I have visited Mumbai.
She has seen that movie.
They have traveled to Japan.
We have eaten Italian food.

Have you ever visited Mumbai?
- Here, we're asking about your experience at any time up to now.
- We aren't asking exactly when.
```

**`Ever` means, _at any time in your life/up to now_** <br/>
`Have + subject + ever + V3 + Object?`
```
Have you ever visited Delhi?
Have you ever eaten sushi?
Have you ever spoken in front of a large audience?
```

**`Never` means, _not at any time_**
```
I have never visited Japan.
She has never eaten sushi.
He has never worked there.
```
> Note: **Don't use another negative with `never`**.
```
I haven't never visited Delhi. Incorrect
I have never visited Delhi.    Correct
```

**Use 2: Recent action with present result** <br/>
Present Perfect is often used when something has just happened and the result matters now.
```
I have finished my work.     Result: My work is finished now.
She has lost her keys.       Result: She doesn't have her keys now.
They have arrived.           Result: They are here now.
He has broken his phone.     Result: The phone is broken now.
```

**`Just` means, _a very short time ago_** <br/>
`Subject have/has + just + V3 + Object`
```
I have just finished my work.
She has just arrived.
They have just left.
We have just completed the task.
```

**Use 3: `Already`, means _something happened before now or earlier than expected_.** <br/>
`Subject + have/has + already + V3 + Object`
```
I have already finished my work.
She has already eaten.
They have already left.
He has already completed the task.
```

**Use 4: `Yet` is commonly used in questions and negative sentences.** <br/>
`Yet` means _up to now_. `Yet` usually comes at the end. <br/>
```
Negative:
I haven't finished yet.
She hasn't arrived yet.
They haven't started yet.

Question:
Have you finished yet?
Has she arrived yet?
Have they started yet?
```

**`Already` vs `Yet`**
```
I have already finished. - It is finished.
I haven't finished yet.  - It isn't finished up to now.
```

**Present Perfect for unfinished time periods** <br/>
We can use Present Perfect when the time period is _still continuing_.
```
I have studied for three hours today.   - Today isn't finished.
I studied for three hours yesterday.    - Yesterday is finished -> Simple Past.

We have had three meetings this month.  - The month isn't finished.
We had three meetings last month.       - Last month is finished -> Simple Past
```

</details>

|---------------------------|-----------------------------|

| for two hours <br/> for three days <br/> for five years <br/> for a long time <br/> | since Monday  <br/> since 2020  <br/> since morning  <br/> since January  <br/> since 9 AM |
| `I have lived here for five years.` | `I have lived here since 2020.` |

Focus: The action has happened/experience or result up to now.
```

<details>
  <summary> <b> 4. Present Perfect Continuous </b> </summary>

<br/>

> Present Perfect Continuous is used **when an action started in the past and continues until now,
emphasizing duration**.

Present Perfect Continuous describes an action that: <br/>
started in the past and is **still continuing**, or <br/>
continued for some time and has **just stopped/recently stopped**, with a connection to the present.

> Basic idea : **It started before now + continued for some time + has a connection with now**.

| Sentence Type | Present Perfect Continuous Structure                     |
|---------------|----------------------------------------------------------|
| Affirmative   | `Subject + has/have + been + V4(ing) + Object`           |
| Negative      | `Subject + has/have + not + been + V4(ing) + Object`     |
| Interrogative | `has/have + Subject + been + V4(ing) + Object?`          |
| Interrogative + Negative | `has/have + Subject + not + been + V4(ing) + Object?`|
| WH Questions  | `WH Word + have/has + Subject + been + V(ing? + Object?` |

```
I have been studying Maths for two hours.
She has not been working on this project since 2025.
Have they been practicing the piano for a long time?
Have you not been listening to me?
How long have you been learning English?
```

### Since vs For

> **Since = starting point (certain specific day/date/time)**
```
since 10 AM
since Monday
since 2026
since morning
```
> **For = duration or period of time(uncertain period)**
```
for two hours
for three years
for a week
for a long time?
```

```
I have been studying since 8 AM.
I have been studying for two hours.
```

<details>
  <summary> Present Perfect vs Present Perfect Continuous </summary>

<br/>

| Present Perfect              | Present Perfect Continuous                                            |
|------------------------------|-----------------------------------------------------------------------|
| Perfect -> what has happened | Perfect Continuous -> how long/how continuously it has been happening |

```
I have studied English for three years.
- Focus can be on the fact/result/experience.

I have been studying English for three years.
- Focus is more strongly on the ongoing activity and duration.
```

**work, finish**
```
I have worked here for five years.
I have been working here for five years.

Both can be correct depending on what you want to emphasize.
-------------------------------------------------------------

I have finished my work.               Focus: RESULT
I have been working for three hours.   Focus: ACTIVITY + DURATION
```

</details>

  <summary> <b> Stative Verbs: Don't use Present Perfect Continuous with every verb </b> </summary>

<br/>

Just like Present Continuous, some stative verbs usually don't work naturally in continuous forms.

```
I have been knowing him for five years.  Incorrect
I have known him for five years.         Correct

I have been liking this movie.           Incorrect
I have liked this movie.                 Correct

I have been understanding the problem.   Incorrect
I have understood the problem.           Correct
```

**Stative verbs generally prefer non-continuous forms.**

**Stative verbs: `know, believe, understand, like, love, hate, want, need, remember`**

## Past Tense

<details>
  <summary> <b> 1. Simple Past(Past Indefinite) </b> </summary>

<br/>

> Simple Past is used **for an action that finished in the past**.

> We use the **Simple Past** to talk about something that **happened and was completed in the past**.

Timeline
```
PAST                         NOW                       FUTURE
  ●--------------------------│--------------------------●
  worked                     │
  finished                   │
  happened                   │
```

| Sentence Type | Simple Past Structure                          |
|---------------|------------------------------------------------|
| Affirmative   | `Subject + V2 + Object`                        |
| Negative      | `Subject + did + not + V1 + Object`            |
| Interrogative | `Did + Subject + V1 + Object?`                 |
| Interrogative + Negative | `Did + Subject + not + V1 + Object?`|
| WH Questions  | `WH-word + did + subject + V1 + Object?`       |


```
I worked yesterday.
You did not visit to Delhi.
Did he go to home?
Did she not call you?
What did you eat?
```

Common Past time expressions
```
yesterday
yesterday morning
last night
last week
last month
last year
two days ago
three years ago
in 2020
in 2015
when I was a child
when I was in school
```
Example:
```
I worked yesterday.
He joined the company in 2021.
RCB won final last year.
I worked there in 2022.
We visited Delhi last year.
```

> Note: **V2 is used only in affirmative statements**.

> Note: **When we use `did/didn't`, then we use V1**.

<details>
  <summary> <b> Simple Past vs Present Perfect </b> </summary>

<br/>

> **Present Perfect**: We're talking about experience up to the present, without specifying a finished past time.

```
PAST ───────────────●──────── NOW
                    │
             present relevance
```

```
I have been to Delhi.             experience up to the present
I have finished the project.      current result? -> The project is finished now.
```

> **Simple Past**: The time is specific and finished.

```
PAST                         NOW
  ●--------------------------│
  happened
  finished
```

``` 
I went to Delhi last year.          finished with specific time
I finished the project yesterday.   When did it happen? → Yesterday.
```

**If you mention a finished specific past time, Simple Past is normally the right choice.**

| Simple Past                | Present Perfect         |
| -------------------------- | ----------------------- |
| I went to Delhi last year. | I have been to Delhi.   |
| I finished it yesterday.   | I have finished it.     |
| She called me an hour ago. | She has called me.      |
| We visited Mumbai in 2022. | We have visited Mumbai. |


</details>

<details>
  <summary> <b> Simple Past vs Past Continuous </b> </summary>

<br/>

**Simple Past tells us about _a completed past event_**.
```
I worked.
I worked yesterday.
```

**Past Continuous emphasizes that the activity was _in progress at a particular time in the past**.
```
I was working.
I was working at 8 PM yesterday.
```

> The key difference is completed event vs. action in progress in the past.

</details>
<!-------------------------------->

<details>
  <summary> <b> When do we use Simple Past? </b> </summary>

<br/>

**Use 1: Completed past action** <br/>
Something happened and finished.
```
I watched a movie yesterday.
She visited her parents last week.
He completed the project.
```

**Use 2: A sequence of past events** <br/>
This is extremely common when telling stories.
```
I woke up, had breakfast, took a shower, and went to work.

woke up -> had breakfast -> took shower -> went to work
```

**Use 3: Past habits** <br/>
We can use Simple Past for things that happened regularly in the past.
```
When I was a child, I played cricket every evening.
We visited our grandparents every summer.
```

> Note: **`used to` and `would` are often useful for past habits**.

|                           | `used to + base verb`                  | 	`would + base verb`                        |
|---------------------------|----------------------------------------|---------------------------------------------|
| Past actions (habits)	    | `I used to play tennis every weekend.` | `Every weekend, I would play tennis.`       |
| Past states (be, have, know, like, live…) | `I used to live in London.` |	~`I would live in London.`~            |
| Tone	                    | Neutral, factual	                     | Nostalgic, narrative                        |
| Time reference needed?	  | No	                                  | Usually yes (when I was young, every summer…)|

**Use 4: Historical events**
```
India became independent in 1947.
The company started in 1990.
The first computer was developed many years ago.
```

**`ago` means _before now_.**
```
an hour ago    == one hour before now
two days ago   == two days before now
five years ago == five years before now

Examples:
- She called me ten minutes ago.
- I saw him two days ago.
- I started learning English three months ago.
```

<details>
  <summary> <b> 2. Past Continuous </b> </summary>

<br/>

> Past Continuous is used **for an action that was in progress at a particular time in the past**.


| Sentence Type |  Past Continuous Structure                     |
|---------------|------------------------------------------------|
| Affirmative   | `Subject + was/were + V4(ing) + Object`        |
| Negative      | `Subject + was/were + not + V4(ing) + Object`  |
| Interrogative | `Was/Were + Subject + V4(ing) + Object?`       |
| Interrogative + Negative | `Was/Were + Subject + not + V4(ing) + Object?`|
| WH Questions  | `WH word + was/were + Subject + V4(ing) + Object?` |

```
I was studying.
They were playing.
He was studying at 8 PM yesterday.
```

Timeline
```
PAST                                      NOW
 |------------------|----------------------|
                  8 PM
                    ↓
              I was studying
```
We aren't focusing on whether the studying finished. We are focusing on what was happening at that moment.


**Interrupted action** : Long/background action and Short/interruption
```
I was sleeping when he called me.
I was sleeping.   - Long/background
She called me.    - Short/interruption
```

<details>
  <summary> <b> When do we use Past Continuous? </b> </summary>

<br/>

**Use #1 - Action happening at a specific past time** <br/>
At that particular past time, the action was in progress.
```
I was studying at 10 PM.
She was sleeping at midnight.
They were playing cricket at 5 PM.
```

**Use #2 - Action interrupted by another action** <br/>
`Past Continuous + when + Simple Past`
```
I was sleeping when the phone rang.
I was studying when my friend called.
We were watching TV when the electricity went out.
They were playing cricket when it started raining.

Two actions:
Sleeping   -> already in progress
Phone rang -> happened during it
```
```
I was sleeping.                        [Past Continuous]
██████████████████████
             ↑
            the phone rang             [Simple Past]
             ●
```

**Use #3 - Two actions happening at the Same Time** <br/>
We use Past Continuous for two actions that were happening simultaneously.
```
She was cooking while I was cleaning.
They were talking while we were working.
I was reading while he was listening to music.
I was studying while my brother was watching TV.
```
```
I was studying
████████████████
Brother was watching TV
████████████████
```

**Use #4 - Temporary situation in the past** <br/>
Past Continuous can describe something temporary around a particular period
```
I was staying with my friend that week.
She was working from home that month.
They were living in Delhi at that time.

- The situation was temporary or limited to that period.
```

```
I lived in Delhi in 2020.      - This simply states a past situation.
I was living in Delhi in 2020. - This emphasizes the situation as ongoing during that period.
```

**Use #5 - Background description in a story** <br/>
Past Continuous is very useful for storytelling.
```
Background
It was raining. People were walking on the streets. Cars were moving slowly.
```
Then a new event happens:
```
Event:
Suddenly, a car stopped.
```
This creates a natural story structure.


</details>

<details>
  <summary> <b> Simple Past + Past Continuous : <code> when </code> and <code> while </code> </b> </summary>

<br/>

Situation:
```
I was studying.
Then my friend called.

I was studying when my friend called.
was studying -> action already in progress
called       -> event that happened during it
```
Both `when` and `while` are very common with Past Continuous.

**`When` often introduces the shorter event** <br/>
`Subject1 + was/were + V4(ing) + when + Subject2 + V2 + Object`
```
I was sleeping when the phone rang.
She was working when I called.
I was studying when he called.
I was working when the meeting started.
```

**`While` often introduces the ongoing action** <br/>
`While + Subject1 + was/were + V4(ing), Subject2 + V2 + Object`
```
While I was sleeping, the phone rang.
While she was working, I called her.
While I was studying, he called.

Reverse:
My brother called me while I was studying.
```

**Stative Verbs**: `know, understand, believe, want, need, remember, own, prefer, etc`

```

I knew the answer.                 Correct

<details>
  <summary> <b> 3. Past Perfect </b> </summary>

<br/>

> Past Perfect is **used when we have two past actions and want to show which happened first**.


```
PAST                          NOW
  A ---------> B -------------|
  ^            ^
  |            |
happened      happened
first         later
```

| Sentence Type | Past Perfect Structure               |
|---------------|--------------------------------------|
| Affirmative   | `Subject + had + V3 + Object`        |
| Negative      | `Subject + had + not + V3 + Object`  |
| Interrogative | `Had + Subject + V3 + Object?`       |
| Interrogative + Negative | `Had + Subject + not + V3 + Object?`|
| WH Quesions   | `WH word + had + subject + V3 + Object?`  |

```
I had finished my work before he arrived.
The train had left before we reached the station.
I had not finished my work.
Had you finished your work?
Had I not finished my task?
Why had they stopped?
Where had she gone?
```

When there are two past events, Past Perfect helps us clearly identify the one that happened first.
```
- When I arrived at the station, the train had left.

Two events:
The train left.
I arrived.

The train left first.
So:

- The train had left before I arrived.
```


<details>
  <summary> <b> When do we use Past Perfect? </b> </summary>

<br/>

**Use #1 One Past action before another**
```
I had eaten dinner before he arrived.

Two Events:
1. I had eaten dinner.
2. He arrived.

Timeline:
PAST                                      NOW
 |-------------|--------------------------|
       ①                    ②
   had eaten              arrived

Past Perfect = earlier past action
Simple Past = later past action


2. When I reached the office, the meeting had started.
- The meeting had started before I reached the office.
```



</details>
<!------------------------->

<details>
  <summary> Why not just use Simple Past, why Past Perfect? </summary>

<br/>

Que: **Why not just use Simple Past?** <br/>
Ans: We can sometimes use Simple Past when the order is already obvious. <br/>
But Past Perfect makes **_the sequence of events crystal clear_**.
```
When I arrived, the train left.
- This can sound like The train left when or after I arrived.

When I arrived, the train had left.
- This clearly means: The train left before I arrived.
```

> **So Past Perfect is especially useful when we need to establish the earlier past event.**

<br/>

**`before`**
```
I had finished my work before I went home.
She had eaten before she went to school.
They had left before we arrived.
He had completed the project before the deadline.
```

**`after`**
```
After I had finished my work, I went home.
After she had eaten, she went to sleep.
After they had completed the project, they celebrated.
After India had won the match, they celebrated.
```

<details>
  <summary> <b> <code> by the time </code>, <code> already </code> and Past Perfect </b> </summary>

<br/>

#### `by the time`

`by the time` is a very useful expression with Past Perfect. It often naturally creates this relationship:
```
Earlier past              Later past
     ↓                         ↓
had happened              happened
```

```
1. By the time I arrived, the movie had started.
- The movie started before I arrived.

2. By the time we reached the airport, the plane had departed.
3. By the time she called me, I had already gone home.
```

#### `already`

Past Perfect often uses already to emphasize that something had happened before another past event.

`Subject1 + had + already + V3 + when/before + Subject2 + V2`
```
I had already eaten when he called.
She had already left when I arrived.
They had already finished the work before the manager came.
```

<details>
  <summary> <b> Simple Past vs Past Perfect </b> </summary>

<br/>

```
I finished my work.                         [Simple Past]
- It simply tells us that the work was completed in the past.

I had finished my work before he arrived.   [Past Perfect]
- It tells us that the work was completed before another past event.
```

**Think this in numbers**, When you see two past events, number them.
```
When I arrived, she had left.

Ask: Which happened first?
1. She left.
2. I arrived.
Therefore: She had left.
------------------------------

When I reached the station, the train had departed.

Ask: Which happened first?
1. The train departed.
2. I reached the station
Therefore: The train had departed.
```

</details>

<details>
  <summary> <b> Past Perfect does not mean very long ago </b> </summary>

<br/>

Past Perfect does not simply mean : "Something happened a long time ago." <br/>
It means: "Something happened before another past reference point."

```
I had eaten breakfast before I left home.

- Maybe breakfast happened only 20 minutes earlier.
- But it is still Past Perfect because it happened before another past event.
```

</details>

<details>
  <summary> <b> Present Perfect vs Past Perfect </b> </summary>

<br/>

```
I have finished my work.                             [Present Perfect]
- The reference point is now.
- My work is finished now.

I had finished my work before the meeting started.    [Past Perfect]
- The reference point is the past.
- My work was already finished before that past event.
```

```
Present Perfect:
PAST ---------> NOW
          have finished
------------------------------------------------------
Past Perfect:
PAST
  1. had finished --> 2. another past event --> NOW
```

</details>

<details>
  <summary> <b> Past Perfect with <code> when </code>, <code> never </code>, <code> just </code> </b> </summary>

<br/>

**`When + Simple Past, Past Perfect`**
```

When he called, I had already gone.
When we reached the station, the train had departed.
When the teacher entered, the students had started the test.
```
It doesn't require Past Perfect every time we have `when`. We use it when we want to clearly show the earlier event.

**`never`**
```

```

**`just`**
```

- I finished my work shortly before he called.

- She left shortly before I arrived.
```

<details>
  <summary> <b> 4. Past Perfect Continuous </b> </summary>

<br/>

> Past Perfect Continuous is used for **An activity had been continuing for some time before another event or point in the past**.

**`Past -> activity continues -> another past event`**

```
I had been studying for two hours when my friend called.
```
**The idea is _duration/activity before a past point_**.
```
Past                                      Later Past
│                                            │
Started studying ────────────────>           │
        2 hours of studying                  │
                                            Friend called
                                               ↓
                                      "had been studying"
```


| Sentence Type | Past Perfect Continuous Structure                |
|---------------|--------------------------------------------------|
| Affirmative   | `Subject + had + been + V4(ing) + Object`        |
| Negative      | `Subject + had + not + been + V4(ing) + Object`  |
| Interrogative | `Had + Subject + been + V4(ing) + Object?`       |
| Interrogative + Negative | `Had + Subject + not + been + V4(ing) + Object?`|
| WH Questions  | `WH word + had + Subject + been + V4(ing) + Object?` |

```
I had been studying for two hours when my friend called.

Studying <----- 2 hours ------> Friend called
- The focus is on duration before a past event.
```

```
She had been studying for two hours before the exam started.
They had not been working on it for long.
Had you been waiting for me?
Had he not been sleeping well before the test?

He had been working there since 2025.
They had been living abroad for ten years.
```

<details>
  <summary> <b> Why do we use <code> had been </code> ? </b> </summary>

<br/>

We know, Present Perfect requires: `has/have + V3` <br/>
Also Past Perfect requires: `had + V3` <br/>
Now, we need the continuous form: V3 of be is `be -> was/were -> been`
So, Past Perfect Continuous: `had + been + V4(ing)`

```
I had been studying.
- had       -> past perfect
- been      -> V3 of "be"
- studying  -> continuous activity
```

</details>
<!----------------------------->

<details>
  <summary> <b> When to use Past Perfect Continuous </b> </summary>

<br/>

**Use #1 - Duration before another past event**
```
I had been studying for two hours before my friend called.

There are two events:
1. Studying started earlier.
2. Friend called later.

The studying continued for two hours before the call.
-----------------------------------------------------------

She had been working for five hours when her manager called.

```
The focus is on the **activity and its duration.**

**Use #2 — Activity leading up to another past event** <br/>
Sometimes we don't specifically emphasize the exact duration. We emphasize that an earlier activity was happening and led up to another past event.

```
She was tired because she had been working all day.
- Working all day before the point when we onserved that she was tired.

He was exhausted because he had been running.
- The running happened before the point when we observed that he was exhausted.
```
```
Working all day
──────────────────────►
                       ↓
                    She was tired
```

**Use #3 — Recent past activity with evidence/result** <br/>
```
The ground was wet because it had been raining.
His clothes were dirty because he had been working outside.
```

| Ask: **How long?**        | Ask: **From when?**    |
| for two hours <br/> for three days <br/> for five years <br/> for 30 minutes | since 9 AM <br/> since Monday <br/> since 2020 <br/> since morning |   
| `I had been waiting for two hours.` <br/> `They had been working for five years.` | `I had been waiting since 9 AM.` <br/> `She had been working since morning.` |

```

<details>
  <summary> <b> Past Perfect vs Past Perfect Continuous </b> </summary>

> **Past Perfect Continuous** focus is _strongly on the activity and duration_.

```

I had been studying for three hours before the exam.  [Perfect Continuous] activity/duration
```

```

> Past Perfect Continuous: The reference point is **a past event**.
```
Past                    Past event
│                           │
Studying ─────────────────►●
```

```
I have been studying for two hours.                [Present Perfect Continuous]
- have been -> connected to now
I had been studying for two hours when he called.  [Past Perfect Continuous]
- had been -> connected to a past point
```

<details>
  <summary> <b> Master rule for all 4 Past tenses </b> </summary>

<br/>

When you see a past situation, ask yourself:

Question 1: **Is it simply a completed past event?** <br/>
Answer: Simple Past `I worked yesterday.`

Question 2: **Was it happening at a particular past moment?** <br/>
Answer: Past Continuous `I was working at 8 PM.`

Question 3: **Was it completed before another past event?** <br/>
Answer: Past Perfect `I had finished my work before he arrived.`

Question 4: **Was it continuing for some time before another past event?** <br/>
Answer: Past Perfect Continuous `I had been working for three hours before he arrived.`

## Future Tense

<details>
  <summary> <b> 1. Simple Future(Future Indefinite) </b> </summary>

<br/>

> Simple Future is used for **Predictions, Decisions made at the moment, Promises, Future events**.

> We use Simple Future to talk about **something that will happen after now**

```
                                                   
Past ───────────────────► NOW ───────────────► FUTURE
                                                 ↓
                                             I will work
```

```
It will rain tomorrow.         - Prediction
I'll help you.                 - Decisions made at the moment
I will call you.               - Promise
I will start work next month.  - Future event
``` 

| Sentence Type | Simple Future Structure                     |
|---------------|---------------------------------------------|
| Affirmative   | `Subject + will/shall + V1 + Object`        |
| Negative      | `Subject + will/shall + not + V1 + Object`  |
| Interrogative | `Will/Shall + Subject + V1 + Object?`       |
| Interrogative + Negative | `Will/Shall + Subject + not + V1 + Object?`|
| WH Questions  | `WH word + will/shall + Subject + V1 + Object?` |


> Note: `shall` is traditionally used with `I/we`, especially in formal British English. <br/>
But in modern everyday English, `will` is much more common for all `I/We/You/He/She/It/Any Name/They`

> Note: `will + not` -> `won't`

```
I will not go.
She will not attend the meeting.
They will not come tomorrow.
Will you come tomorrow?
When will you come?
How will you complete the project?
```

**Simple Future** commonly appears with: 
```
tomorrow
tonight
next week
next month
next year
soon
later
in two days
in five years
someday
one day
```
```
I will call you tomorrow.
She will join us next week.
They will arrive soon.
I will finish it in two days.
```

<details>
  <summary> <b> When do we use Simple Future?</b> </summary>

<br/>

**Use #1 - Future decisions** <br/>
We often use Simple Future `will` when we make a **decision at the moment of speaking**.
```
A to B: I'm hungry.
B to A: I will make you something to eat.

A to B: The phone is ringing
B to A: I will answer it.
```
**You didn't necessarily plan it earlier. You decided now.**


**Use #2 - Promises** <br/>
We use `will` for promises.
```
I will help you.                   Promise -> will
I will call you later.             Promise -> will
I will never forget this.          Promise -> will
I will finish the work tomorrow.   Promise -> will
I will be there on time.           Promise -> will
```

**Use #3 - Offers** <br/>
We use `will` when offering to do something.
```
A: I don't understand this question.
B: Don't worry. I'll explain it.

I will help you with your project.
I'll carry the bag.
I'll explain it again.
I'll send you the document.
```

**Use #4 - Predictions** <br/>
We use `will` to make predictions about the future.
```
I think it will rain tomorrow.
I think India will win.
She will get the job.
Technology will change the way we work.
```
Common expression of prediction: `I think..., I believe..., I expect..., probably, maybe, I’m sure...`
```
I think he will come.
She will probably pass the exam.
I'm sure you will succeed.
```

**Use #5 - Future facts** <br/>
Sometimes we talk about something that is expected to happen in the future.
```
The meeting will start at 10 AM.
The results will be announced tomorrow.
The company will launch the product next month.
```


</details>
<!------------------------->

<details>
  <summary> <b> <code> will </code> vs <code> going to </code> </b> </summary>

<br/>

We have more than one way to talk about the future. <br/>
Two very common forms are: `will`, `be going to`

#### `will` - decision made now
```
Are you free tonight?
I will study tonight.
```

#### `going to` - plan already made, Strong present evidence

We use use `going to` when there is already planned.
```
Tonight, I am going to study Maths.
I am going to study tonight.
- The decision is happening now.
```

We also use `going to` when there is present evidence that something is about to happen.
```
Look at those clouds. It is going to rain.
- This is a prediction based on evidence we can see now.

I think it will rain tomorrow.
- This is more of a general prediction/opinion.
```

| Situation               | Common choice | Example                     |
| ----------------------- | ------------- | --------------------------- |
| Decision made now       | **will**      | I'll call him.              |
| Promise                 | **will**      | I'll help you.              |
| Offer                   | **will**      | I'll carry it.              |
| Prediction/opinion      | **will**      | I think he'll win.          |
| Already planned         | **going to**  | I'm going to study tonight. |
| Strong present evidence | **going to**  | It's going to rain.         |

**This as not an absolute rule, `will` and `going to` can overlap.**

</details>
<!------------------------->

<details>
  <summary> <b> Do we need <code> shall </code>? </b> </summary>

<br/>

`shall` is traditionally used with `I/we`, especially in formal British English.
```
I shall go.
We shall discuss this tomorrow.
```
But in modern everyday English, `will` is much more common with all `I/We/You/He/SHE/It/Any-name/They`.
```
I will go.
We will discuss this tomorrow.
They will come.
```

</details>

- Because it is a planned arrangement.

- Simple Present, but it refers to the future
- because it's a timetable/schedule.
```

**Time and tense are related, but they are not exactly the same thing.**

### Shall vs Will

| Context                                 | Use   |
|-----------------------------------------|-------|

| **Suggestions/offers** (I, we)	        | shall |
| **Legal/formal obligation** (any person)| shall |
| **Emphatic/Strong determination** (2nd/3rd person You, He/She/It/Any name)	| shall |

Shall we go to the cinema?                             - suggestion
The tenant shall pay rent on the 1st of every month.   - Formal/legal obligation
No person shall enter without a permit.                - Formal/legal obligation
This too shall pass!                                   - Empathy                                
He shall answer for his actions.                       - Determination
```

</details>

<details>
  <summary> <b> 3. Future Perfect </b> </summary>

<br/>

> Future Perfect is used **for an action that will be completed before a particular future time/event**.

| Sentence Type | Future Perfect Structure                           |
|---------------|----------------------------------------------------|
| Affirmative   | `Subject + will/shall have + V3 + Object`          |
| Negative      | `Subject + will/shall + not + have + V3 + Object`  |
| Interrogative | `Will/Shall + Subject + have + V3 + Object?`       |
| Interrogative + Negative | `Will/Shall + Subject + have + not + V3 + Object?`|

```
I will have completed the project by Friday.
I will have finished by 5 PM.
She will not have left by the time you arrive.
Will you have finished your work by 6 PM?
Will he not have received the letter yet?
```

Common expressions:
```
by tomorrow
by next week
by 2030
by the time
```
```
By the time you arrive, I will have finished dinner.
```

Note: The Future Perfect always pairs with a time reference (by + time, before, when, etc.) because it describes an action that will be completed before a specific future point.
```
I will have graduated by June.
```

</details>

<details>
  <summary> <b> 4. Future Perfect Continuous </b> </summary>

<br/>

> It **emphasizes duration continuing up to a future point**.

```
By next year, I will have been working here for five years.
By 10 PM, she will have been studying for four hours.
```

| Sentence Type | Future Perfect Continuous Structure                |
|---------------|----------------------------------------------------|
| Affirmative   | `Subject + will/shall have been + V4(ing) + Object`          |
| Negative      | `Subject + will/shall not have been + V4(ing) + Object`  |
| Interrogative | `Will/Shall + Subject + have + been + V4(ing) + Object?`       |
| Interrogative + Negative | `Will/Shall + Subject + have + not + V4(ing) + Object?`|

```
They will have been waiting since 6 AM.
I will not have been driving for more than 2 hours.
Will they have been trying to fix it all week?
Will you not have been practicing for months by the exam?
```

Note: Future Perfect Continuous emphasizes the duration of an action that will be ongoing up until a future point. It almost always pairs with for + duration or since + starting point:
```
She will have been teaching for 30 years by 2027.
They will have been living here since 2020 by next year.
```

<details>
  <summary> <b> Rules </b> </summary>

<br/>

#### Rule 1 - After `do/does/did` -> V1
```
He doesn't go.
You do not go.
Did you go?
```

#### Rule 2 - After `has/have/had` -> V3
```
They have gone.
She had eaten.
I will have finished by 5 PM.
```

#### Rule 3 - Continuous -> V4(ing)
```
I am studying.
He was working.
You will be working.
```

#### Rule 4 - Modal verbs -> V1

Modal verbs are auxiliary verbs that modify the main verb to express conditions such as ability, possibility, permission, necessity, and advice.

The core modal verbs include `can, could, may, might, shall, should, will, would, and must`, along with marginal modals like `ought to` and `need`.

|                       |                                                                                       |
|-----------------------|---------------------------------------------------------------------------------------|
| Ability               | `can` (present) and `could` (past or polite request)                                  |
| Permission            | `can` (informal), `could` (polite), and `may` (formal)                                |
| Possibility/Certainty | `may/might` (uncertain), `could` (theoretical), and `must` (strong logical deduction) |
| Obligation/Advice     | `must` (strong necessity/prohibition), `should/ought to` (recommendation), and `have to`  (external rule) |
| Future/Intent         | `will` (prediction/promises) and `would` (hypotheticals/past habits)                  |



```
She can speak three languages.                  Ability: can (present)
I could swim when I was five.                   Ability: could (past)

Can I use your phone?                           Permission: can (informal)
Could I borrow your pen, please?                Permission: could (polite)
May I leave the room?                           Permission: may (formal)

It may rain tomorrow.                           Possibility/Certainty: may (uncertain)
She might be at home.                           Possibility/Certainty: might (less certain)
This plan could work if everyone cooperates.    Possibility/Certainty: could (theoretical
The lights are on; someone must be home.        Possibility/Certainty: must (strong deduction)

You must wear a seatbelt.                       Obligation/Advice: must (strong necessity)
You mustn't talk during the exam.               Obligation/Advice: must not (prohibition)
You should see a doctor.                        Obligation/Advice: should (advice)
We ought to help those in need.                 Obligation/Advice: ought to (moral obligation)

I will send the notes this evening.             Future/Intent/Hypothetical: will (prediction/promise) 
If I were you, I would apologize.               Future/Intent/Hypothetical: would (hypothetical)
Would you like a glass of water?                Future/Intent/Hypothetical: would (polite offer)
She would read to us every night before bed.    Future/Intent/Hypothetical: would (past habit)

Shall I carry that box for you?                 Suggestions/Offers (shall)
Shall we go to the park?                        Suggestions/Offers (shall)
```

#### Rule 5 - Simple Present: he/she/it/any name -> V5(`s/es`) 
```
He/She/It/Ram works.     V5(s/es)
```

<br/>

This is beyond 12 tenses formula:

#### 1. Stative verbs

> **Stative verb is not used in the continuous form normally**.

**Stative verbs**: `know, believe, understand, like, love, hate, want, need, remember, own, prefer`


```
       Incorrect           |      Correct
I am knowing the answer.   | I know the answer.
I am understanding.        | I understand.
I am believing him.        | I belive him.
He is loving the game.     | He love the game.
```

#### 2. Present Perfect vs Simple Past

```
       Incorrect             |      Correct
I have seen him yesterday.   | I saw him yesterday.   bcuz yesterday is a finished past time.

```

#### 3. Present Perfect vs Present Perfect Continuous

Present Perfect : emphasizes the completed result. <br/>
Present Perfect Continuous : emphasizes the activity/duration.
```
I have read the book.           emphasizes the completed result.

I have been reading the book.    emphasizes the activity/duration.

I am living here since 2020. | I have been living here since 2020. bcuz action started in the past and continues
```

#### 4. Past Simple vs Past Continuous
```
I cooked dinner.
I was cooking dinner when he called.
```

#### 5. Past Simple vs Past Perfect

Both communicate different timelines.
```
When I arrived, he left.

When I arrived, he had left.
```

#### 6. Used to / Would
```
I used to play cricket.

When I was young, I would play cricket every evening.
```

#### 7. Future expressions

In English, we use several structures to talk about the future: `will, be going to, present continuous, Simple Present, Future Perfect, Future Continuous`

```
I will call you.
I am going to call you.
I am calling him tomorrow.

```
