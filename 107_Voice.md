# Voice


## Level 1 - Foundation

<details>
  <summary> <b> What is Voice? </b> </summary>

<br/>

> Voice tells us **whether the subject performs an action or receives an action**.


The term `voice` is a term that is used to denote the `form of the verb` **which shows if the subject in a given 
sentence is the doer or receiver of the action**. 

The voice of a verb describes the **relationship between the action and the participants (subject or object) in a 
sentence**.

</details>
<!------------------------------>


<details>
  <summary> <b> Types of voice </b> </summary>

<br/>

In English, the two primary voices are `active voice`, where the subject is the agent and `passive voice`, 
where the subject is the patient.

Examples:
```
Ravi writes a letter.
- Here, Ravi performs the action.
- So, it is Active Voice.

A letter is written by Ravi.
- Here, the letter receives the action.
- So, it is Passive Voice.
```

While most languages focus on these two, some grammatical frameworks also recognize a **`middle voice`,
where the subject is affected by the action or performs it for themselves**.

Examples
```
1. Active Voice:  The cat chased the mouse.
2. Passive Voice: The mouse was chased by the cat.
3. Middle Voice:  The book sells well.
```

| Voice in English Grammar                                                                             |
|------------------------------------------------------------------------------------------------------|
| **Active Voice**: `Subject + Verb + Object`; emphasizes the doer.                                    |
| **Passive Voice**: `Object + "to be" + Past Participle (+ by Agent)`; emphasizes the receiver.       |
| **Middle Voice**: Subject is both agent and patient, or the action reflects on the subject's state.  | 


#### The choice of voice impacts clarity and emphasis: 

`active voice` is generally preferred for directness and clarity, while <br/>
`passive voice` is useful when the actor is unknown, irrelevant, or when emphasizing the result of the action. 


</details>
<!------------------------------>


<details>
  <summary> <b> 1. Active Voice </b> </summary>

<br/>

> The active voice, in a sentence, denotes that the noun/pronoun that acts as the subject in the sentence is the
doer of the action. 

In other words, the **subject performs the action or acts upon the verb**.


> Basic structure: **`Subject + Verb + Object`**

Examples:
```
1. Riya reads a book.
Subject = Riya
Verb    = reads
Object  = a book
Riya(Subject) -> performs the action (reads).
Therefore, Active Voice.

2. The boy kicked the ball.
3. She cooked dinner.
4. Rahul opened the door.
5. The teacher teaches English.
6. They built a house.
- In every sentence, the subject is doing the action.
```

</details>
<!----------------------------->

<details>
  <summary> <b> 2. Passive Voice </b> </summary>

<br/>

The passive voice, on the other hand, represents that the subject is one acted upon by the action/verb in 
the sentence. 

It can also be said that the passive voice indicates that **the subject in the sentence is no longer active
but passive**.

In Passive Voice, the **subject receives the action**

> Basic structure: **`Object + helping verb + V3 + by + Subject`**

Examples:
```
Active:  Ram reads a book.
- Ram -> reads -> a book
Passive: A book is read by Ram.
- A book -> is read -> by Ram

```
**The object of the active sentence becomes the subject of the passive sentence.**

</details>

<details>
  <summary> <b> Subject, Verb, Object </b> </summary>


#### 1. What is a Subject?

> The subject is the person, animal, thing, or idea that the sentence is mainly about.

In an active sentence, it is often the **doer of the action**.

Examples:
```
1. Rahul plays cricket.
- Who plays cricket? ->  Rahul
- So, Rahul = Subject.

2. The dog chased the cat.
- Who chased the cat? -> The dog
- So, the dog = Subject.

3. My sister cooked dinner.
- Who cooked dinner? ->My sister
- So, my sister = Subject.
```

#### 2. What is a Verb?

> A verb expresses an action, event, or state.

Examples: `eat, write, open, kick, build, clean, read, teach, buy, repair, etc`
```
1. Rahul plays cricket.
- What is the action? -> plays
- So, plays = Verb

2. She writes a letter.
- What is the action? -> writes
- So, writes = Verb
```

#### 3. What is an Object?

> **The object is the person or thing that receives or is affected by the action of the verb**.

Example:
```
1. Rahul plays cricket.
- Ask: Rahul plays what?
- Answer: cricket
- So, cricket = Object

2. She writes a letter.
- Ask: She writes what? 
- Answer: a letter
- So, a letter = Object

```

#### 4. Basic `Sub + Verb + Obj` Pattern

> **`Subject + Verb + Object`**

Examples:
```
Ram reads a book.
Subject = Ram
Verb    = reads
Object  = a book
```

**`Who + Verb + What?` Method**

```
The boy kicked the ball.

Step 1: Who?
- Who performed the action?
- The boy -> Subject

Step 2: What action?
- What did he do?
- kicked  -> Verb

Step 3: What?
- He kicked what?
- the ball -> Object

Therefore:
Sub + Verb + Object
The boy + kicked + the ball.
```

```
The teacher teaches English.
- Who?
- The teacher.
- What does the teacher do?
- teaches -> Verb
- teaches what?
- English -> Object
```

#### 5. Object can be a person/place/animal/thing, object can also be a pronoun

| Subject form | Object form |
| ------------ | ----------- |
| I            | me          |
| we           | us          |
| you          | you         |
| he           | him         |
| she          | her         |
| it           | it          |
| name         | name        |
| they         | them        |



#### 6. Direct Object and Indirect Object

> **A direct object receives the action directly.**

```
Ravi opened the door.
- Opened what?
- the door.
- Therefore, the door = Direct Object.
```

> Some verbs can have two objects.**A indirect object receives the action indirectly.**

```
Ravi gave me a book.
----------------------------
There are two objects:
me -> Indirect Object
a book -> Direct Object
----------------------------
Ask: Ravi gave what?
Ans: a book.
That's the direct object.
----------------------------
Ask: Ravi gave the book to whom?
Ans: me.
That's the indirect object.
------------------------------
So, Di-transitive Verbs
```

#### 7. Not every sentence has an object

**`Subject + Verb` not `Subject + Verb + Object`**

```
The baby slept.
The children laughed.
```

```
The baby slept.

- Who slept?
- The baby = Subject
- What is the verb?
- slept = Verb
Slept what?
There is no answer.
Therefore, there is no object.
-------------------------------
The children laughed.

Subject = children
Verb = laughed
Object = none
```

#### 8. **Subject does not always come first.**
```
In the garden, the children played.
Yesterday, Rahul bought a car.
```
```
In the garden, the children played.
- Subject: the children, Not In the garden
- prepositional phrase: In the garden 
```

#### 9. Subject, Object, and Complement

People sometimes confuse **object and complement**.

```
Rahul is a teacher.
```
"Teacher" is not receiving an action. <br/>
It describes/identifies Rahul. <br/>
So a teacher is a subject complement, not an object.

There will be no ordinary passive transformation:
```
A teacher is been by Rahul.  - Incorrect
```

```
He became a doctor.
- doctor is a subject complement, not a direct object.
She is happy.
- "Happy" is an adjective complement.
```

So eventually We need to distinguish:
- Object
- Subject complement
- Adverbial
- Prepositional phrase

#### 10. Object in passive voice 

```
Active: The boy kicked the ball.
Subject = the boy
Verb = kicked
Object = the ball
---------------------------------
Passive: The ball was kicked by the boy.
Subject = The ball
Verb (Passive Verb)    = was kicked
Object (Subject/Agent) = by the boy
```

<details>
  <summary> <b> Transitive vs Intransitive verbs </b> </summary>

#### Transitive Verb

> A transitive verb is a verb that takes a direct object.

Example
```
She reads books.
He opened the door.
They built a house.
I bought a phone.
We helped them.
```

- A transitive verb takes an object.
```
Ram opened the door.
Ask: Ram opened what?
Answer: the door.
Therefore, opened is transitive.
```
A normal passive construction is possible:
```
The door was opened by Ravi.
```

#### Intransitive Verb

> An intransitive verb does not take a direct object.

Example
```
He sleeps.
She laughed.
The baby cried.
They arrived.
The sun rose.
The children played.
```

- An intransitive verb does not take an object.
```
The baby slept.
Ask: The baby slept what?
Answer: There is no object.
Therefore, there is normally no passive voice.
```

It is not necessary that every active sentence can be converted into passive.
> **No object -> normally no passive voice.**


#### A verb can be both Transitive and Intransitive

A verb isn't necessarily permanently transitive or permanently intransitive. <br/>
It can depend on how the verb is used in the sentence.

```
The door opened.            - opened = Transitive verb
Rahul opened the door.      - opened = Intransitive verb

The glass broke.            - broke = Transitive verb
Rahul broke the glass.      - broke = Transitive verb

The bell rang.              - rang = Transitive verb
The teacher rang the bell.  - rang = Transitive verb
```

#### Transitive vs Intransitive

| Transitive                      | Intransitive                        |
| ------------------------------- | ----------------------------------- |
| Takes a direct object           | Does not take a direct object,  No direct object |
| `Subject + Verb + object`       | `Subject + Verb`                    |
| Usually can form normal passive | Normally cannot form normal passive |
| `She opened the door.` <br/> `He broke the glass.` <br/>  `They built a house.`    | `The door opened.` <br/> `The glass broke.` <br/> `They arrived.`|

<details>
  <summary> <b> V1, V2, V3, V4, V5 </b> </summary>

<br/>

English verbs commonly have different forms.

| Form         | Name                           | Example: write |
| ------------ | ------------------------------ | -------------- |
| **V1**       | Base form                      | write          |
| **V2**       | Past form                      | wrote          |
| **V3**       | Past participle                | written        |
| **V4-ing**   | Present participle / -ing form | writing        |
| **V5(s/es)** | Present Base form              | writes         |

####  V1 (Base Form) is commonly used with: `I, we, you, they, plural subjects, modal verbs, infinitives`

```
I write.
You write.
They/We write.     
She can write.     - modal verbs
I want to write.   - infinitives
```

#### V2 (Past Form) is generally used for the simple past tense.

```
I went to school.
She ate an apple.
Rahul wrote a letter.
They saw a movie.
```

#### V3 (Past Participle) 

V3 is especially important for passive voice. It is used with BE in passive
```
A letter is written by Rahul.
The window was broken.
The apple was eaten.
```

V3 is not used only in Passive Voice, It is also used after `has/have/had`
```
I have eaten.
She has written a letter.
They had gone home.
```

Note: **V2 != V3**

#### Forms of `BE`

The verb BE (`is/am/are/was/were/be/been/being`) changes according to tense and subject.

| Form  | Example          |
| ----- | ---------------- |
| am    | I am             |
| is    | He is            |
| are   | They are         |
| was   | He was           |
| were  | They were        |
| be    | will be / can be |
| been  | has been         |
| being | is being         |

#### Regular Verbs vs Irregular Verbs

- Regular verbs usually form V2 and V3 using -ed.
| V1    | V2      | V3      |
| ----- | ------- | ------- |
| work  | worked  | worked  |
| play  | played  | played  |
| clean | cleaned | cleaned |
| open  | opened  | opened  |
| save  | saved   | saved   |
| laugh | laughed | laughed |

- Irregular verbs don't follow the simple -ed pattern.
| V1    | V2    | V3      |
| ----- | ----- | ------- |
| go    | went  | gone    |
| come  | came  | come    |
| eat   | ate   | eaten   |
| write | wrote | written |
| take  | took  | taken   |
| give  | gave  | given   |
| see   | saw   | seen    |
| do    | did   | done    |
| speak | spoke | spoken  |
| break | broke | bronken |
| drive | drove | driven  |


> When we convert Active Voice to Passive Voice, we use **V3**.

| V1(Base) | V2      | V3      |  V4(ing)  | V5(s/es) |
| -------- | ------- | ------- | --------- | -------- |
| write    | wrote   | written | writing   | writes   |
| eat      | ate     | eaten   | eating    | eats     |
| make     | made    | made    | making    | makes    |
| do       | did     | done    | doing     | does     |
| take     | took    | taken   | taking    | takes    |
| see      | saw     | seen    | seeing    | sees     |
| build    | built   | built   | building  | builds   |
| clean    | cleaned | cleaned | cleaning  | cleanes  |
| play     | played  | played  | playing   | plays    |

<details>
  <summary> <b> Basic conversion </b> </summary>

#### How to change Active into Passive? 

**Active `Subject + Verb + Object`** <br/>
**Passive `Object + Helping Verb + V3 + by + Subject`**

Example:
```
The cat catches the mouse.
Subject = The cat
Verb = catches
Object = the mouse

The mouse is caught by the cat.
```

`Ravi writes a letter.`

> **Step 1 - Find the Subject**

Subject = Ravi

> **Step 2 - Find the Object**

Object = a letter

> **Step 3 - Bring the Object to the beginning**

New Subject (was object)  = A letter ...

> **Step 4 - Choose the correct helping verb**

 Add helping verb = A letter is ...

> **Step 5 - Change the main verb to V3 and add `by`**

Add main verb (v3) + `by` + Object (was subject) = A letter is written by Ravi.

`A letter is written by Ravi.`

<details>
  <summary> <b> Why and when passive voice is preferred? </b> </summary>

<br/>

Passive voice isn't simply a "conversion exercise." It has a purpose.

We often use passive when:
1. **If the action is more important than the person**
```
The road was repaired yesterday.
```

2. **If the person is unknown**
```
My phone was stolen.
His car was broken.
```

3. **If the person is obvious**
```
The suspect was arrested.
The theif was caught by police.
```

4. **If we want a formal/scientific style**
```
The samples were tested in the laboratory.
```

</details>

<details>
  <summary> <b> Sometime <code> by </code> is not necessary in passive voice </b> </summary>

<br/>

Sometimes we don't need to mention who performed the action.

Active: `Someone stole my bicycle.` <br/>
Passive: `My bicycle was stolen.` <br/>
Here, We don't know or don't care who stole it.

Active: `People speak English all over the world.` <br/>
Passive: `English is spoken all over the world.` <br/>
We don't need `English is spoken by people all over the world.`


```
Active:  Someone broke the window.
Passive: The window was broken.
We don't need: The window was broken by someone.

Active:  People speak English here.
Passive: English is spoken here.
```
The agent is either unknown, obvious, or unimportant.

<details>
  <summary> <b> Present Simple </b> </summary>

<br/>

Active: **`Subject + V(s/es) + Object`** <br/>
Passive: **`Object + am/is/are + V3 + (by + Subject)`**

Affirmative: `Object + am/is/are + V3 + by + Subject`
```
Active:  Ravi writes a letter.
Passive: A letter is written by Ravi.

Active:  She cleans the room.
Passive: The room is cleaned by her.

Active:  They play cricket.
Passive: Cricket is played by them.

Active:  The teacher teaches English.
Passive: English is taught by the teacher.
-----------------------------------------
Active:   People grow rice in India.
Passive1: Rice is grown in India.
Passive2: Rice is grown by people in India.
We don't need Passive2 bcuz focus is on rice, not the people.
```

Here, Tense is represented by `is/am/are`.

Negative: `Object + am/is/are + not + V3 + by + Subject`
```
Active:  Ravi does not write a letter.
Passive: A letter is not written by Ravi.

Active:  They do not clean the room.
Passive: The room is not cleaned by them.

Active:  She does not teach English.
Passive: English is not taught by her.

Active:  He does not read newspapers.
Passive: Newspapers are not read by him.
```

Interrogatove: `am/is/are + Object + V3 + by + Subject?`
```
Active:  Does Ravi write a letter?
Passive: Is a letter written by Ravi?

Active:  Does she clean the room?
Passive: Is the room cleaned by her?

Active:  Do they play cricket?
Passive: Is cricket played by them?
```

WH-Questions: `What, Who, Which, When, Why, How, Where` <br/>
`WH + am/is/are + Object + V3 + by + Subject?`
```
Active:  Why does Ravi write letters?
Passive: Why are letters written by Ravi?

Active:  When do they build the bridge?
Passive: When is the bridge built by them?

Active:  How did she solve the problem?
Passive: How was the problem solved by her?

Active:  Who teaches English?
Passive: By whom is English taught?
```

<details>
  <summary> <b> Imperative </b> </summary>

<br/>

> **An imperative sentence tells someone to do something or not do something.**

An imperative sentence expresses **command, order, request, advice, instruction, warning**.

Imperative sentence is a special type of sentence because an imperative usually does not explicitly mention its subject. Example: `Open the door.`,`You open the door.`

Examples:
```               
Close the window.
Read the book.
Follow the rules.
Please help me.
Do not waste water.
Do not touch the machine.
```
Note: These don't follow the normal `Subject + verb + object` pattern because the subject "you" is usually understood.

<details>
  <summary> Step by step conversion </summary>

<br/>

**Step 1: Find the object** <br/>
**Step 2: Move the object** <br/>
**Step 3: Use the imperative passive structure** <br/>

Example:
```
Active:  Close the window.
- Verb = close
- Object = the window
Passive: Let the window be closed.
```
  
</details>

Active for imperative: **`V1 + Object`** <br/>
Passive for imperative: **`Let + object + be + V3`**

> **The word `let` helps create the passive imperative structure.**

Examples:
```
Active:  (You) Open the door.
Passive: Let the door be opened.

Active:  Clean the room.
Passice: Let the room be cleaned.

Active:  Write the answer.
Passive: Let the answer be written.

Active:  Close the window.
Passive: Let the window be closed.

Active:  Please help me.
Passive: Let me be helped
Passive: You are requested to help me.
```

**Negative Imperative** passive structure **`Let + object + not be + V3`**
```
Active:  Do not open the door.
Passive: Let the door not be opened.
Passive: The door should not be opened.

Active:  Do not close the window.
Passive: Let the window not be closed.
Passive: The window should not be closed.

Active:  Do not play the video game.
Passive: Let the video game not be played.
Passive: The videos game should not be played.

Active:  Do not waste water.
Passive: Let water not be wasted.
Passive: Water should not be wasted.

Active:  Do not touch the machine.
Passive: Let the machine not be touched.
Passive: The machine should not be touched.
```

**Imperative with "Please"**
```
Active:  Please help the old man.
Passive: Let the old man be helped, please.
Passive: Please, Let the old man be helped.

Active:  Please open the door.
Passive: Let the door be opened, please.
```
According to tradional grammar rule above passive is okay but in natural English, Passive Imperative can sound
formal or unnatural depending on the context.


**Imperative: Commands vs Requests, Advice vs Intructions**
```
Active:  Please help me.
Passive: Let me be helped.

Active:  Follow the instructions carefully.
Passive: Let the instructions be followed carefully.

Active:  Read the question carefully.
Passive: Let the question be read carefully.
```

**Imperative with `Let`** <br/>
Be careful because let can already appear in the active sentence.

```
Let him open the door.
```
This does not follow the simple `Let + object + be + V3` pattern in the same way. <br/>
Here **`let`** means **allow/permit**.

Passive:
```
Let the door be opened.
```

> **Remember that the subject of an imperative is normally understood as `you`.** That's why we usually don't use **`by you`**

```
Active:  Open the door.
Passive: Let the door be opened.
Passive: Let the door be opened by you.  [Not required]
```

| Type                 | Active                     | Passive                          |
| -------------------- | -------------------------- | -------------------------------- |
| Positive command     | `Open the door.`           | `Let the door be opened.`        |
| Positive command     | `Clean the room.`          | `Let the room be cleaned.`       |
| Instruction          | `Follow the rules.`        | `Let the rules be followed.`     |
| Negative command     | `Do not open the door.`    | `Let the door not be opened.`    |
| Negative instruction | `Do not touch the machine.`| `Let the machine not be touched.`|


We should understand that passive imperative constructions with `let` are common in traditional grammar exercises, but they are not always the most natural way to express instructions in modern English.
```
Active:  Please close the door.
Passive: Let the door be closed.
Passive: The door should be closed.

```

  <summary> <b> Negative sentences </b> </summary>

<br/>

> A negative sentence says that **an action does not, did not, has not, will not, etc. happen**.

**When changing Active -> Passive, keep the negative meaning.**

**Present/Past/Future Simple**

Active: **`Sub + do/does/did +  V1 + Obj`** <br/>
Passive: **`Obj + is/am/are/was/were + not +  V3 + by + Sub`**
```
Active:  Ravi does not write the letter.
Passive: The letter is not written by Ravi.

Active:  Ravi did not write the letter.
Passive: The letter was not written by Ravi.

```

**Future Simple**

Active: **`Sub + will not + be + V1 + Obj`** <br/>
Passive: **`Obj + will + not + be V3 + by + Sub`**
```
Active:  She will not complete the project.
Passive: he project will not be completed by her.
```

The word remains in the passive sentence. But its position changes because the helping verb changes.

Note: **NOT comes after the helping verb and before the V3.**
```
is not written
was not written
has not been written
will not be written
cannot be written
```

**Present/Past/Future Continuous**

Active: **``Sub + am/is/are/was/were/will + not + being + V3 + Obj``** <br/>
Passive: **`Obj + am/is/are/was/were/will + not + being + V3 + by + Sub`**
```
Active:  Ravi is not writing the letter.
Passive: The letter is not being written by Ravi.

Active:  Ravi was not writing the letter.
Passive: The letter was not being written by Ravi.

```

**Present/Past Perfect**

Passive: **`Obj + has/have/had + not + been + V3 + by + Sub`**
```
Active:  Ravi has not written the letter.
Passive: The letter has not been written by Ravi.

Active:  They had not repaired the road.
Passive: The road had not been repaired by them.
```

**Future Perfect**

Passive: **`Obj + will not have been + V3 + by + Sub`**
```
Active:  Ravi will not have written the letter.
Passive: The letter will not have been written by Ravi.

Active:  They will not have completed the project.
Passive: The project will not have been completed by them.
````

**Modal Verbs**

Active: **`Sub + modal + not + V1 + Obj`** <br/>
Passive: **`Obj + modal + not + be + V3 + by + Sub`**
```
Active:  Ravi cannot write the letter.
Passive: The letter cannot be written by Ravi.

Active:  You should not break the rules.
Passive: The rules should not be broken by you.

Active:  They must not enter the room.
Passive: The room must not be entered by them.

Active:  She may not complete the work.
Passive: The work may not be completed by her.

Passive: The project could not have been completed by them.

| ------------------ | -------------------------------- |
| Present Simple     | am/is/are + **not + V3**         |
| Past Simple        | was/were + **not + V3**          |
| Future Simple      | will + **not + be + V3**         |
| Present Continuous | am/is/are + **not + being + V3** |
| Past Continuous    | was/were + **not + being + V3**  |
| Present Perfect    | has/have + **not + been + V3**   |
| Past Perfect       | had + **not + been + V3**        |
| Future Perfect     | will + **not + have been + V3**  |
| Modal              | modal + **not + be + V3**        |
| Modal Perfect      | modal + **not + have been + V3** |



#### Negative Imperatives

```
Active:    Do not open the door.

Passive 2: The door should not be opened.  [Natural Passive]
```

```
Active:  They did not look after the child.
Passive: The child was not looked after by them.
```

#### Negative Ditransitive Sentences

```
Active:    Ravi did not give me a book.
----------------------------------------
Passive 1: I was not given a book by Ravi.
Passive 2: A book was not given to me by Ravi.
```

#### `Never`

```
Active:  Ravi never writes letters.
Passive: Letters are never written by Ravi.

Active:  They never clean this room.
Passive: This room is never cleaned by them.
```

#### `Nobody` / `No One`

```

Passive: Ravi was not invited by anyone.
```

#### `Nothing`

```

Passive: Nothing was said by anyone.

Active:  Nobody gave me anything.
Passive: I was not given anything by anyone.
```

#### `No One` and `Anyone`

```
Active:  No one helped him.
Passive: He was not helped by anyone.
```
This is generally more natural than trying to keep `no one` directly after `by`.

#### Be Careful With Double Negatives

English generally avoids unnecessary double negatives.

Examples:
```
The letter was not never written. [Incorrect]
- That is not the normal way to express the idea.

The letter was never written. [Correct]
---------------------------------------------------

He was not helped by nobody.     [Incorrect]
- He was not helped by anybody.  [Correct]
- Nobody helped him.             [Correct]
```

<br/>

Some verbs are followed by prepositions.

Examples: `look at, laugh at, speak to, talk about, look after, listen to, rely on, believe in`

The **preposition can remain with the verb in the passive construction.**

Active: **`Subject + Verb + Preposition + Object`** <br/>
Passive: **`Object + be + V3 + Preposition + by + Subject`**
```
Active:  They laughed at him.
Passive: He was laughed at by them.

Active:  Everyone laughed at him.
Passive: He was laughed at by everyone.

Active:  They looked after the child.
Passive: The child was looked after by them.

Active:  We should listen to the teacher.
Passive: The teacher should be listened to by us.

Active:  They talked about the problem.
Passive: The problem was talked about by them.

Active:  We depend on our parents.
Passive: Our parents are depended on by us.
```

The confusing part is that the object may come after a preposition, but it can still become the subject of a passive sentence.

`Verb + Preposition` -> keep the preposition in the passive construction. <br/>
This is sometimes called a **prepositional passive**.

> **A sentence can have a grammatically possible passive form that is less natural than the active form.**

Passive 2: I was given a book by Ravi.       [Subject = Indirect Object, me -> I ]

Passive 1: A message was sent to me by her.
Passive 2: I was sent a message by her.

Passive 1:  The picture was shown to me by him.
Passive 2:  I was shown the picture by him.

Active:     She told me a story.
Passive 1:  A story was told to me by her.
Passive 2:  I was told a story by her.

Active:     The company offered him a job.
Passive 1:  A job was offered to him by the company.
Passive 2:  He was offered a job by the company.
```

Ans: When indirect object remains after the direct object in the second passive structure, we generally use `to`

```

Passive 2: I was not given a book by Ravi.
```

Passive 1:  Was a book given to me by Ravi?
Passive 2:  Was I given a book by Ravi?
```

Tenses: Present/Past/Future

Passive 2: I am given a book by Ravi.

<details>
  <summary> <b> "To be" constructions </b> </summary>

<br/>

Forms of to `be` include: `is, am, are, was, were, be, being, been`

`be` can function as a main verb as well as a helping verb. So, It becomes complicated while looking at it for 
making passive.

Examples:
```
She is a teacher.
- Here, is = main/linking verb.
- There is no object receiving an action.
- So, There is no passive transformation here.
```

But `be` can also appear in passive constructions.
```
The door is opened by Ravi.
- Here: is = helping verb
- opened = V3/main verb
```

`is + noun/adjective` -> often linking verb <br/>
`is + V3` -> can form passive


#### 1. What are `To Be` verbs?

The different forms of to be are:

| Form    | Example                    |
| ------- | -------------------------- |
| `am`    | I **am** happy.            |
| `is`    | He **is** a teacher.       |
| `are`   | They **are** ready.        |
| `was`   | She **was** tired.         |
| `were`  | We **were** late.          |
| `be`    | It will **be** completed.  |
| `been`  | It has **been** completed. |
| `being` | It is **being** repaired.  |

> A sentence containing am/is/are/was/were/will be is not necessarily passive.

#### 2. `Be` as a Linking Verb

Sometimes be simply connects the subject to information describing or identifying it.

Example:
```
He is a teacher.
- Break it down:
- He = Subject
- is = Linking verb
- a teacher = Subject complement
- There is no object.
So we cannot convert it into passive voice.

```

**`Be` + Adjective**

Example:
```
They are ready.
- "Ready" describes they.
- It isn't an object receiving an action.
- Therefore, No normal passive conversion.
```

| Active/Original sentence | Passive? |
| ------------------------ | -------- |
| `He is a doctor.`        | No       |
| `She is happy.`          | No       |
| `They are ready.`        | No       |
| `I am tired.`            | No       |
| `We were late.`          | No       |


#### An interesting case where context matters.

```
The door is closed.
```
It can have two interpretations.

1. Meaning 1 - Passive action

Someone closed the door.
```
The door is closed by the security guard.
- Here, closed is V3 and the sentence is passive.
```

2. Meaning 2 — State/condition

The door is simply in a closed state.
```
The door is closed.
- Here, closed can function like an adjective describing the door.
```

```
1. The door is closed.
- The door is closed by the security guard. [Passive Action]
- The door us closed.                       [State/Condition]

2. He is tired.
- He is tired by someone.    [Passive Action]
- He is tired.               [State/Condition]
```

#### Compare Active, Linking, and Passive
 
| Sentence                         | Structure               | Type    |
| -------------------------------- | ----------------------- | ------- |
| `Ravi writes a letter.`          | `S + V + O`             | Active  |
| `The letter is written by Ravi.` | `S + be + V3 + agent`   | Passive |
| `Ravi is a teacher.`             | `S + be + noun`         | Linking |
| `Ravi is happy.`                 | `S + be + adjective`    | Linking |
| `Ravi is in the room.`           | `S + be + place phrase` | Linking |
| `The room is cleaned by Ravi.`   | `S + be + V3 + agent`   | Passive |


#### Difference: BEEN vs BEING

> **`been` -> Perfect**

> **`being` -> Continuous**

Perfect Passive: `Subject + has/have + been + V3`
```
The work has been completed.
```

Continuous Passive: `am/is/are + being + V3`
```
The work is being completed.
```

<details>
  <summary> <b> Some sentences cannot be made passive </b> </summary>

<br/>

An intransitive verb cannot normally be changed into passive voice.

Que: **What Is an Intransitive Verb?** <br/>
Ans: An intransitive verb does not take a direct object.

Example:
```
The baby slept.
Ask: The baby slept what?
Ans: There is no answer.
Therefore, "slept" is intransitive.

The boy ran.
Ask: The boy ran what?
Ans: No direct object.
So, "ran" is intransitive.
```

Que: **Why can't we normally make it passive?** <br/>
Ans: Normal passive voice requires something that can become the new subject.

Example:
```
Active: Ravi opened the door.
Here:
- Ravi -> subject
- opened -> verb
- the door -> object
Passive: The door was opened by Ravi.
The object the door becomes the passive subject.
------------------------------------------------
Active: Ravi slept.
- Ravi -> subject
- slept -> verb
- There is no object.
So there is nothing that can move into the subject position.
Passive: Slept was by Ravi. [We can't]
```

Some commonly used intransitive verbs are: `sleep, arrive, go, come, happen, occur, die, laugh, cry, sneeze, fall, 
sit, stand, run, walk, swim, disappear, rise, appear`

Examples:
```
He arrived.
She slept.
The baby cried.
The accident happened.
The weather changed.
```
These don't normally have direct objects.

Therefore, they don't have ordinary passive forms.

**No object does not mean no other words**

```
He slept on the bed.

Don't think: "Bed" is an object, so passive should be possible. No.
"On the bed" is a prepositional phrase.

- slept -> intransitive verb
- on -> preposition
- the bed -> object of the preposition
"The bed" is not a direct object of slept.
Therefore: The bed was slept by him. But It is not correct.
```

```
They arrived at the station.
- "Station" is not the direct object of "arrived."
- It is the object of the preposition at.
So, The station was arrived at by them. But It is not correct.
```

> **Not every noun after a preposition can become a passive subject.**

**Intransitive Verb + Adverb**
```
The baby cried loudly.
- he baby -> Subject
- cried -> Intransitive verb
- loudly -> Adverb
There is no object.
So, The adverb doesn't become a passive subject.
```

**Intransitive Verb + Prepositional Phrase**
```
The students arrived at school.
- students -> subject
- arrived -> intransitive verb
- at school -> prepositional phrase
"School" isn't the direct object of "arrived."
So ordinary passive isn't formed.
```

<details>
  <summary> Three-way classification </summary>

<br/>

When you see a sentence, classify it into one of these:

### Type 1 - Transitive

Object exists, Therefore Normal passive possible.

```
Active:  Ravi opened the door.
Passive: The door was opened by Ravi.

Active:    Ravi did not give me a book.
Passive 1: A book was not given to me by Ravi.
Passive 2: I was not given a book by Ravi.
```

### Type 2 - Intransitive

No object, Therefore Normal passive not possible.

```
Active:   Ravi slept.
Passive: No passive, bcuz of no object

Active:  He arrived.
Passive: No passive
```

### Type 3 - Verb + Preposition

Object of preposition exists. Therefore, Prepositional passive may be possible.

```
Active:  Ravi laughed at the boy.
Passive: The boy was laughed at by Ravi.
Wrong Passive: He was laughed by Ravi.
```

### Same verb can be transitive as well as intransitive

The same verb can be transitive in one sentence and intransitive in another.

```
The door opened.
- intransitive
- As there is no object, So no passive possible

Ravi opened the door.
- transitive
- Object is there, so passive.
Passive: The door was opened by Ravi.
```

### Don't mistake an object of a preposition for a direct object.

```
Ravi slept on the bed.
- "bed" is the object of on, not the direct object of slept.
```

<details>
  <summary> <b> Modal Perfect </b> </summary>

<br/>

**It is used when a modal expresses something related to a past action.**

**Ordinary Modal: `Subject + modal + be + V3`**
```
The work must be completed.
- Meaning: The work needs to be completed.
```

**Modal Perfect: `Subject + modal + have been + V3`**
```
The work must have been completed.
- Meaning: We believe or conclude that the work was completed in the past.
```


Passive Structure: **`Object + modal + have been + V3 + by + Subject`**

```
Active:  They must have completed the work.
Passive: The work must have been completed by them.

Active:  She may have written the letter.
Passive: The letter may have been written by her.

Active:  Ravi may have completed the work.
Passive: The work may have been completed by Ravi.

Active:  Ram could have solved the problem.
Passive: The problem could have been solved by Ram.

Active:  Rahul should have completed the work.
Passive: The work should have been completed by Rahul.

Active:  They might have changed the plan.
Passive: The plan might have been changed by them.
```

Negative:
```
Active:  Ravi may not have completed the work.
Passive: The work may not have been completed by Ravi.

Active:  They should not have ignored the warning.
Passive: The warning should not have been ignored by them.
```

Interrogative:
```
Active:  Could Ravi have completed the work?
Passive: Could the work have been completed by Ravi?

Active:  Should they have submitted the report?
Passive: Should the report have been submitted by them?

Active:
Passive:
```

WH-Questions:
```
Active:  Why might Ravi have changed the plan?
Passive: Why might the plan have been changed by Ravi?

Active:  How could they have solved the problem?
Passive: How could the problem have been solved by them?

Active:  Who could have written the letter?
Passive: By whom could the letter have been written?

Active:  Who should have completed the project?
Passive: By whom should the project have been completed?
```

Que: **Why do we need `Have`?** <br/>
Ans: `have` connects the modal to the past perfect meaning.


### Three Important Modal Patterns

**Pattern 1 - Modal Passive `Subject + modal + be + V3`**

Example:

**Pattern 2 - Modal Perfect Active `Subject + modal + have + V3`**

Example:
```

```

**Pattern 3 - Modal Perfect Passive `Subject + modal + have been + V3`**

Example:
```
The work must have been completed by Ravi.

Passive: They avoided being recognized.

#### Passive gerunds after prepositions

When a verb follows a preposition, we often use the `-ing` form.

Prepositions  `of, about, for, by, without, etc`.

| Active idea                                  | Passive form                       |
|----------------------------------------------|------------------------------------|
| He is **afraid of** people judging him.      | He is afraid of being judged.      |
| She is **worried about** people blaming her. | She is worried about being blamed. |
| He **left without** anyone noticing him.     | He left without being noticed.     |
| They **talked about** people excluding them. | They talked about being excluded.  |
| She is **tired of** people interrupting her. | She is tired of being interrupted. |

Note: After a preposition, use a gerund rather than a regular infinitive.

```
Correct:   He is afraid of being judged.
Incorrect: He is afraid of to be judged.
```

#### Passive perfect gerund: `having been + V3`

We use it to emphasize that a passive action happened before another action or situation.

Examples
```
Active idea: He regretted that people had misunderstood him.
Passive:     He regretted having been misunderstood.

Active idea: She was proud that the committee had selected her.
Passive:     She was proud of having been selected by the committee.
```

| Structure          | Description                            | Example                       |
|--------------------|----------------------------------------|-------------------------------|
| `being + V3`       | focuses on an experience or action     | He dislikes being criticized. |
| `having been + V3` | emphasizes an earlier completed action | He denied having been warned. |

Some verbs are commonly followed by gerunds:
```

<details>
  <summary> <b> Difference between <code> by </code> and <code> with </code> in passive Voice </b> </summary>

<br/>

The basic difference is:
> **`by` = Doer** <br/>
> **`with` = Instrument or tool **
```
The letter was written by Ravi.  [by = Doer]
- Ravi is the person who performed the action.

The letter was written with a pen.  [with = Instrument or tool ]
- A pen is the tool used to perform the action.
```

> `By` usually identifies the person or thing that performs the action.

> `With` usually identifies the tool, instrument, or material used.


### What is an Agent?

> An agent is the person or thing that performs the action in a passive sentence.

Examples:
```
Active:  Ravi broke the window.
Passive: The window was broken by Ravi.
Here,
- The window = passive subject
- was broken = passive verb
- by Ravi = agent
```

|    Active sentence             |   Passive sentence                   |
|--------------------------------|--------------------------------------|
| The teacher praised Ravi.      | Ravi was praised by the teacher.     |
| The police arrested the thief. | The thief was arrested by the police.| 
| The chef prepared the meal.    | The meal was prepared by the chef.   |
| The storm damaged the roof.    | The roof was damaged by the storm.   |

In each sentence, `by` introduces the agent.

### What is an Instrument/tool?

> An instrument is a tool or object used to perform an action.

Example:
```
Active:   Ravi cut the paper with scissors.
Passive: The paper was cut with scissors by Ravi.
Here,
- by Ravi = agent
- with scissors = instrument
```

|    Passive sentence                | Instrument |
|------------------------------------|------------|
| The letter was written with a pen. | a pen      |
| The window was broken with a stone.| a stone    |
| The wood was cut with a saw.       | a saw      |
| The door was opened with a key.    | a key      |
| The floor was cleaned with a mop.  | a mop      |

Notice that the instrument is not usually introduced with by in these examples.


### `by` and `with` in the same sentence

`by`: Who wrote the letter? <br/>
`with`: What tool was used?

Example: 
```
The letter was written by Ravi with a pen.
- by Ravi = Agent
- with a pen = instrument

The window was broken by the boy with a stone.
- by the boy = agent
- with a stone = instrument
```
The sentence identifies both the doer and the tool.

### `by` always doesn't mean a person.

The agent can also be a person, thing, force, or event.

Examples:
```
The tree was damaged by the storm.
The village was flooded by the river.
The match was interrupted by rain.
The road was blocked by a fallen tree.
```
`by` identifies the cause or source of the action.

### `with` always doesn't mean a physical tool

`with` can introduce a material or substance used in an action.

Examples:
```
The wall was painted with blue paint.
The dish was decorated with fresh herbs.
The wound was covered with a clean cloth.
The box was filled with sand.
```
the phrase introduced by `with` tells us what material or substance was used.

### Active-to-Passive Conversion with both phrases `by` and `with`

```
Active:  Ravi opened the door with a key.
Passive: The door was opened with a key by Ravi.
Passive: The door was opened by Ravi with a key.
```

### We cam omit `by` + agent

In passive voice, the agent is often omitted when it is unknown, obvious, or unimportant.

Examples:
```
The window was broken.
The window was broken by someone.

The road was repaired yesterday.
The road was repaired with heavy machinery.
```

### Summary

| Question                  | Use        |
|---------------------------|------------|
| Who performed the action? | By         |
| What tool was used?       | With       |
| What material was used?   | Often with |
| What caused an event?     | Often by   |

<details>
  <summary>  What is Get-Passive? </summary>

<br/>

In ordinary passive voice, we use a form of `be + V3`. But we can also use `get + V3` in many situations.

Both describe something happening to the window, but the tone and emphasis can differ.

| Be-passive               | Get-passive              |
|--------------------------|--------------------------|
| `be + V3`                | `get + V3`               |
| `The window was broken.` | `The window got broken.` |
| `He was injured.`        | `He got injured.`        |
| `She was promoted.`      | `She got promoted.`      |
| `They were married.`     | `They got married.`      |

The get-passive is often more conversational and may emphasize a change, event, or experience.

Active: `Subject + Verb + Object` <br/>
Get-passive: `Object + get (correct tense) + V3 + (by + agent)`
```
Active:      Ravi broke the window.
Be-passive:  The window was broken by Ravi.
Get-passive: The window got broken.
```
Notice that we often omit the agent when it is unknown or unimportant.


Examples:
```
Active:      Someone broke the window.
Be-passive:  The window was broken by someone.
Get-passive: The window got broken.
--------------------------------------------------------
Active:      The company promoted Ravi.
Be-passive:  Ravi was promoted by the company. 
Get-passive: Ravi got promoted.
--------------------------------------------------------
Active:      The courier delivered the package.
Be-passive:  The package was delivered by the courier.
Get-passive: The package got delivered.
--------------------------------------------------------
```

Negative and Quetions
```
Active:      Someone did not invite Ravi.
Get-passive: Ravi didn't get invited.

Active:      Did someone invite Ravi?
Get-passive: Did Ravi get invited?

Ravi will not get selected.

Is Ravi getting interviewed?
```

</details>

<details>
  <summary> Get-Passive in different tenses  </summary>

<br/>

The form of get changes according to tense.

| Tense              | Get-passive                | Example                          |
|--------------------|----------------------------|----------------------------------|
| Present Simple     | `get/gets + V3`            | `He gets promoted regularly.`    |
| Past Simple        | `got + V3`                 | `He got promoted yesterday.`     |
| Future Simple      | `will get + V3`            | `He will get promoted soon.`     |
| Present Continuous | `am/is/are getting + V3`   | `He is getting promoted.`        |
| Present Perfect    | `has/have got/gotten + V3` | `The package has got delivered.` |

The be-passive remains the more neutral option in formal writing.

<details>
  <summary> <b> Reporting Verbs and Passive Voice </b> </summary>

<br/>

We will learn how to convert sentences using reporting verbs such as say, believe, think, know, report, expect, and consider into passive voice.

### 1. What are reporting verbs?

> **Reporting verbs are verbs we use to communicate what people say, think, believe, or report.**

Examples:
```
People say that he is honest.
Everyone believes that she is talented.
They think that Ravi is intelligent.
People know that the Earth revolves around the Sun.
They reported that the building was damaged.
```
These sentences report information, but they do not necessarily tell us exactly who originally said it.

### 2. Two ways to make reporting passives

We can convert it into passive voice in two ways.
1. Impersonal passive
2. Personal passive

Example:
```
Active:             People say that he is honest.
Impersonal passive: It is said that he is honest.
Personal passive:   He is said to be honest.
```

**Method 1: Impersonal passive**

> **`It + appropriate form of BE + V3 + that + clause`**

|     Active voice                         |        Passive voice                      |
|------------------------------------------|-------------------------------------------|
| People say that he is honest.            | It is said that he is honest.             |
| People believe that she is innocent.     | It is believed that she is innocent.      |
| They think that Ravi is intelligent.     | It is thought that Ravi is intelligent.   |
| People know that the Earth is round.     | It is known that the Earth is round.      |
| They reported that the road was blocked. | It was reported that the road was blocked.|

**Method 2: Personal passive**

> **`Subject of the that-clause + appropriate form of BE + V3 + to-infinitive`**

| Active voice                             |    Personal passive                 |
|------------------------------------------|-------------------------------------|
| People believe that she is innocent.     | She is believed to be innocent.     |
| They think that Ravi is intelligent.     | Ravi is thought to be intelligent.  |
| People know that he is a doctor.         | He is known to be a doctor.         |
| They expect that the team will win.      | The team is expected to win.        |
| People consider that the book is useful. | The book is considered to be useful.|


#### 3. How do we choose the correct infinitive?

The infinitive depends on the time relationship between the reported action and the reporting.

**Case A: Same time or a general fact** <br/>
Use `to + V1` or `to be + adjective/noun`, depending on the sentence.`
```
Active:  People say that he works hard.
Passive: He is said to work hard.

Active:  People believe that she is intelligent.
Passive: She is believed to be intelligent.
```

**Case B: The action happened earlier** <br/>
Use `to have + V3`. This is called the perfect infinitive.
```
Active:             People say that he stole the money.
Impersonal passive: It is said that he stole the money.
Personal passive:   He is said to have stolen the money.
```

Why do we use to have stolen instead of to steal? <br/>
Because the stealing happened before the present-time reporting.

|            Active voice                    |         Personal passive                    |
|--------------------------------------------|---------------------------------------------|
| People believe that he left the country.   | He is believed to have left the country.    |
| They think that she won the competition.   | She is thought to have won the competition. |
| People report that the building collapsed. | The building is reported to have collapsed. |

**Case C: The action is in progress**  <br/>
Use `to be + V-ing`.
```
Active:  People say that he is working abroad.
Passive: He is said to be working abroad.

Active:  They believe that she is preparing for the exam.
Passive: She is believed to be preparing for the exam.
```

| Meaning                        | Infinitive structure    |  Example                 |
|--------------------------------|-------------------------|--------------------------|
| General or simultaneous action | `to + V1`               | He is said to work hard. |
| State or identity              | `to be + noun/adjective`| He is said to be honest. |
| Earlier completed action       | `to have + V3`          | He is said to have left. |
| Action in progress             | `to be + V-ing`         | He is said to be working.|

#### 4. What happens when the reporting verb is in the past?

The passive form of the reporting verb must reflect the tense of the original reporting verb.

```
Active: People say that he is honest.
Passive: It is said that he is honest.

Active:  People said that he was honest.
Passive: It was said that he was honest.

Active:  They believe that he stole the money.
Passive: He is believed to have stolen the money.

Active:  They believed that he had stolen the money.
Passive: He was believed to have stolen the money.
```

#### Summary

1. Impersonal passive: `It + BE + V3 + that-clause`. <br/>
Example: `It is believed that he is innocent.`

2. Personal passive: `Subject + BE + V3 + infinitive`. <br/>
Example: `He is believed to be innocent.`

3. Earlier completed action: `Subject + BE + V3 + to have + V3`. <br/>
Example: `He is believed to have left the country.`

The key is to identify the reporting verb, select the appropriate passive form, and then choose the correct infinitive based on the timing of the reported action.

<details>
  <summary> <b> Passive Voice with Phrasal Verbs </b> </summary>

<br/>

#### 1. What is a phrasal verb?

> A phrasal verb is a combination of a verb and one or more particles (such as an adverb or preposition) that together express a meaning.

Examples:
```
They called off the meeting.
The police looked into the case.
She handed in the assignment.
```

| Phrasal verb  |  Meaning             |
|---------------|----------------------|
| Call off      | Cancel               |
| Carry out     | Perform or conduct   |
| Put off       | Postpone             | 
| Look into     | Investigate          |
| Turn down     | Reject               |
| Bring up      | Mention or raise     |
| Hand in       | Submit               |
| Break into    | Enter by force       |
| Look after    | Take care of         |
| Set up        | Establish or arrange |

#### Rules to convert phrasal verb

**Keep the complete phrasal verb together.**

Active: **`Active: Subject + phrasal verb + object`** <br/>
Passive: **`Passive: Object + appropriate form of BE + V3 + remaining particle(s)`**

Examples
```
Active voice:  The manager called off the meeting.
Passive voice: The meeting was called off by the manager.

Active:  They called off the match.
Passive: The match was called off.

Active:  The team carried out the experiment.
Passive: The experiment was carried out by the team.

Active:  They put off the meeting.
Passive: The meeting was put off.
 
Active:  The police looked into the matter.
Passive: The matter was looked into by the police.

Active:  She turned down the offer.
Passive: The offer was turned down by her.

Active:  He handed in the report.
Passive: The report was handed in by him.

Active:  They brought up an important issue.
Passive: An important issue was brought up by them.

Active:  The company set up a new office.
Passive: A new office was set up by the company.
```

The `by + agent phrase` is often unnecessary when the person doing the action is unknown or unimportant.

#### Phrasal verbs with prepositions

Some common expressions have a verb followed by a preposition, such as:
```
Look after
Look into
Deal with
Speak about
Laugh at
Rely on
```
In passive voice, the preposition usually stays after the verb.

Examples:
```
Active: They look after the children.
Passive: The children are looked after by them.

Active: The police dealt with the complaint.
Passive: The complaint was dealt with by the police.

Active: Everyone laughed at him.
Passive: He was laughed at by everyone.

Active: We can rely on Ravi.
Passive: Ravi can be relied on.
```

Note:  Do not move the preposition to an unrelated position or omit it.

#### Passive voice with modal verbs and phrasal verbs

We already learned that modal verbs use this structure: `Modal + be + V3`

Examples:
```
Active:  They must carry out the plan.
Passive: The plan must be carried out.

Active:  We should look into the complaint.
Passive: The complaint should be looked into.

Active:  They may call off the event.
Passive: The event may be called off.

Active:  You can hand in the form tomorrow.
Passive: The form can be handed in tomorrow.

Active:  They might turn down the proposal.
Passive: The proposal might be turned down.
```

The modal remains unchanged, and the main verb changes to V3.

#### Negative and interrogative sentences

Negative sentences: Place not after the appropriate auxiliary verb.
```
Active:  They did not call off the match.
Passive: The match was not called off.

Active:  They have not looked into the complaint.
Passive: The complaint has not been looked into.
```

Interrogative sentences : Move the auxiliary verb before the new subject.
```
Active:  Did they call off the meeting?
Passive: Was the meeting called off?

Active:  Have they handed in the report?
Passive: Has the report been handed in?

Active:  Should we look into the matter?
Passive: Should the matter be looked into?
```

<details>
  <summary> <b> Passive Voice with two clauses and complex sentences </b> </summary>

<br/>

we will learn how to use passive voice in complex sentences containing words such as because, when, if, although, that, and after.

Changing the voice of the clause that you want to make passive, while preserving the meaning and tense of the whole sentence.

<details>
  <summary> 1. What is a clause? </summary>

<br/>

> A clause is a group of words containing a subject and a verb.

A sentence may contain one clause or multiple clauses.


Example: One clause
```
Active:  Ravi completed the work.
Passive: The work was completed by Ravi.
```

Example 2: Two clauses
```
Active:           The teacher praised Ravi because he completed the work.
Main clause:      The teacher praised Ravi.
Dependent clause: because he completed the work.

We can change one or both clauses into passive voice, depending on what we want to emphasize.
```


</details>

<details>
  <summary> 2. Sentences with <code> because </code> </summary>

<br/>

```
Active: The teacher praised Ravi because he completed the assignment.
- We can change the main clause into passive:
Passive: Ravi was praised by the teacher because he completed the assignment.
- Or we can change the dependent clause into passive
Passive: The teacher praised Ravi because the assignment was completed by him.

Both are grammatically possible, though the first sounds more natural in most contexts. 
```

```
Active:  The police arrested him because he broke the law. 
Passive: He was arrested by the police because he broke the law. 

Active:  She thanked me because I helped her.
Passive: I was thanked by her because I helped her.  

Active:  The manager rewarded Ravi because he achieved the target.
Passive: Ravi was rewarded by the manager because he achieved the target.
```
Notice that **because** remains unchanged.

</details>

<details>
  <summary> 3. Sentences with <code>  when </code> </summary>

<br/>

Example:
```
Active: When the police arrived, the thief opened the door.
We can make the main clause passive
Passive: When the police arrived, the door was opened by the thief.
We can also make the first clause passive if the context permits it.

Active:  When the manager selected Ravi, Ravi received the offer.
Passive: When Ravi was selected by the manager, Ravi received the offer.
```

```
Active:  When the teacher entered the room, the students stopped talking.
Passive: When the room was entered by the teacher, the students stopped talking.

Active:  When the company announced the results, everyone celebrated.
Passive: When the results were announced by the company, everyone celebrated.
```
The first example is grammatically possible, but `When the teacher entered the room` is more natural because enter often sounds better in active voice in this context.

Imp Note: Not every clause needs to be converted into passive voice. Prefer natural English.

</details>

<details>
  <summary> 4. Sentences with <code> if </code> </summary>

<br/>

> The word **if** introduces a condition.

Example:
```
Active:  If the manager approves the request, the company will release the payment.
Passive: If the request is approved by the manager, the company will release the payment.

Active clause: the manager approves the request.
Passive clause: the request is approved by the manager.
```

```
Active:  If the teacher accepts the answer, the student will get marks.
Passive: If the answer is accepted by the teacher, the student will get marks.

Active:  If the police catch the thief, they will arrest him.
Passive: If the thief is caught by the police, he will be arrested.

Active:  If the company selects me, I will join next month.
Passive: If I am selected by the company, I will join next month.
```
The word `if` stays in its original position, and the tense and conditional meaning are preserved.

</details>

<details>
  <summary> 5. Sentences with  <code> although </code> </summary>

<br/>

> **Although** expresses contrast.

```
Active:  Although the manager rejected the proposal, the team continued the project.
Passive: Although the proposal was rejected by the manager, the team continued the project.

Active:  Although the teacher criticized Ravi, she praised his effort.
Passive: Although Ravi was criticized by the teacher, his effort was praised by her.
```
The connecting word although remains unchanged.

</details>

<details>
  <summary> 6. Sentences with <code> that </code> </summary>

<br/>

> Some sentences contain a reporting verb followed by a that-clause.

Examples:
```
Active: People believe that Ravi is honest.

Method 1 - Impersonal passive
Impersonal passive: It is believed that Ravi is honest.

Method 2 - Personal passive
Personal passive: Ravi is believed to be honest.
```

```
Active:  People say that she is talented.
Passive: It is said that she is talented.

Active:  People think that he stole the money.
Passive: He is thought to have stolen the money.

Active:  They report that the building was damaged.
Passive: It is reported that the building was damaged.

Active:  People believe that he has completed the work.
Passive: He is believed to have completed the work.
```
Here, remember that the `that`-clause has its own tense and meaning, so do not change it mechanically.

</details>

<details>
  <summary> 7. Sentences with <code> after </code> and <code> before </code> </summary>

<br/>

> These words after and before show the order of events.

```
Active: After the police arrested the thief, they questioned him.
Passive: After the thief was arrested by the police, he was questioned.

Active: Before the manager approved the request, the employee submitted the documents.
Passive: Before the request was approved by the manager, the documents were submitted by the employee.
```
The connecting words after and before remain unchanged.

</details>

<details>
  <summary> 8. Key Rule: You do not need to change every clause </summary>

<br/>

```
Active: The teacher gave Ravi a book because he answered correctly.
Passive: Ravi was given a book by the teacher because he answered correctly.
- Only the main clause needs to change.

Active:  The company will promote Ravi if he performs well.
Passive: Ravi will be promoted by the company if he performs well.

The conditional clause remains active because it is already clear and natural.
```

**Remember these points**

- Identify the clause containing the object you want to emphasize.

- Change that clause into passive voice.

- Preserve conjunctions such as because, if, when, and although.

- Preserve the original tense and meaning.

- Do not force passive voice when active voice sounds more natural.

</details>

  <summary> <b> Passive Voice with <code> Need </code> , <code> Require </code>, and <code> Want </code> </b> </summary>

The car needs repairing.
The room requires cleaning.
The floor requires to be cleaned.
I want the room to be cleaned.
They want the car to be repaired.
```
All three express a need for an action, but their grammatical structures are different.

#### 1. Structure with `need`

There are two common ways to express this idea.

**Structure 1: `Subject + need(s) + to be + V3`**
```
The car needs to be repaired.
```

**Structure 2: `Subject + need(s) + V-ing`**
```
The car needs repairing.
```
Both sentences mean that the car requires repair.

| Using `to be + V3`                | Using `V-ing`               |
|-----------------------------------|-----------------------------|
| The room needs to be cleaned.     | The room needs cleaning.    |
| The report needs to be completed. | The reports need completing |
| The door needs to be painted.     | The door needs painting.    |
| These clothes need to be washed.  | These clothes need washing. |
| The problem needs to be solved.   | The problem needs solving.  |

In the `V-ing` form has a passive meaning. The room receives the cleaning; it does not clean something itself.

Que: **Why does `needs repairing` have a passive meaning?** <br/>
Ans: Consider these sentences:
```
Ravi needs to repair the car.
The car needs to be repaired.
The car needs repairing.

- The first sentence is active: Ravi performs the repair.
- The second sentence is passive: the car receives the repair.
- The third sentence uses a special construction called the need + gerund construction, which has a passive meaning.
```

| Sentence                      | Structure                     | Meaning                      |
|-------------------------------|-------------------------------|------------------------------|
| Ravi needs to repair the car. | `Subject + need + to + V1`    | Ravi must perform the repair.|
| The car needs to be repaired. | `Subject + need + to be + V3` | The car requires repair.     |
| The car needs repairing.      | `Subject + need + V-ing`      | The car requires repair.     |


#### 2. Structure with `require`

The verb `require` can also be used with a passive infinitive or an `-ing` form.

**`Subject + require(s) + to be + V3`** <br/>
**`Subject + require(s) + V-ing`**

| Passive infinitive                  | V-ing construction             |
|-------------------------------------|--------------------------------|
| The document requires to be signed. | The document requires signing. |
| The floor requires to be cleaned.   | The floor requires cleaning.   |
| The machine requires to be repaired.| The machine requires repairing.|

Note: Although the first pattern is understandable, “require + object + to be + V3” or “require + V-ing” is often more natural in standard English.

Examples: These are natural alternatives.
```
The document requires signing.
The document requires a signature.
The company requires the document to be signed.
The document needs to be signed.
```

### 4. Structure with `want`

The verb `want` behaves differently from `need` and `require`.

For a passive meaning, we generally use: <br/>
**`Subject + want(s) + object + to be + V3`**
Examples:
```
I want the room to be cleaned.
She wants the report to be completed.
They want the car to be repaired.
The manager wants the documents to be submitted.
```

We generally do not use the same `need + V-ing` construction with `want` to express this meaning.
```
Natural Eng:   I want the car to be repaired.
Unnatural Eng: The car wants repairing.
```

In some regional varieties of English, `wants repairing` is used, but for standard formal English, prefer `needs repairing` or `needs to be repaired`.


#### 4. `Need doing` versus `need to do`

```
A. I need to wash the clothes.
Meaning: I must wash the clothes myself, or arrange to do the washing.

B. The clothes need washing.
Meaning: The clothes need someone to wash them.

C. I need the clothes to be washed.
Meaning: I need the clothes to receive the washing, perhaps by someone else.
```

| Active meaning                     | Passive meaning                        |
|------------------------------------|----------------------------------------|
| I need to clean the room.          | The room needs cleaning.               |
| She needs to repair the computer.  | The computer needs repairing.          |
| We need to paint the walls.        | The walls need painting.               |
| He needs to submit the application.| The application needs to be submitted. |

We can notice how the grammatical subject changes depending on what we want to emphasize.

#### 5. Questions and negatives

Remember subject-verb agreement:
```
The car needs repairing.
The cars need repairing.
```

Negative sentences
```
The car does not need to be repaired.
The car does not need repairing.
The room does not require cleaning.
The documents do not need to be signed.
```

Questions
```
Does the car need to be repaired?
Does the car need repairing?
Does the room require cleaning?
Do the documents need to be signed?
```

#### 6. Summary: Final Revision

| Structure                    |  Example                          |
|------------------------------|-----------------------------------|
| `Need + to be + V3`          | The car needs to be repaired.     |
| `Need + V-ing`               | The car needs repairing.          |
| `Require + V-ing`            | The document requires signing.    |
| `Want + object + to be + V3` | I want the document to be signed. |

<details>
  <summary> <b> Passive Voice with <code> Make </code>, <code> See </code>, <code> Hear </code>, and Other Verbs of Perception </b> </summary>

<br/>

We will learn how to convert sentences containing make, see, hear, watch, notice, and observe into passive voice.

These verbs have special rules, especially when they are followed by another verb.

#### 1. Passive voice with `make`

Active formula: **`Subject + make + object + V1`**
```
The teacher made Ravi apologize.
The manager made the employees work late.
The police made the suspect answer questions.
```
Passive formula: **`Object + appropriate form of BE + made + to + V1`**
```
Active:  The teacher made Ravi apologize.
Passive: Ravi was made to apologize by the teacher.

Active:  The manager made the employees work late.
Passive: The employees were made to work late by the manager.
```
Important rule: When make changes to passive voice, we normally add `to` before the following verb.

| Active                           | Passive                                      |
|----------------------------------|----------------------------------------------|
| The teacher made him stand.      | He was made to stand by the teacher.         |
| They made Ravi clean the room.   | Ravi was made to clean the room.             |
| The manager made them work late. | They were made to work late by the manager.  |
| The coach made the players run.  | The players were made to run by the coach.   |

#### 2. Passive voice with `see`


When see is followed by an object and the base form of a verb, the active structure is: <br/>
**`Subject + see + object + V1`**

Example:
```
Active:  I saw Ravi cross the road.
Passive: Ravi was seen to cross the road.
```

| Active voice                       | Passive voice                         |
|------------------------------------|---------------------------------------|
| I saw him enter the room.          | He was seen to enter the room.        |
| They saw the thief climb the wall. | The thief was seen to climb the wall. |
| We saw her leave the building.     | She was seen to leave the building.   |


#### 3. Passive voice with `hear`

The same general rule applies to `hear` when it is followed by an object and the base form of a verb.

Active formula: **`Subject + hear + object + V1`** <br/>
Passive formula: **`Object + appropriate form of BE + heard + to + V1`**

Example:
```
Active:  We heard Ravi sing a song.
Passive: Ravi was heard to sing a song.
```

| Active voice                     | Passive voice                        |
|----------------------------------|--------------------------------------|
| I heard him shout.               | He was heard to shout.               |
| They heard the child cry.        | The child was heard to cry.          |
| We heard her announce the result.| She was heard to announce the result.|


#### 4. Other Verbs of Perception: `watch`, `notice`, `observe`

These verbs follow a similar pattern when the active sentence contains an object followed by the base form of a verb.

| Active voice                        | Passive voice                         |
|-------------------------------------|---------------------------------------|
| I watched him open the door.        | He was watched to open the door.      |
| We noticed him leave the room.      | He was noticed to leave the room.     |
| They observed the bird build a nest.| The bird was observed to build a nest.|

However, some of these passive constructions sound formal or less natural in everyday English. A sentence using 
an `-ing` form may sound more natural when emphasizing an action in progress.
```
Active:  We saw him crossing the road.
Passive: He was seen crossing the road.
```

#### 5. Important difference: `V1` versus `V-ing`

With verbs such as `see`, `hear`, and `watch`, the active sentence can use either the base form or the `-ing` form.

**`Object + V1`** <br/>
This often presents the action as a complete event or as a whole.
```
Active:  I saw him cross the road.
Passive: He was seen to cross the road.
```

**`Object + V-ing`** <br/>
This often emphasizes an action in progress.
```
Active:  I saw him crossing the road.
Passive: He was seen crossing the road.
```

| Active construction | Passive construction    |
|---------------------|-------------------------|
| Saw him cross       | He was seen to cross    |
| Saw him crossing    | He was seen crossing    |
| Heard her sing      | She was heard to sing   |
| Heard her singing   | She was heard singing   |

The difference in meaning can be subtle, and context matters.

#### 6. `help`

The verb `help` is slightly different.

In active voice, we can use either the base form or the infinitive:
```
They helped Ravi complete the task.
They helped Ravi to complete the task.
```
In passive voice, the following infinitive commonly includes `to`:
```
Ravi was helped to complete the task.
Ravi was helped by them to complete the task.
```
The second sentence is grammatically possible, but the first is usually more concise.

#### A special exception: `let`

In active voice, `let` can mean to allow someone to do something.

```
Active:  They let Ravi enter the room.
Passive: Ravi was allowed to enter the room.
```
We generally do not use `Ravi was let to enter the room` in standard English.

| Active voice                | Passive voice                     |
|-----------------------------|-----------------------------------|
| They let him go.            | He was allowed to go.             |
| They let the children play. | The children were allowed to play.|
| They let Ravi enter.        | Ravi was allowed to enter.        |

**`let`** -> **`be allowed to`** is often the natural passive alternative.

#### Summary: Final revision

| Active structure        | Passive structure           |
|-------------------------|-----------------------------|
| `Made + object + V1`    | `Was/were made + to + V1`   |
| `Saw + object + V1`     | `Was/were seen + to + V1`   |
| `Heard + object + V1`   | `Was/were heard + to + V1`  |
| `Saw + object + V-ing`  | `Was/were seen + V-ing`     |
| `Helped + object + V1`  | `Was/were helped + to + V1` |
| `Let + object + V1`     | `Was/were allowed + to + V1`|

<details>
  <summary> <b> Passive Voice with <code> Supposed to </code>, <code> Expected to </code>, and <code> Likely to </code> </b> </summary>

<br/>

- **Supposed to** - what is expected, required, or intended.
- **Expected to** - what people anticipate or predict.
- **Likely to** - what has a reasonable possibility of happening.

These expressions are especially useful in workplace conversations, interviews, news reports, and grammar examinations.

#### 1. Passive voice with `supposed to`

Structure: **`Subject + BE + supposed to + V1`**

We use this structure to express an expectation, duty, rule, or arrangement.
```
You are supposed to follow the rules.
The report is supposed to be submitted today.
The students are supposed to complete the assignment.
The meeting is supposed to be conducted tomorrow.
```

`supposed to` does not automatically mean passive voice.
```
Active infinitive:  You are supposed to follow the rules.
Passive infinitive: The rules are supposed to be followed.
```

| Active construction                       | Passive construction                   |
|-------------------------------------------|----------------------------------------|
| You are supposed to obey the rules.       | The rules are supposed to be obeyed.   |
| They are supposed to finish the work.     | The work is supposed to be finished.   |
| We were supposed to submit the form.      | The form was supposed to be submitted. |
| Someone is supposed to repair the machine.| The machine is supposed to be repaired.|

Key rule: After `supposed to`, use `be + V3` when the infinitive has a passive meaning.

#### 2. Passive voice with `expected to`

We use `expected to` to describe something anticipated or predicted.

Active Structure: **`Subject + BE + expected to + V1`** <br/>
Passive infinitive:: **`Subject + BE + expected to + be + V3`**

Examples:
```
The train is expected to arrive soon.
The team is expected to win.
The results are expected to be announced tomorrow.
The new policy is expected to be implemented next month.
```

| Active infinitive                                  | Passive infinitive                        |
|----------------------------------------------------|-------------------------------------------|
| The company is expected to announce the results.   | The results are expected to be announced. |
| The manager is expected to approve the request.    | The request is expected to be approved.   |
| The government is expected to introduce the policy.| The policy is expected to be introduced.  |
| The teacher is expected to evaluate the papers.    | The papers are expected to be evaluated.  |

Active Infinitive: the subject performs the action, Passive infinitive: the subject receives the action.

#### 3. Passive voice with `likely to`

The expression `likely to` indicates that something has a reasonable chance of happening.

Active infinitive: **`Subject + BE + likely to + V1`** <br/>
Passive infinitive: **`Subject + BE + likely to + be + V3`**

Examples:
```
Ravi is likely to win the competition.
The competition is likely to be won by Ravi.
The company is likely to launch a new product.
A new product is likely to be launched by the company.
The manager is likely to approve the request.
The request is likely to be approved by the manager.
```
The expression `likely to` remains unchanged. We change the infinitive from active to passive by adding `be + V3`.

#### 4. How to identify the correct structure

```
Active sentence: The manager is expected to approve the request.
Step 1: Identify the action - approve.
Step 2: Identify the object - the request.
Step 3: Move the object into the subject position.
Step 4: Change the infinitive to passive - to be approved.
The request is expected to be approved by the manager.
```

#### 5. Negative sentences

To make these sentences negative, we must consider what we want to negate.

**Negating the expectation or obligation**
```
You are not supposed to enter this room.
The report is not expected to arrive today.
The team is not likely to win.
```

**Negating the passive action**
```
The request is expected not to be approved.
The policy is likely not to be implemented.
The documents are supposed not to be shared publicly.
```

In many contexts, the placement of `not` changes the emphasis. <br/>
Example:
```
The request is not expected to be approved
- negates the expectation of approval

while

The request is expected not to be approved.
- emphasizes an expectation of non-approval.
```

#### 6. Questions

We can form questions by moving the appropriate form of BE(is/am/are/was/were/has/have) before the subject or
WH-words.

```
Statement: The report is supposed to be submitted today.
Question:  Is the report supposed to be submitted today?

Statement: The results are expected to be announced.
Question:  Are the results expected to be announced?

Statement: The policy is likely to be approved.
Question:  Is the policy likely to be approved?

Statement: The documents were supposed to be signed.
Question:  Were the documents supposed to be signed?
```

#### Summary: Final revision

| Expression  |    Active infinitive                       | Passive infinitive                        |
|-------------|--------------------------------------------|-------------------------------------------|
| Supposed to | They are supposed to follow the rules.     | The rules are supposed to be followed.    |
| Expected to | They are expected to announce the results. | The results are expected to be announced. |
| Likely to   | The company is likely to launch a product. | A product is likely to be launched.       |

**`Supposed to/expected to/likely to + be + V3`** expresses a passive action.

  <summary> <b> Passive Voice with Infinitive Clauses </b> </summary>

<br/>

We will learn how to change sentences containing two verbs into passive voice, especially sentences using `to + V1`.

#### 1. What is an infinitive?

An infinitive is usually formed using: **`to + V1`**

Examples: `to write, to complete, to submit, to finish, to read, etc`
```
I want him to complete the work.
- I = subject
- want = main verb
- him = object of want
- to complete the work = infinitive clause

They want me to write the script.
```

#### 2. Two different ways to use passive voice

There are two possible transformations, depending on which part we want to change.

**Method 1: Make the infinitive clause passive** 
```
Active:  I want him to complete the work.
- Change "to complete the work" into passive form.
Passive: I want the work to be completed by him.
```

**`to + V1` -> `to be + V3`**

| Active infinitive    |  Passive infinitive |
|----------------------|---------------------|
| to write the letter  | to be written       |
| to complete the task | to be completed     |
| to submit the report | to be submitted     |
| to repair the car    | to be repaired      |

**Method 2: Make the main clause passive**
```
Active:  They asked Ravi to submit the report.
- "They asked Ravi" into passive form.
Passive: Ravi was asked to submit the report.


I want him to complete the work.       [Infinitive clause]
I want the work to be completed.       [Infinitive clause Passive]

They asked him to complete the work.   [Main clause]
He was asked to complete the work.     [ Main clause - Passive]
```

#### `Want + object + infinitive`

| Active sentence                    | Passive sentence                           |
|------------------------------------|--------------------------------------------|
| I want him to clean the room.      | I want the room to be cleaned by him.      |
| She wants me to prepare dinner.    | She wants dinner to be prepared by me.     |
| We want them to finish the project.| We want the project to be finished by them.|
| He wants Ravi to repair the bike.  | He wants the bike to be repaired by Ravi.  |


#### `ask, tell, order, advise + object + infinitive`

These verbs often allow the object to become the subject of the passive sentence.

| Active sentence                   | Passive sentence                           |
|-----------------------------------|--------------------------------------------|
| They told Ravi to wait.           | Ravi was told to wait.                     |
| The teacher asked me to sit down. | I was asked to sit down by the teacher.    |
| The officer ordered them to leave.| They were ordered to leave by the officer. |
| The doctor advised him to rest.   | He was advised to rest by the doctor.      |
| They encouraged her to apply.     | She was encouraged to apply.               | 



#### `Expect + object + infinitive`

This pattern needs extra care. <br/>
There are two possible passive structures with different emphasis:
```
Active:    I expect them to finish the project.
Passive 1: I expect the project to be finished by them.
- The project is emphasized within the infinitive clause
Passive 2: They are expected to finish the project.
- The people are emphasized, and the main expectation structure is passive
```

Both are grammatically possible, but they emphasize different things.


#### The most important rule

Passive infinitive <br/>
**`to + V1` → `to be + V3`**
```
Active:  to complete the work
Passive: to be completed.
```
Passive main clause <br/>
**`Object + appropriate be + V3 + to + V1`**
```
Active:  They asked Ravi to wait
Passive: Ravi was asked to wait.
```

#### Revision

- Infinitive passive: `to be + V3`.
- Main clause passive: the object of the main verb may become the subject.
- Always identify which clause you are changing.
```
Ravi was asked to submit the report,   [infinitive stays active]
I want the report to be submitted,     [infinitive is passive.]
```

#### 1. What is a `that-clause`?

> A clause is a group of words containing a subject and a verb.

Example:
```

- The main verb is believe, and
- the that-clause tells us what people believe.

| That Clause | `that he is honest` | What people believe |

```
People believe that he is honest.

People think that the company will succeed.
```
These sentences contain a **that-clause**. <br/>
There are two common ways to make them passive.

**Method 1 - Using `It is believed that…`** <br/>
This is called the **impersonal passive**.

Active: **`People + reporting verb + that-clause`** <br/>
Passive: **`It + passive reporting verb + that-clause`**
```
Active:  People believe that he is honest.
Passive: It is believed that he is honest.
```

| Active                                      | Passive                                  |
|--------------------------------------------|-------------------------------------------|
| People say that he is intelligent.         | It is said that he is intelligent.        |
| Everyone knows that she is talented.       | It is known that she is talented.         |
| They think that he is innocent.            | It is thought that he is innocent.        |
| People reported that the road was blocked. | It was reported that the road was blocked.|
| They expect that prices will rise.         | It is expected that prices will rise.     | 

**Method 2 - Making the person the subject** <br/>
This is called the **personal passive**.

Instead of starting with “It,” we bring the person or thing mentioned in the that-clause to the beginning.  

**`Subject + passive reporting verb + to-infinitive`**
```
Active:  People believe that he is honest.
Passive: He is believed to be honest.
```

| Active                                   | Passive                                |
|------------------------------------------|----------------------------------------|
| People say that she is rich.             | She is said to be rich.                |

| People think that she is innocent.       | She is thought to be innocent.         |
| They report that the building is unsafe. | The building is reported to be unsafe. |
| People expect that the team will win.    | The team is expected to win.           |

**What if the action happened in the past?**
```
Active:             People believe that he stole the money.
Impersonal passive: It is believed that he stole the money.
Personal passive:   He is believed to have stolen the money.
```

| Earlier passive action     | `to have been + V3`        | The painting is believed to have been stolen. |
| Future action              | `to + V1`, often with expected/likely | The team is expected to win.       |

<details>
  <summary> <b> Passive Voice with <code> There is/are </code> and Existential Sentences </b> </summary>

<br/>

How to handle sentences beginning with there is, there are, there was, and there were, and understand why these sentences do not always convert into passive voice directly.

#### 1. What does `there` mean in these sentences?

```
There is a book on the table.
There are five students in the classroom.
There was an accident yesterday.
There were several problems in the project.
```
In these sentences, there introduces the existence or presence of something. It does not refer to a specific place.

```
There is a book on the table.
- There = introductory or dummy subject
- is = verb
- a book = the thing that exists
- on the table = place
```

#### 2. Can we change these sentences into passive voice?

Usually, no direct passive transformation is possible for ordinary existential sentences because they do not contain an action performed on an object.

| Sentence                                    | Passive            |
|---------------------------------------------|--------------------|
| There is a book on the table.               | No natural passive |
| There are five students in the classroom.   | No natural passive |
| There was an accident yesterday.            | No natural passive |
| There were several problems in the project. | No natural passive |


#### 3. What if the sentence contains an action?

A sentence may begin with there but still contain a verb that takes an object.

Examples:
```
Active:  There are people repairing the road.
- This means people are repairing the road.
- We can rephrase it as
Passive: The road is being repaired by people.
```

| Sentence with `there`                 | Possible passive rephrasing             |
|---------------------------------------|-----------------------------------------|
| There are workers painting the walls. | The walls are being painted by workers. |
| There is someone cleaning the room.   | The room is being cleaned by someone.   |
| There were people discussing the issue.| The issue was being discussed by people.|

These are rephrasings that emphasize the action, rather than mechanical conversions of the existential sentence.

#### 4. `There has been` and `There will be`

| Sentence                          | Explanation                                              |
|-----------------------------------|----------------------------------------------------------|
| There has been a delay.           | Describes the existence of a delay; no direct passive    |
| There will be a meeting tomorrow. | Describes a future event; no direct passive              |
| There had been several complaints.| Describes the existence of complaints; no direct passive |
| There is a document that needs signing. | The clause “needs signing` expresses a passive meaning |

Note: the presence of `has been`, `had been`, or `will be` does not automatically mean the sentence is passive.

Example:
```
There has been a problem.    - existential construction
The problem has been solved. - passive voice
```

#### 5. Compare these sentences carefully

```
Existence: There is a car in the garage.
- This tells us that a car exists or is present. It has no natural passive form.

Passive action: The car is repaired by Ravi.
- This tells us what is done to the car. The car receives the action.

Active action: There is a mechanic repairing the car.
- This tells us that a mechanic is performing an action. We can emphasize the car by saying, "The car is being repaired by a mechanic."
```

#### 6. Summary

1. **`There is/There are`** usually describe existence, so they do not have a direct passive form.

2. If an action is present in another clause, that action may be rewritten in passive voice.

3. **`Has been`/`was`/`will be`** do not automatically indicate passive voice. Always check the meaning and sentence structure.

| Simple      | The instructions are simple to follow. |
| Impossible  | This task is impossible to complete.   |
| Comfortable | This chair is comfortable to sit on.   |
| Safe        | This water is safe to drink.           |

Here, the subject receives the action described by the infinitive.

**`Subject + be(is/am/are) + adjective + to + V1`**

Examples:
```
The book is easy to read.
The machine is difficult to operate.
The question is impossible to answer.
```

This structure has passive meaning, but it is not a standard grammatical passive construction. <br/>
The infinitive remains in its active form.

#### 3. Why don't we use `to be + V3` here?

| Natural expression                    | Less natural or incorrect in the intended meaning |
|---------------------------------------|---------------------------------------------|
| This book is easy to read.            | This book is easy to be read.               |
| The problem is difficult to solve.    | The problem is difficult to be solved.      |
| The instructions are simple to follow.| The instructions are simple to be followed. |

In standard English, adjectives such as easy, difficult, hard, and impossible commonly take an active infinitive even when the subject receives the action.

However, **`to be + V3` is correct in other constructions**:
```
This book needs to be read.
The problem is expected to be solved.
The instructions are required to be followed.
```

The difference is the grammatical structure, not simply the meaning.

#### 4. Sentences with `to be + V3` after nouns

```
She is a person to be trusted.
- Here, to be trusted describes the noun person.
- It is a passive infinitive.
```

| Sentence                                | Explanation                            |
|-----------------------------------------|----------------------------------------|
| She is a person to be trusted.          | Passive infinitive                     |
| This book is easy to read.              | Active infinitive with passive meaning |
| He is difficult to convince.            | Active infinitive with passive meaning |
| The report is to be submitted tomorrow. | Passive infinitive expressing an arrangement or requirement |

```
This is the work to be completed today.
He is the person to be contacted.
These are the documents to be signed.
The report is to be submitted by Monday.
```

#### 5. `Too…to` and `enough…to` constructions

**A. `Too + adjective + to + V1`**

Examples:
```
1. The box is too heavy to lift.
- Meaning: The box is so heavy that someone cannot lift it.

2. The question is too difficult to answer.
3. The wall is too high to climb.
4. The water is too hot to drink.
```

**B. `Adjective + enough + to + V1`**

Examples:
```
1. The water is cool enough to drink.
- Meaning: Someone can drink the water because it is sufficiently cool.

2. The problem is simple enough to solve.
3. The room is large enough to accommodate everyone.
4. The book is short enough to read in one day.
```

#### 6. How to identify the correct structure

When you see `Easy/difficult/hard`,  Use `adjective + to + V1`.

Example: 
```
The problem is difficult to solve.
```

When you see `Noun + passive infinitive`, Use `noun + to be + V3` when the meaning requires it.

Example: 
```
The documents are to be signed.
```

When you see `Need/require`, Use `to be + V3` when expressing a required action.

Example: 
```
The car needs to be repaired.
```

#### 7. Summary

**`Adjective + infinitive`**: The book is easy to read.

**`Noun + passive infinitive`**: The documents are to be signed.

**`Need + passive infinitive`**: The car needs to be repaired.

<details>
  <summary> <b> Passive Voice with <code> Have/Get Something Done </code> in Different Tenses </b> </summary>

<br/>

Lets revise and expand a useful structure called the **causative construction**.

We use it when someone arranges for another person to do something for them, rather than doing the work themselves.

Example:
```
I repaired my car.      — I did the repair myself.
I had my car repaired.  — I arranged for someone else to repair my car.
```

#### 1. Basic Formula

`Have something done` basic formula `Subject + have + object + V3`

Example: 
```
I have my car repaired.
```

`Get something done` basic formula `Subject + get + object + V3`

Example:
```
I get my car repaired.
```

#### 2. `Have something done` in different tenses

The tense changes the form of have, while the object and V3 remain in place.

| Tense              | Formula                                | Example                                       |
|--------------------|----------------------------------------|-----------------------------------------------|
| Present simple     | `Sub + have/has + object + V3`         | I have my car repaired regularly.             |
| Past simple        | `Sub + had + object + V3`              | I had my car repaired yesterday.              |
| Future simple      | `Sub + will have + object + V3`        | I will have my car repaired tomorrow.         |
| Present continuous | `Sub + am/is/are having + object + V3` | I am having my car repaired now.              |
| Past continuous    | `Sub + was/were having + object + V3`  | I was having my car repaired when you called. |
| Present perfect    | `Sub + have/has had + object + V3`     | I have had my car repaired.                   |
| Past perfect       | `Sub + had had + object + V3`          | I had had my car repaired before the trip.    |
| Future perfect     | `Sub + will have had + object + V3`    | I will have had my car repaired by Friday.    |

Note: `I have had my car repaired,` the first `have` is the auxiliary for the present perfect, and the second `had` is the past participle of the causative verb have.

#### 3. `Get something done` in different tenses

| Tense              | Formula                                 | Example                                   |
|--------------------|-----------------------------------------|-------------------------------------------|
| Present simple     | `Sub + get/gets + object + V3`          | I get my hair cut regularly.              |
| Past simple        | `Sub + got + object + V3`               | I got my laptop repaired yesterday.       |
| Future simple      | `Sub + will get + object + V3`          | I will get the documents printed tomorrow.|
| Present continuous | `Sub + am/is/are getting + object + V3` | I am getting my phone repaired.           |
| Present perfect    | `Sub + have/has got + object + V3`      | I have got my phone repaired.             |

In some varieties of English, particularly British English, `have got` can be used in this structure, though `have had` is often clearer when emphasizing a completed service.

#### 4. Compare three different sentence structures


```
Active voice:
I repaired my car.
I personally performed the repair.

Ordinary passive:
My car was repaired by the mechanic.
The car receives the action; the mechanic performed it.

Causative
I had my car repaired.
I arranged for the repair, usually by another person.
```
The causative construction is not simply another passive form. It emphasizes the person who arranged the service.

#### 5. When something unpleasant happens

The causative construction can also describe an unwanted experience.

Example:
```
He had his wallet stolen.
She had her phone damaged.
They had their house broken into.
```

These do not necessarily mean that the person arranged for the action. <br/>
Instead, they describe something that happened to them or their possessions, often unexpectedly.

```
I had my phone repaired. - I arranged for a repair.
I had my phone stolen.   - My phone was stolen; I did not arrange for it.
```
The context and the participle determine the meaning.

<details>
  <summary> <b> Alternative Passive Structures: `Need + -ing` and Similar Patterns </b> </summary>

<br/>

English sometimes expresses a passive meaning without using the normal `be(is/am/are) + V3` structure.

Example:
```
The car needs repairing.
- The car cannot repair itself. Someone needs to repair it.
- So "needs repairing" has passive meaning.
```

#### 1. `Need + -ing`

The basic pattern is: `Subject + need(s) + V-ing`
```
The car needs repairing.
- Meaning: The car needs to be repaired.

Both sentences have essentially the same meaning.
```

| `-ing` structure            | Passive infinitive                |
|-----------------------------|-----------------------------------|
| The car needs repairing.    | The car needs to be repaired.     |
| The house needs painting.   | The house needs to be painted.    |
| The document needs checking.| The document needs to be checked. |
| The machine needs cleaning. | The machine needs to be cleaned.  |
| The door needs fixing.      | The door needs to be fixed.       |

Here, `V-ing` does not mean that the subject is performing the action.
```
The house needs painting.
- The house isn't painting anything.
- Someone needs to paint the house.
- Therefore, the construction has passive meaning.
```

#### 2. Why does English use `-ing` here?

This is a special grammatical pattern. Normally: `V-ing` -> active meaning like `Ravi is repairing the car.` 
Here Subject which is Ravi is performing the action.

But after **`need`** in this construction like `The car needs repairing.` The meaning is passive. <br/>
This is especially common in British English. <br/>
In American English, `The car needs to be repaired` is often preferred.

#### 3. `Want + -ing`

In some varieties of English, especially British English, you may hear:
```
The floor wants cleaning.
This can mean:
The floor needs to be cleaned.
```

For general English tandard or less widely used even in exams, prefer:
```
The floor needs to be cleaned.
```

#### 4. `Require + -ing`

```
The document requires signing.
Meaning:
The document requires to be signed.
```
But wait- `requires to be signed` is generally not the natural structure when the document itself is the subject.

The natural alternatives are:
```
The document requires signing.
or
The document requires someone to sign it.
or
The document needs to be signed.
```

```
The report requires checking.      [Natural]
The report requires to be checked. [Less Natural]
The report needs to be checked.    [Natural]
```
So don't blindly apply: `require + to be + V3` to every sentence.

#### 5. `Deserve + -ing`

Another useful structure is:
```
The problem deserves discussing.
- This has passive meaning:
The problem deserves to be discussed.
```
However, in everyday English, the following can often sound more natural:
```
The problem deserves to be discussed.
```
Examples:
```
This issue deserves considering.
- This issue deserves to be considered.
The proposal deserves examining.
- The proposal deserves to be examined.
```

#### 6. `Be worth + -ing`

This is another very common pattern.

```
The book is worth reading.
Meaning:
The book is worth being read.
```
But `worth being read` is usually much less natural. So we normally say: `The book is worth reading.`

```
The movie is worth watching.
The museum is worth visiting.
The problem is worth discussing.
```

These have a passive-like meaning because the subject receives the action.

#### 7. Compare all the structures

Normal passive
```
The car needs to be repaired.
```

Need + -ing
```
The car needs repairing.
```

Causative
```
I need to have my car repaired.
```

The meanings are different:

| Sentence                        | Meaning                                     |
| ------------------------------- | ------------------------------------------- |
| The car needs to be repaired.   | Repair is necessary.                        |
| The car needs repairing.        | Same basic meaning; alternative structure.  |
| I need to have my car repaired. | I need to arrange for someone to repair it. |

#### 8. `Be + adjective + infinitive`

We have already seen this before
```
The book is easy to read.
- This has passive meaning.
```
But notice:
```
The book is easy to read.
Not: The book is easy to be read.
```

```
The question is difficult to answer.
The machine is easy to operate.
The instructions are simple to follow.
```
These are passive in meaning, but they don't use the normal passive `be(is/am/are) + V3` construction.

####  Quick comparison and summary

| Structure                 | Example                       | Meaning                              |
| ------------------------- | ----------------------------- | ------------------------------------ |
| Passive                   | The car was repaired.         | Someone repaired it.                 |
| Need + -ing               | The car needs repairing.      | It needs repair.                     |
| Need + passive infinitive | The car needs to be repaired. | It needs repair.                     |
| Adjective + infinitive    | The car is easy to repair.    | Repairing it is easy.                |
| Causative                 | I had the car repaired.       | I arranged for someone to repair it. |

1. Normal passive
```
The car was repaired.
```
2. Need + -ing
```
The car needs repairing.
```
3. Need + passive infinitive
```
The car needs to be repaired.
```
4. Adjective + infinitive
```
The car is easy to repair.
```

<details>
  <summary> <b> Passive Voice with Indefinite Subjects </b> </summary>

<br/>

What happens when the active sentence has subjects such as:
```
people
someone
somebody
everyone
everybody
they
nobody
no one
anyone
someone else
```
These subjects are called **indefinite subjects** because they don't identify a specific person.

#### 1. Why are these subjects important?

```
Active: People speak English all over the world.
Subject - People
Verb - speak
Object - English

Passive: English is spoken all over the world.
usually don't need: English is spoken by people all over the world.

Why?
- Because people” is obvious and unimportant.
- So passive voice often allows us to remove the agent.
```

> Rule: **When the active subject is general or unknown, `by + subject` is often omitted.**

#### 2. `Someone` and `Somebody`

Example:
```
Active: Someone stole my phone.
- Someone = subject
- stole = verb
- my phone = object

Passive: My phone was stolen.
Normally don't need: My phone was stolen by someone.

The identity of the person is unknown, so we can omit the agent.
```

```
Active:  Someone broke the window.
Passive: The window was broken.

Active:  Somebody opened the door.
Passive: The door was opened.

Active:  Someone has taken my bag.
Passive: My bag has been taken.

Active:  Someone will repair the machine.
Passive: The machine will be repaired.
```

#### 3. `People`

This is one of the most common cases.

```
Active:  People use smartphones everywhere.
Passive: Smartphones are used everywhere.

Active:  People speak Hindi in many parts of India.
Passive: Hindi is spoken in many parts of India.

Active:  People believe that exercise is important.
Passive: It is believed that exercise is important.
```

Here we can omit **people** because the statement refers to people generally.

#### 4. `They`

`They` can have two different meanings.

**Meaning 1 - `They` as Specific people**
```
Active:  The employees completed the project.
- Here, the employees are identifiable.
Passive: The project was completed by the employees.
```

**Meaning 2 - `They` as Unspecified people**
```
Active:  They say that the company is successful.
- Here, “they” means people generally, not a specific group.
Passive: It is said that the company is successful.
```

Rule: Don't automatically remove every they.
```
Ask: Who does “they” refer to?
- If it refers to a known group, keep the agent when useful.
- If it means people generally, it can often be omitted.
```

#### 5. `Everyone/Everybody`

These words normally mean all people in a particular group or situation.

Example:
```
Active:  Everyone respects the teacher.
Passive: The teacher is respected by everyone.

Active:  Everybody liked the movie.
The movie was liked by everybody.
```
Unlike `people`, everyone is often useful to retain because it emphasizes that all people have the same attitude.


```
Everybody liked the movie.
The movie was liked by everybody.
- But grammatically, you can sometimes omit the agent if the context makes it unnecessary:
The movie was liked.
```

#### 6. `Nobody/No one`

These require special care because the negative meaning must remain.

```
Active:  Nobody opened the door.
We can't simply say: The door was opened.
- That changes the meaning.
Passive: The door was not opened by anyone.
Passive: The door was opened by nobody.

Active:  Nobody answered the question.
Passive: The question was not answered by anyone.
```

#### 7. Why does `nobody` become `anyone`?

This is a very useful transformation.

```
Active:  Nobody helped him.
Passive: He was not helped by anyone.
```

The negative meaning moves into not, and nobody changes to anyone.

**Pattern** <br/>
Active: `Nobody + active verb` <br/>
Passive: `Object + be + not + V3 + by anyone`
```
Active:  Nobody invited Ravi.
Passove: Ravi was not invited by anyone.
```

#### 8. `Anyone/Anybody`

```
Active:  Anyone can use this computer.
Passive: This computer can be used by anyone.
- Here, "anyone" remains because it expresses permission or possibility for any person.

Active:  Anyone can access the website.
Passive: The website can be accessed by anyone.
```

But if `anyone` means an unknown person in a question or negative sentence, the structure can behave differently.
```
Active:  Did anyone open the door?
Passive: Was the door opened by anyone?
```

#### 9. `Someone else / somebody else`

If the identity is unknown but the idea of another person is important, we can retain it.

```
Active:  Someone else will complete the task.
Passive: The task will be completed by someone else.
```
The agent is not identified, but someone else carries useful meaning, so keeping it can be appropriate.

#### 10. `People say…` vs `Someone says…`

```
Active: People say that he is rich.
Passive: It is said that he is rich.
- The statement is general.

Active:  Someone says that he is rich.
Passive: It is said that he is rich.
- Here too, the exact person is not identified, so the agent is usually omitted.

Passive: It is said by someone that he is rich.
- This is grammatical but unnatural in most contexts.
```

#### 11. Negative indefinite subjects

| Active                         | Passive                                  |
| ------------------------------ | ---------------------------------------- |
| Nobody opened the door.        | The door wasn't opened by anyone.        |
| No one answered the phone.     | The phone wasn't answered by anyone.     |
| Nobody invited her.            | She wasn't invited by anyone.            |
| No one has seen the document.  | The document hasn't been seen by anyone. |
| Nobody will solve the problem. | The problem won't be solved by anyone.   |

Notice that the negative meaning is preserved.

#### 12. `Everyone` vs `Anyone`

These words are easy to confuse.

**`Everyone` means all people.**
```
Active:  Everyone knows him.
Passive: He is known by everyone.
```

**`Anyone` Means any person / no particular person depending on context.**
```
Active:  Anyone can use this room.
Passive: This room can be used by anyone.
```

#### 13. A very important rule

Don't change the meaning while converting active to passive.

```
Active:  Nobody completed the work.
Passive: The work was completed.  [Wrong]
- This removes the negative meaning.
Passive: The work was not completed by anyone. [Correct]

Active: Everyone praised her.
Passive: She was praised.
- if require all information to be preserved.
Passive: She was praised by everyone. [Correct]
```

#### 14. Quick conversion strategy

When you see an indefinite subject, follow these steps:

**Step 1 - Find the object**
```
Someone repaired the car.
- Object = the car
```

**Step 2 - Move it to the beginning**
```
The car ...
```

**Step 3 - Preserve the tense**
```
Someone repaired the car.
- Past simple -> was/were
```

**Step 4 - Use V3**
```
- repair -> repaired
The car was repaired.
```

**Step 5 - Decide whether the agent is necessary**
```
"Someone" is unknown, so normally: The car was repaired.
Not: The car was repaired by someone.
```

#### 15. Summary: Final revision

The most important patterns are:

**Unknown person**
```
Active:  Someone broke the window.
Passive: The window was broken.
```

**General people**
```
Active:  People speak English.
Passive: English is spoken.
```

**Everyone**
```
Active:  Everyone liked the movie.
Passive: The movie was liked by everyone.
```

**Nobody**
```
Active:  Nobody opened the door.
Passive: The door was not opened by anyone.
```

**Anyone**
```
Active:  Anyone can use the machine.
Passive: The machine can be used by anyone.
```

**Main rule** <br/>
Don't just change the grammar - preserve the meaning.

<details>
  <summary> <b> Passive Voice with Focus Words: <code> Only, Even, Also, Just, Still, etc. </code> </b> </summary>

<br/>

When changing Active -> Passive, the focus words should normally stay with the part of the sentence they logically modify.

Words such as `only, even, also, just, still, already, never, always` can change the emphasis of a sentence.


#### 1. `Only`


```
Active:  Only Ravi completed the assignment.
- Here, only modifies Ravi.
Passive: The assignment was completed only by Ravi.
- The word only still emphasizes Ravi.

Active:  Only Ravi completed the assignment.
Passive: The assignment was completed only by Ravi.
- Meaning: Nobody except Ravi completed it.

Active:  Only the manager approved the request.
Passive: The request was approved only by the manager.
```

#### 2. `Only` can modify the object

The position of **`only`** can completely change the meaning.
```
Active:  Ravi bought only the blue shirt.
- Here, only modifies the blue shirt, not Ravi.
Passive: Only the blue shirt was bought by Ravi.

Active:  Only Ravi bought the blue shirt.
Passive: The blue shirt was bought only by Ravi.

Active:  Ravi bought only the blue shirt.
Passive: Only the blue shirt was bought by Ravi.
```

#### 3. `Also`

`Also` generally remains associated with the action or information it adds.

```
Active:  Ravi also completed the report.
Passive: The report was also completed by Ravi.

Active:  They also invited Sarah.
Passive: Sarah was also invited by them.
```
The meaning of also remains.

#### 4. `Even`

`Even` adds emphasis or surprise.

```
Active:  They even invited Ravi.
Passive: Ravi was even invited by them.

Active:  The company even offered him a promotion.
Passive: He was even offered a promotion by the company.
```
The focus remains on the surprising element.

#### 5. `Just` - `Recently` and `Only`

`Just` can mean **recently or only/exactly**, depending on context.

Meaning 1 - Recently
```
Active:  They have just completed the project.
Passive: The project has just been completed.
```
The structure is: `Subject + has + just + been + V3`


Meaning 2 - Only
```
Ravi just wanted an explanation.
- This meaning is different and doesn't necessarily require a passive transformation.
```

Always understand what just means before changing the sentence.

#### 6. `Already`

`Already` often appears with perfect tenses.
```
Active:  They have already completed the work.
Passive: The work has already been completed.

Active:  Someone had already closed the shop.
Passive: The shop had already been closed.
```
Structure: `Sub + has/have + already + been + V3`

#### 7. `Still`

`Still` usually indicates that something continues.
```
Active:  They are still repairing the road.
Passive: The road is still being repaired.

Active:  They were still discussing the problem.
Passive: The problem was still being discussed.
```

Structure: `Subject + is/am/are + still + being + V3`

#### 8. `Never`

We studied negative sentences earlier, but `never` is worth revising.
```
Active:  They have never opened this room.
Passive: This room has never been opened.

Don't add another not.

Incorrect:  This room has not never been opened.
Correct:    This room has never been opened.
```

#### 9. `Always`

```
Active:  People always remember great leaders.
Passive: Great leaders are always remembered.

Active:  They always clean the classroom.
Passive: The classroom is always cleaned.
```

Notice that always normally comes after the auxiliary be in this passive structure: `Sub + is/am/are + always + remembered`

#### 10. “Often / Usually / Sometimes / Rarely”

These adverbs normally keep their position relative to the auxiliary and main verb.

```
Active:  They often use this machine.
Passive: This machine is often used.

Active: People usually follow these rules.
Passive: These rules are usually followed.

Active:  They rarely use this method.
Passive: This method is rarely used.
```

#### 11. Position with different passive structures

```
Present simple passive:     The machine is always used.
Past simple passive:        The machine was always used.
Present continuous passive: The machine is still being used.
Present perfect passive:    The machine has already been used.
Modal passive:              The machine must always be used carefully.
```

#### 12. `Only` with modal verbs

The focus word normally comes after the first auxiliary and before the remaining verb phrase.

```
Active:  Only trained workers can operate this machine.
Passive: This machine can be operated only by trained workers.

Active:  Only managers may access this information.
Passive: This information may be accessed only by managers.
```
The word **only** continues to emphasize who is permitted/able to operate it.

#### 13. `Not only … but also`

This is a more advanced structure.

```
Active:  The company not only hired Ravi but also promoted him.
Passive: Ravi was not only hired but also promoted by the company.
- The parallel structure is preserved.

Active:  They not only repaired the car but also cleaned it.
Passive: The car was not only repaired but also cleaned.
- Notice that we don't need to repeat the agent if it is already obvious.
```

#### 14. Quick reference

| Active                               | Passive                                 |
| ------------------------------------ | --------------------------------------- |
| They have already finished the work. | The work has already been finished.     |
| They are still repairing the road.   | The road is still being repaired.       |
| People always respect him.           | He is always respected.                 |
| They often use this machine.         | This machine is often used.             |
| They have never opened the door.     | The door has never been opened.         |
| Only Ravi completed the task.        | The task was completed only by Ravi.    |
| Ravi bought only the blue shirt.     | Only the blue shirt was bought by Ravi. |
| They even invited Sarah.             | Sarah was even invited by them.         |

#### 15. Final rule

When converting Active -> Passive: Don't treat adverbs as decoration.

Words such as: `only, even, also, just, already, still, never, always, often, usually` can affect the meaning and emphasis of the sentence.


1. Identify what the focus word modifies.
2. Change the voice.
3. Place the focus word where the same meaning is preserved.

#### 16. Final revision

Remember these examples:
```
Active:  They have already completed the work.
Passive: The work has already been completed.

Active:  They are still repairing the road.
Passive: The road is still being repaired.

Active:  People always respect him.
Passive: He is always respected.

Active:  Only Ravi completed the task.
Passive: The task was completed only by Ravi.

Active:  Ravi bought only the blue shirt.
Passive: Only the blue shirt was bought by Ravi.
```

The biggest lesson is: **placement can change meaning, especially with `only`.**

<details>
  <summary> <b> Passive Voice with Relative Clauses </b> </summary>

<br/>

This is important because a sentence can contain both:
1. a relative clause, and
2. a passive construction.

Example:
```
Active:  This is the book that Ravi wrote.
- We can change the relative clause to passive:
Passive: This is the book that was written by Ravi.
```

#### 1. What is a relative clause?

A relative clause gives additional information about a noun.

Common relative words are:
```
who
whom
whose
which
that
```
Example:
```
I met the man who helped me.
```
The clause **who helped me** gives information about the man.

#### 2. Active relative clause to Passive relative clause

```
Active:  This is the book that Ravi wrote.
- Focus only on the relative clause:

Active: Ravi wrote the book.
- Ravi = subject
- wrote = verb
- the book = object
Passive: The book was written by Ravi.

Therefore
Passive:  This is the book that was written by Ravi.
```

Active relative clause: `noun + that/which + subject + verb + object` <br/>
Passive relative clause: `noun + that/which + be + V3 + by + subject`

#### 3. More examples with `that`

```
Active: The car that Ravi bought is expensive.
- Relative clause: Ravi bought the car.
Passive: The car that was bought by Ravi is expensive.

Active: The letter that she wrote was beautiful.
Passive: The letter that was written by her was beautiful.

Active:  The movie that they produced became popular.
Passive: The movie that was produced by them became popular.
```

#### 4. `Which` in passive relative clauses

We can use which when referring to things.
```
Active: The computer which Ravi repaired is working now.
Passive: The computer which was repaired by Ravi is working now.

Active:  The house which they built is very large.
Passive: The house which was built by them is very large.
```

#### 5. “Who” and people

When who is the subject of the relative clause, we need to be careful.

```
Active: The man who helped me was kind.
- Here, who is the subject of helped.
- Can we directly make it passive?
- There is no object receiving the action in:
- Who helped me?
- The object is me.
- So the passive of the relative clause is:
Passive: The man by whom I was helped was kind.
- However, this sounds formal.
- A more natural sentence would usually be:
Active:  The man who helped me was kind.
```

This demonstrates an important principle:
> **A grammatically possible passive isn't always the most natural English sentence**.

#### 6. `Whom` in active relative clauses

```
Active:  The person whom Ravi invited came to the party.

Inside the relative clause: Ravi invited whom.
- Ravi = subject
- whom = object

Passive:  The person who was invited by Ravi came to the party.
```

In modern everyday English, **`who`** is commonly used instead of **`whom`** in many such contexts.


#### 7. `Whose`

`Whose` indicates possession.

Example:
```
I met the student whose teacher praised him.
- We need to be careful because the relative clause has its own structure.

This is the company whose products are used worldwide.
- This is already passive:
- products are used worldwide.
- We don't simply replace whose.
```

The important rule is: <br/>
**Change the verb inside the relative clause, not the relative pronoun itself, unless the sentence structure requires something else.**

#### 8. Relative clause already containing passive voice

Sometimes the sentence is already passive.

Example:
```
This is the car that was repaired by Ravi.
- There is nothing more to convert inside that clause.
- The relative clause is: "that was repaired by Ravi"

The documents which were submitted yesterday are being checked.

The relative clause: "which were submitted yesterday"
- It is already passive.
```
Structure: `that + was + V3 + by + agent`

#### 9. Omitting `that` in active clauses

This is a very useful advanced point.

```
Active: The book that Ravi wrote is interesting.
- Because that is the object of wrote, it can be omitted:
Active: The book Ravi wrote is interesting.
- But what happens when we make the clause passive?
Passive: The book that was written by Ravi is interesting.
- Can we remove that? Yes:
Passive: The book written by Ravi is interesting.
```
This is a reduced relative clause.


#### 10. Reduced passive relative clauses

This is a very common structure.
```
Full relative clause
The car that was damaged in the accident was repaired.

Reduced relative clause
The car damaged in the accident was repaired.

We remove: that was and keep the past participle: damaged

The documents that were submitted yesterday are missing.
The documents submitted yesterday are missing.

The houses that were built last year are expensive.
The houses built last year are expensive.

The students who were selected for the competition will travel tomorrow.
The students selected for the competition will travel tomorrow.
```

#### 11. Don't confuse this with a normal passive sentence

```
Compare:
The documents were submitted yesterday.
- This is a normal passive sentence.
But:
The documents submitted yesterday are missing.
- Here, submitted yesterday is a reduced relative clause describing the documents.

The complete version is:
The documents that were submitted yesterday are missing.
```

#### 12. Relative clauses with `where` and `when`

These are slightly different.

**Where**
```
This is the building where they held the meeting.
- A passive version:
This is the building where the meeting was held.
- Notice that where remains.
```
**When**
```
Active:  I remember the day when they announced the result.
Passive: I remember the day when the result was announced.
- Again, when remains.
```

#### 13. Relative clauses with modal verbs

```
Active:  This is the machine that you must operate carefully.
Passive: This is the machine that must be operated carefully.

Active:  The documents that you should submit today...
Passive: The documents that should be submitted today...
```
The structure is: `modal + be + V3`

#### 14. Relative clauses with perfect tense

```
Active:  This is the report that Ravi has completed.
Passive: This is the report that has been completed by Ravi.

Active:  The work that they had completed was lost.
Passive: The work that had been completed by them was lost.

```
Formula: `has/have + been + V3`

#### 15. A step-by-step conversion method

Take: `The laptop that Ravi repaired is working perfectly.`

**Step 1 - Find the relative clause**
`that Ravi repaired`

**Step 2 - Find S, V, O**
```
Ravi = subject
repaired = verb
laptop = object
```
**Step 3 - Make the clause passive**
`that was repaired by Ravi`

**Step 4 - Put it back into the sentence**

`The laptop that was repaired by Ravi is working perfectly.`

That's it.

#### 16. Quick reference

| Active relative clause  | Passive relative clause         |
| ----------------------- | ------------------------------- |
| that Ravi wrote         | that was written by Ravi        |
| that she completed      | that was completed by her       |
| which they built        | which was built by them         |
| that he has repaired    | that has been repaired by him   |
| which they are using    | which is being used by them     |
| that they will announce | that will be announced by them  |
| that you must follow    | that must be followed           |
| that they had submitted | that had been submitted by them |


#### 17. Final revision

There are three important patterns to remember.

Full passive relative clause
```
The book that Ravi wrote.
- The book that was written by Ravi.
```

Reduced passive relative clause
```
The book that was written by Ravi.
- The book written by Ravi.
```

Already-passive relative clause
```
The book that was written by Ravi is expensive.
```
No further change is required.

The key idea is: <br/>
**When a relative clause contains an active transitive verb, you can often make that clause passive while leaving the main clause unchanged.**

<details>
  <summary> <b> Passive Voice with <code> Who </code> and <code> Whom </code> in Questions </b> </summary>

<br/>

We'll focus specifically on questions containing `who, whom, what, which, and whose`.

These can be confusing because when we change Active -> Passive, the question word may change its grammatical role.

#### 1. The basic idea

```
Active:  Who wrote the letter?
- We don't know who performed the action.
- Who = subject
- wrote = verb
- the letter = object
- To make it passive, the object the letter becomes the subject:
Passive: By whom was the letter written?
- the letter -> new subject
- was -> auxiliary
- written -> V3
- by whom -> agent

Active:  Who broke the window?
Passive: By whom was the window broken?
```

**Formula** <br/>
Active: `Who + V2 + object?` <br/>
Passive: `By whom + was/were + object + V3?`

#### 2. `Who` as the subject

This is the most important case.

```
Active:  Who invited Ravi?
- Who = subject
- invited = verb
- Ravi = object
Passive: Who was Ravi invited by?
- This is common in everyday English.

- A more formal version is:
Passive: By whom was Ravi invited?

- Both are grammatical.
```

**Compare**

| Style	          | Question                   |
|-----------------|----------------------------|
| Common/informal	| Who was Ravi invited by?   |
| Formal	        | By whom was Ravi invited?  |

> For grammar exercises, “By whom…” is often the expected answer.

#### 3. `Whom` as the object

```
Active:  Whom did Ravi invite?
- Ravi = subject
- did invite = verb
- whom = object
- The object is already whom, so when we make the sentence passive, it becomes the new subject.

Passive: Who was invited by Ravi?
- Notice something interesting:
- whom -> who
- Why?
- Because after becoming the subject of the passive sentence, the pronoun takes the subject form who.

Active:  Whom did Ravi invite?
Passive: Who was invited by Ravi?
```

#### 4. Compare the two situations

This is extremely important.

**Situation A - `Who` is the active subject**
```
Active:  Who invited Ravi?
Passive: Who was Ravi invited by?
or:
Passive: By whom was Ravi invited?
- The unknown person is the agent.
```

**Situation B - `Whom` is the active object**
```
Active:  Whom did Ravi invite?
Passive: Who was invited by Ravi?
- The unknown person is the receiver of the action.

So: Who invited Ravi? and Whom did Ravi invite?
ask completely different questions.

Active:  Who wrote this book?
- Who = person performing the action.
Passive: By whom was this book written?

Active:  Whom did the author thank?
- Whom = person receiving the action.
Passive: Who was thanked by the author?
```

#### 6. `What` questions

Let's look at `what`.

```
Active:  What did Ravi buy?
- Ravi = subject
- buy = verb
- what = object
Passive: What was bought by Ravi?

In natural English, we might simply say:
What did Ravi buy?

Active:  What did they build?
Passive: What was built by them?
```
The active form is often more natural in conversation. <br/>
Though, grammatically possible, but the active question may sound more natural.

#### 7. `Which` questions

Consider:
```
Active:  Which book did Ravi write?
- Ravi = subject
- write = verb
- which book = object
Passive: Which book was written by Ravi?
- This is very natural.

Active:  Which car did they repair?
Passive: Which car was repaired by them?
```

#### 8. `Whose` questions

`Whose` expresses possession.

Example:
```
Active:  Whose car did Ravi repair?
Passive: Whose car was repaired by Ravi?
- Notice that whose car remains together.

Active: Whose house did they paint?
Passive: Whose house was painted by them?
```

#### 9. Questions with `did`

This is a common place for mistakes.
```
Active:  Who did Ravi invite?
- Here "did" is the auxiliary.
Passive: Who was invited by Ravi?
- We don't keep did.
- Why?
- Because passive voice uses the appropriate form of be: was invited not: did invited

Incorrect: Who did invited by Ravi?
Correct:   Who was invited by Ravi?
```

#### 10. Present simple questions

```
Active:  Who cleans the room?
Passive: By whom is the room cleaned?
or:
Passive: Who is the room cleaned by?

Active:  Who teaches English?
Passive: By whom is English taught?
```

#### 11. Past simple questions

```
Active:  Who broke the window?
Passive: By whom was the window broken?

Active:  Who painted the wall?
Passive: By whom was the wall painted?
```

#### 12. Present continuous questions

```
Active:  Who is repairing the car?
Passive: By whom is the car being repaired?

Active:  Who is cleaning the room?
Passive: By whom is the room being cleaned?
```
**Structure: `is + being + V3`**

#### 13. Present perfect questions

```
Active:  Who has completed the project?
Passive: By whom has the project been completed?

Active:  Who has opened the door?
Passive: By whom has the door been opened?
```
Structure: `has + been + V3`

#### 14. Future questions

```
Active:  Who will complete the project?
Passive: By whom will the project be completed?

Active:  Who will repair the machine?
Passive: By whom will the machine be repaired?
```
Structure: `will + be + V3`

#### 15. Modal questions

```
Active:  Who can solve this problem?
Passive: By whom can this problem be solved?

Active:  Who should complete the form?
Passive: By whom should the form be completed?

Active:  Who must follow these rules?
Passive: By whom must these rules be followed?
```
Formula: `modal + subject + be + V3`

#### 16. `What` can also ask about the subject

```
Active:  What caused the accident?
- Here what is the subject.
- The object is: the accident
Passive: What was the accident caused by?
```

A formal version: 
```
By what was the accident caused?
```
However, this sounds unnatural in many contexts.
A natural English speaker would often simply use the active question:
```
What caused the accident?
```

Important lesson: **Not every grammatically possible passive question is natural English.**

#### 17. `Who` vs `whom` - modern English

Traditional grammar distinguishes: <br/>
`who` -> subject <br/>
`whom` -> object

Example:
```
Who called you?
Whom did you call?
```
But in modern everyday English, who is very commonly used instead of whom:
```
Who did you call?
```
This is completely normal in conversational English.

Whom is more formal and is especially common after prepositions:
```
To whom did you speak?
By whom was the letter written?
```

#### 18. Quick conversion method

Take: `Who completed the report?`

**Step 1 - Find the object**
```
the report
```
**Step 2 - Move the object to the beginning**
```
The report...
```
**Step 3 - Identify the tense**
```
completed = past simple
So use: was/were
```
**Step 4 - Use V3**
```
complete → completed
```
**Step 5 - The unknown agent becomes `by whom`**
```
By whom was the report completed?
```
Done.

#### 19. Quick reference table

| Active question              | Passive question                      |
| ---------------------------- | ------------------------------------- |
| Who wrote the letter?        | By whom was the letter written?       |
| Who broke the window?        | By whom was the window broken?        |
| Whom did Ravi invite?        | Who was invited by Ravi?              |
| Which book did Ravi write?   | Which book was written by Ravi?       |
| Whose car did Ravi repair?   | Whose car was repaired by Ravi?       |
| Who is cleaning the room?    | By whom is the room being cleaned?    |
| Who has completed the work?  | By whom has the work been completed?  |
| Who will repair the machine? | By whom will the machine be repaired? |
| Who can solve the problem?   | By whom can the problem be solved?    |


#### 20. Final rule

When dealing with questions, first ask: **Is the question word the subject or the object?**

**If `who` is the subject**:
```
Active:  Who wrote the letter?
Passive: By whom was the letter written?
```

**If `whom` is the object**:
```
Active:  Whom did Ravi invite?
Passive: Who was invited by Ravi?
```
That's the key distinction.

<details>
  <summary> <b> Passive Voice with Phrasal & Prepositional Verbs </b> </summary>

<br/>

This is important because the particle or preposition usually stays with the verb when we make the sentence passive.

Example:
```
Active:  They called off the meeting.
Passive: The meeting was called off.
Not:     The meeting was called.
```

#### 1. What is a phrasal verb?

> **A phrasal verb is a verb combined with another word, usually an adverb or preposition, that creates a particular meaning**.

Examples:
```
call off = cancel
carry out = perform
put off = postpone
look into = investigate
hand in = submit
bring up = mention
turn down = reject
set up = establish
take over = assume control
look after = take care of
```
The entire combination acts as the verb.

#### 2. The basic passive rule

When a phrasal verb becomes passive: **Keep the particle/preposition with the verb**.

Example
```
Active:  They called off the meeting.
Passive: The meeting was called off.
- The particle off remains.
```

#### 3. Call off = cancel.

```
Active:  They called off the match.
Passive: The match was called off.

Active:  They have called off the meeting.
Passive: The meeting has been called off.

Active:  They will call off the event.
Passive: The event will be called off.
```

Notice that the tense changes normally, but off remains attached to the phrasal verb.

#### 4. Carry out = perform or execute.

```
Active:  The scientists carried out an experiment.
Passive: An experiment was carried out by the scientists.

Active:  They will carry out the investigation.
Passive: The investigation will be carried out.
```

#### 5. Look into = investigate.

```
Active: The police are looking into the complaint.
Passive: The complaint is being looked into by the police.
- Notice "looked into" not "looked"
```
The preposition into stays.

#### 6. Look after = take care of.

```
Active:  She looks after the children.
Passive: The children are looked after by her.

Active:  Someone must look after the patient.
Passive: The patient must be looked after.
```
The final preposition is not removed.

#### 7. Hand in = submit.

```
Active:  Ravi handed in the report.
Passive: The report was handed in by Ravi.

Active:  Please hand in your assignments.
Passive: Your assignments should be handed in.
```

#### 8. Put off = postpone.

```
Active:  They put off the meeting.
Passive: The meeting was put off.

Active: They have put off the event.
Passive: The event has been put off.
```

#### 9. Turn down = reject or reduce.

**Meaning 1 - Reject**
```
Active:  They turned down my application.
Passive: My application was turned down.
```

**Meaning 2 - Reduce volume/level**
```
Active:  He turned down the volume.
Passive: The volume was turned down.
```
The same phrasal verb can have different meanings depending on context.

#### 10. Set up = establish/arrange.

```
Active:  They set up a new company.
Passive: A new company was set up.

Active:  They have set up the equipment.
Passive: The equipment has been set up.
```

#### 11. Separable phrasal verbs

Some phrasal verbs can separate their verb and particle.

Example:
```
They called off the meeting.
or:
They called the meeting off.
```
But when the object becomes the subject of the passive sentence, the normal passive form keeps the particle after the V3:
```
The meeting was called off.
Not:
The meeting was off called.
```

#### 12. Prepositional verbs

Not every `verb + preposition` combination is technically a phrasal verb.

Examples:
```
talk about
listen to
depend on
believe in
refer to
deal with
```
These can also form passive constructions.

Example: 

talk about
```
Active:  They talked about the problem.
Passive: The problem was talked about.
- The preposition about remains.
```

Listen to
```
Active:  Everyone listened to the speaker.
Passive: The speaker was listened to by everyone.
```
Refer to
```
Active:  The report refers to several problems.
Passive: Several problems are referred to in the report.
```

#### 13. `Deal with`

```
Active:  The manager dealt with the complaint.
Passive: The complaint was dealt with by the manager.

- Do not remove with.
Incorrect: The complaint was dealt by the manager.
Correct:   The complaint was dealt with by the manager.
```

#### 14. `Depend on`

This one needs special attention.
```
Active:  The result depends on several factors.
- We normally do not force this into a passive construction.
- Why?
- Because depend on does not work like an ordinary transitive verb where the object naturally becomes the subject.
- So, "The result depends on several factors." is normally left active.
```

This illustrates an important principle: <br/>
**Not every `verb + preposition` combination has a natural passive form.**

#### 15. Prepositional passive

Some prepositional verbs have very natural passive forms.

Examples:
```
Active:  They laughed at him.
Passive: He was laughed at.

Active:  Someone has taken care of the child.
Passive: The child has been taken care of.

Active:  They are looking for the missing document.
Passive: The missing document is being looked for.

Active:  People often talk about this problem.
Passive: This problem is often talked about.
```
These may sound slightly more formal than their active counterparts, but they are grammatical.

#### 16. Questions with phrasal/prepositional verbs

The same principle applies to questions.
```
Active:  Who did they talk about?
Passive: Who was talked about?

Active:  Which problem did they look into?
Passive: Which problem was looked into?

Active:  Who did they look after?
Passive: Who was looked after?
```
Notice that the preposition remains where the construction requires it.

#### 17. Negative sentences

```
Active:  They did not call off the meeting.
Passive: The meeting was not called off.

Active:  They haven't looked into the complaint.
Passive: The complaint hasn't been looked into.

Active: They won't put off the event.
Passive: The event won't be put off.
```
The negative auxiliary follows the normal passive rules.

#### 18. Modal verbs

```
Active:  They must carry out the instructions.
Passive: The instructions must be carried out.

Active:  Someone should look after the children.
Passive: The children should be looked after.

Active:  They can deal with the problem.
Passive: The problem can be dealt with.
```
Formula: `Modal + be + V3 + particle/preposition`

#### 19. A very important distinction between Ordinary verb, Phrasal verb, Prepositional verb

**Ordinary verb**
```
Active:  They repaired the car.
Passive: The car was repaired.
```
**Phrasal verb**
```
Active:  They called off the meeting.
Passive: The meeting was called off.
```
**Prepositional verb**
```
Active:  They looked after the child.
Passive: The child was looked after.
```

> Key point: **Treat the complete verb expression as one unit.**

<details>
  <summary> <b> Passive Voice with Negative Pronouns </b> </summary>

<br/>

We'll learn how to change sentences containing `nothing, nobody, no one, neither, none, and not…anything` into passive voice without changing their meaning.

#### 1. The basic rule

When a negative word is the object of an active sentence, it can often become the subject of the passive sentence.

**Active: `Subject + negative word + verb + object (or negative object)`** <br/>
**Passive: `Negative word + appropriate form of be + V3`**

Example:
```
Active: They found nothing.
Passive: Nothing was found.
```
The tense remains the same, and the negative meaning must be preserved.

#### 2. Using `nothing`

When `nothing` is the object of a verb, it can become the subject of the passive sentence.

| Active Voice              | Passive Voice                  |
|---------------------------|--------------------------------|
| They found nothing.       | Nothing was found.             |
| She said nothing.         | Nothing was said by her.       |
| They have done nothing.   | Nothing has been done.         |
| Nobody can do anything.   | Nothing can be done by anybody.|
| They will change nothing. | Nothing will be changed.       |

Notice how the auxiliary verb changes according to the tense: <br/>
Past simple: `was/were + V3` <br/>
Present perfect: `has/have been + V3` <br/>
Modal: `modal + be + V3` <br/>
Future simple: `will be + V3` <br/>

#### 3. Using `nobody` and `no one`

When `nobody` or `no one` is the subject of an active sentence, the passive commonly uses `not…anyone, nobody, or no one`, depending on the sentence.

| Active Voice                    | Passive Voice                              |
|---------------------------------|--------------------------------------------|
| Nobody opened the door.         | The door was not opened by anyone.         |
| No one invited Ravi.            | Ravi was not invited by anyone.            |
| Nobody has solved the problem.  | The problem has not been solved by anyone. |
| No one can answer this question.| This question cannot be answered by anyone.|

In standard English, avoid double negatives such as `The door wasn't opened by nobody` when you mean that nobody opened it. <br/>
Correct: `The door wasn't opened by anyone`.

#### 4. Using `neither`

`Neither` means not one and not the other of two things or people.

When it refers to the object of an active sentence, it can become the subject of the passive.

| Active Voice                          | Passive Voice                                |
|---------------------------------------|----------------------------------------------|
| They accepted neither proposal.       | Neither proposal was accepted.               |
| The manager approved neither request. | Neither request was approved by the manager. |
| She completed neither task.           | Neither task was completed by her.           |
| They selected neither candidate.      | Neither candidate was selected.              |

#### 5. Using `none` and `no + noun`

**A. None**

`None` means not one or not any of a group.
```
Active: The team completed none of the tasks.
Passive: None of the tasks were completed by the team.
```
You may also see "`None of the tasks was completed`" when treating the tasks as a group or in more formal usage. Plural agreement is very common when referring to multiple countable items.

**B. No + noun**

The word `no` can appear before a noun.
```
Active: They issued no tickets.
Passive: No tickets were issued.

Active: The committee made no decision.
Passive: No decision was made.

Active: The company provided no explanation.
Passive: No explanation was provided.
```
Here, the whole noun phrase `no tickets, no decision, or no explanation` becomes the subject.

#### 6. `Not…anything` vs `nothing`

These structures often express the same meaning.

|  Active Voice                    | Passive Voice               |
|----------------------------------|-----------------------------| 
| They didn't find anything.       | Nothing was found.          |
| They didn't repair anything.     | Nothing was repaired.       |
| They haven't announced anything. | Nothing has been announced. |
| They won't change anything.      | Nothing will be changed.    |

Both forms preserve the negative meaning, but the passive with nothing places stronger 
emphasis on the thing affected or on the absence of a result.

#### 7. Common mistakes

```
Incorrect: Nobody was not invited.
Correct:   Nobody was invited. / No one was invited.

Incorrect: Nothing did found.
Correct:   Nothing was found.

Incorrect: Neither proposal were accepted.
Correct:   Neither proposal was accepted.

Incorrect: No tickets was issued.
Correct:   No tickets were issued.
```

Note: **After changing the object into the subject, choose the correct be verb to match the new subject and tense.**

Exercise
```
Active:  They found nothing.
Passive: Nothing was found.

Active:  Nobody has completed the assignment.
Passive: The assignment has not been completed by anyone.

Active:  The manager rejected neither application.
Passive: Neither application was rejected by the manager.

Active:  They issued no warnings.
Passive: No warnings were issued.

Active:  They didn't announce anything.
Passive: Nothing was announced.
```

#### Quick revision

**`Nothing`** -> Nothing was done.

**`Nobody / No one`** -> The work was not done by anyone.

**`Neither + singular noun`** -> Neither application was accepted.

**`None of + plural noun`** -> None of the tasks were completed.

**`No + noun`** -> No tickets were issued.

**`Not…anything`** -> Nothing, in a suitable passive transformation.

<details>
  <summary> <b> Passive Voice with Double Objects and Complex Structures </b> </summary>

<br/>

We'll learn how to convert sentences containing **two objects**, as well as sentences where the object is followed by additional information.


#### 1. What are double objects?

Some verbs can take two objects:

**Indirect object (IO)**: The person who receives something.

**Direct object (DO)**: The thing that is given, sent, shown, or taught.

Example:
```
Active: Ravi gave me a book.
- Subject = Ravi
- Verb = gave
- Indirect object  = me
- Direct object = a book

"Me" tells us who received something.
"A book" tells us what was given.
```

#### 2. Two ways to form the passive

When a verb allows both passive structures, either object can become the subject.
```
Active: Ravi gave me a book.
Passive 1: I was given a book by Ravi.
- The indirect object "me" becomes I.
Passive 2: A book was given to me by Ravi.
- The direct object "a book" becomes the subject.
- The preposition to is added.
```
Both sentences are grammatically correct. The first is often more natural when the recipient is important.

The formula

**Pattern A - Indirect object becomes subject** <br/>
`Indirect object + appropriate be + V3 + direct object`.

**Pattern B - Direct object becomes subject** <br/>
`Direct object + appropriate be + V3 + to/for + indirect object`.

Remember to change pronouns correctly when they become subjects.
```
us -> We
me -> I,
him -> he,
her -> she,
them -> they 
```

#### 3. Verbs that commonly allow two passive forms


| Active sentence             | Passive using recipient    | Passive using thing          |
|-----------------------------|----------------------------|------------------------------|
| She sent me a letter.       | I was sent a letter.       | A letter was sent to me.     |
| They taught us English.     | We were taught English.    | English was taught to us.    |
| He showed her the picture.  | She was shown the picture. | The picture was shown to her.|
| My father bought me a gift. | I was bought a gift.       | A gift was bought for me.    |
| She made him a cake.        | He was made a cake.        | A cake was made for him.     |

Note: **We can omit `by + agent` when the agent is already clear or unimportant.**

Notice the prepositions: These are useful patterns, not universal rules for every verb. <br/>
`To` is common with `give, send, show, teach, and offer`. <br/>
`For` is common with `buy, make, cook, and prepare` when something is done for someone.

#### 4. Important exception: not every verb allows both forms

```
Active: The teacher explained the problem to me.
Natural passive: The problem was explained to me by the teacher.
We generally do not say: I was explained the problem by the teacher.
- Why?
-Because explain normally takes the thing being explained as its direct object,
followed by to and the recipient.


Active: She described the incident to us.
Passive: The incident was described to us.

Active: He mentioned the issue to me.
Passive: The issue was mentioned to me.

Active: They reported the problem to the manager.
Passive: The problem was reported to the manager.
```

#### 5. Passive voice with object + complement

Sometimes the object is followed by a word or phrase that describes it or gives it a new status. This is called an **object complement**.

Example:
```
Active: They elected Ravi captain.
- Subject: They
- Verb: elected
- Object: Ravi
- Object complement: captain
Passive: Ravi was elected captain.

Active:  They made him the leader.
Passive: He was made the leader.

Active:  The committee named her chairperson.
Passive: She was named chairperson.

Active:  They painted the door red.
Passive: The door was painted red.

Active:  Everyone considered him honest.
Passive: He was considered honest.

Active:  They found the room empty.
Passive: The room was found empty.

- The complement remains because it completes the meaning of the sentence.
```
Do not automatically add `by + agent` if it sounds unnecessary.

#### 6. Passive voice with `object + infinitive`

Some verbs take an object followed by `to + V1`.
```
Active: They asked Ravi to complete the task.
Passive: Ravi was asked to complete the task.
- Here, only the main clause changes to passive.
- Ravi still performs the action of completing the task.

Active:  They advised her to rest. 
Passive: She was advised to rest.

Active:  They ordered him to leave. 
Passive: He was ordered to leave.

Active:  They encouraged us to participate.  
Passive: We were encouraged to participate.

Active:  They warned him not to touch it. 
Passive: He was warned not to touch it.
```
We can notice that `to + V1` remains unchanged after the passive reporting verb.

#### 7. Negative and interrogative forms

**Negative sentence**
```
Active: They did not give me the documents.
Passive option1: I was not given the documents.
Passive option2: The documents were not given to me.
```

**Question**
```
Active: Did they offer you a job?
Passive option1: Were you offered a job?
Passive option2: Was a job offered to you?
```

**WH-question**
```
Active:  Why did they give Ravi a prize?
Passive: Why was Ravi given a prize?
```
The tense and question structure must remain correct.


#### Practice 

Exercise:
```
Active:   The principal gave the student a certificate.
Passive1: The student was given a certificate by the principal.
Passive2: A certificate was given to the student by the principal.

Active:  She explained the rules to us.
Passive: The rules were explained to us by her.

Active:  They appointed Priya team leader.
Passive: Priya was appointed team leader.

Active:  The coach encouraged the players to practise.
Passive: The players were encouraged to practise by the coach.

Active:   Did the company offer him a position?
Passive1: Was he offered a position by the company?
Passive2: Was a position offered to him by the company?
```

#### Final revision

1. Some verbs with two objects allow **two passive forms**.

2. Use `to` or `for` when the direct object becomes the passive subject, depending on the verb.

3. Verbs such as `explain, describe, and mention` usually keep the thing as the passive subject.

4. With object complements, retain the complement:
```
They elected Ravi captain.
Ravi was elected captain.
```

5. With `object + infinitive`, the main verb changes to passive while the infinitive often remains active:
```
They asked Ravi to leave.
Ravi was asked to leave.
```

<details>
  <summary> <b> Passive Voice with Prepositions, Infinitives and Gerunds </b> </summary>

<br/>

We'll revise three important structures that often confuse learners:
1. Passive voice with prepositions.
2. Passive infinitives.
3. Passive gerunds.

The goal is to understand how to recognize the structure and change it without changing the meaning.

#### 1. Passive voice with prepositions

Some verbs are followed by a preposition. When we change these sentences into passive voice, **the preposition usually stays with the verb**.

Examples:
| Active Voice                      | Passive Voice                            |
|-----------------------------------|------------------------------------------|
| They laughed at Ravi.             | Ravi was laughed at.                     |
| She looks after the children.     | The children are looked after by her.    |
| They dealt with the problem.      | The problem was dealt with.              |
| Someone has stolen my bag.        | My bag has been stolen.                  |
| They talked about the incident.   | The incident was talked about.           |
| Everyone listened to the speaker. | The speaker was listened to by everyone. |

**Why does the preposition remain?**

```
Active: They looked after the child.
- The expression is look after, meaning to take care of someone.
Passive: The child was looked after.
- We cannot remove after because it is part of the verb expression.

Call off - The meeting was called off.
Look into - The complaint was looked into.
Put up with - The behaviour was put up with.
Speak to - The manager was spoken to.
```

> **Rule: Move the object to the subject position, use the appropriate form of `be(is/am/are) + V3`, and retain the necessary preposition or particle.**

#### 2. Passive infinitives

An infinitive usually uses `to + V1`.

Example:
```
to write
to complete
to repair
```
**A passive infinitive uses: `to be + V3`**

| Active infinitive | Passive infinitive |
|-------------------|--------------------|
| to write          | to be written      |
| to complete       | to be completed    |
| to repair         | to be repaired     |
| to select         | to be selected     |
| to deliver        | to be delivered    |

| Sentence                                   | Explanation       |
|--------------------------------------------|-------------------|
| I want to complete the work.               | Active infinitive |
| I want the work to be completed.           | Passive infinitive|
| The report needs to be checked.            | Passive infinitive|
| The task is expected to be finished today. | Passive infinitive|
| The documents are ready to be signed.      | Passive infinitive|

**Perfect passive infinitive** <br/>
When the action happened before the time being discussed, we can use: `to have been + V3`

Examples:
```
He seems to have been selected.
The document appears to have been signed.
The project is believed to have been completed.

The report is expected to be completed.        -  Completion is expected.
The report is believed to have been completed. - Completion is believed to have already happened.
```

#### 3. Passive gerunds

A gerund is a verb ending in `-ing` that functions like a noun.

Examples:
```
reading
writing
completing
```
**The passive gerund uses: `being + V3`**

| Active gerund | Passive gerund   |
|---------------|------------------|
| writing       | being written    |
| checking      | being checked    |
| criticizing   | being criticized |
| selecting     | being selected   |
| repairing     | being repaired   |

```
He hates being criticized
She enjoys being appreciated.
The document needs being checked. (Not the usual standard construction.)
- The document needs checking.
Or:
- The document needs to be checked.
He is afraid of being judged.
They discussed being transferred to another office.
```
We can notice that a **passive gerund often follows verbs or prepositions** that naturally take an -ing form.

#### 4. Perfect passive gerund

The perfect passive gerund uses: `having been + V3`

It emphasizes an action that was completed before another event.

Examples:
```
He denied having been informed about the change.
She was proud of having been selected.
They complained about having been ignored.

He denied being informed.       - Focuses on being informed.
He denied having been informed. - Emphasizes an earlier event.
```
The perfect form is useful, but it is not always necessary. Context often makes the sequence of events clear.

#### 5. How to choose the correct structure

**Passive infinitive: `to be + V3`** <br/>
Example: `The report needs to be submitted.`

**Perfect passive infinitive: `to have been + V3`** <br/>
Example: `The report seems to have been submitted.`

**Passive gerund: `being + V3`** <br/>
Example: `He dislikes being interrupted.`

**Perfect passive gerund: `having been + V3`** <br/>
Example: `She remembered having been warned.`

#### 6. Practice

Exercise:
```
They are looking into the complaint.
The complaint is being looked into.

I want someone to check this report. Rewrite using a passive infinitive.
I want this report to be checked.

He dislikes people interrupting him. Rewrite using a passive gerund.
He dislikes being interrupted.

The document seems to have been signed. Identify the passive structure.
Perfect passive infinitive: to have been + V3.

They spoke to the manager. Change to passive.
The manager was spoken to.
```

#### Quick revision

1. Prepositional verbs: **was laughed at, was looked after**.

2. Passive infinitive: **`to be + V3`**.

3. Perfect passive infinitive: **`to have been + V3`**.

4. Passive gerund: **`being + V3`**.

5. Perfect passive gerund: **`having been + V3`**.

6. Always retain the necessary preposition and use the correct V3 form.

<details>
  <summary> <b> Mixed Tenses and Mixed Structures in Passive Voice </b> </summary>

<br/>

Until now, we've studied individual tenses and structures. <br/>
Now, we'll combine them so you can identify the correct passive form even when different sentence types appear together.

#### 1. The master formula

The most important rule is: **Passive voice = appropriate form of `BE + V3`**

The form of `BE` depends on the tense, aspect, and modal verb.

| Active tense       | Passive structure      | Example                            |
|--------------------|------------------------|------------------------------------|
| Present simple     | am/is/are + V3         | The work is completed.             |
| Past simple        | was/were + V3          | The work was completed.            |
| Future simple      | will be + V3           | The work will be completed.        |
| Present continuous | am/is/are + being + V3 | The work is being completed.       |
| Past continuous    | was/were + being + V3  | The work was being completed.      |
| Present perfect    | has/have + been + V3   | The work has been completed.       |
| Past perfect       | had + been + V3        | The work had been completed.       |
| Future perfect     | will have been + V3    | The work will have been completed. |
| Modal              | modal + be + V3        | The work must be completed.        |
| Modal perfect      | modal + have been + V3 | The work must have been completed. |

#### 2. Mixed-tense transformations

Look carefully at how the tense changes the auxiliary verbs.
```
Active: The manager checks the reports.                [Present simple]
Passive: The reports are checked by the manager.

Active: The manager was checking the reports.          [Past continuous]
Passive: The reports were being checked by the manager.

Active: The manager has checked the reports.           [Present perfect]
Passive: The reports have been checked by the manager.

Active: The manager will check the reports.             [Future simple]
Passive: The reports will be checked by the manager.
```
Notice that reports is plural, so we use `are, were, and have` in the corresponding examples.

#### 3. Mixed negatives and questions

A negative sentence remains negative after conversion. A question remains a question.

| Active Voice                       | Passive Voice                      |
|------------------------------------|------------------------------------|
| They do not sell these products.   | These products are not sold.       |
| Did Ravi complete the task?        | Was the task completed by Ravi?    |
| Have they announced the result?    | Has the result been announced?     |
| Why did they cancel the meeting?   | Why was the meeting cancelled?     |
| Will they invite the candidates?   | Will the candidates be invited?    |
| They should not ignore the warning.| The warning should not be ignored. |

Note: **Do not carry `do, does, or did` into the passive form. Instead, use the correct form of `BE(is/am/are/was/were)`.**

#### 4. Mixed modals and perfect structures

Modal verbs often appear in sentences that look complicated but follow predictable patterns.

| Active Voice                              | Passive Voice                           |
|-------------------------------------------|-----------------------------------------|
| They must finish the work.                | The work must be finished.              |
| They should have informed us.             | We should have been informed.           |
| Someone may have stolen the file.         | The file may have been stolen.          |
| They could be repairing the road.         | The road could be being repaired.       |
| They might announce the results tomorrow. | The results might be announced tomorrow.|

The sentence `The road could be being repaired` is grammatically possible, but it sounds awkward. <br/>
A more natural alternative is `The road may be under repair.`

Note: **Grammatical transformations are not always the most natural way to communicate.**


#### 5. Mixed structures with infinitives and reporting verbs

Now let's combine the structures from previous lessons.

**A. Infinitive**
```
Active: They expect the team to finish the project.
Passive: The team is expected to finish the project.

- Here, the team is the subject of the passive main clause,
- but to finish remains active because the team performs the action.
```

**B. Passive infinitive**
```
Active: They expect someone to finish the project.
Passive: The project is expected to be finished.

- Here, the project is the thing that receives the action, so we use to be + V3.
```

**C. Reporting verb**
```
Active: People believe that she won the competition.
Passive: It is believed that she won the competition.

Alternative: She is believed to have won the competition.
```
The second version uses a perfect infinitive because the winning happened before the present belief.

####  6. Mixed clauses

In complex sentences, change the appropriate clause while preserving the conjunction and the original meaning.

| Active Voice                                              | Passive Voice                                         |
|-----------------------------------------------------------|-------------------------------------------------------|
| They cancelled the match because it was raining.          | The match was cancelled because it was raining.       |
| They will publish the report when they finish it.         | The report will be published when it is finished.     |
| They have repaired the road that connects the villages.   | The road that connects the villages has been repaired.|
| If they approve the proposal, they will start the project.| If the proposal is approved, the project will be started. |

In the final example, both clauses change to passive. However, you do not need to change every clause in every complex sentence. Change only the clause or clauses required by the task.

#### 7. A five-step method for any mixed sentence

1. **Find the object**. Identify what receives the action. If there is no suitable object, an ordinary passive may not be possible.

2. **Identify the tense**. Check whether the active verb is simple, continuous, perfect, or future.

3. **Choose the passive auxiliary**. Use the appropriate form of BE, with being or been where required.

4. **Use V3**. The main verb in the passive must be in its past participle form.

5. **Check the meaning**. Preserve negatives, questions, modals, time references, and necessary prepositions.

#### 8. Practice test

```
They have not completed the project.
The project has not been completed.

Were they repairing the bridge?
Was the bridge being repaired by them?

Someone must have deleted the file.
The file must have been deleted.

They expect Ravi to submit the application.
Ravi is expected to submit the application.

Why will they postpone the event?
Why will the event be postponed?

People say that he has left the company.
It is said that he has left the company.
He is said to have left the company.

They are looking after the injured bird.
The injured bird is being looked after.
```

#### Final revision

Simple passive: `BE + V3`

Continuous passive: `BE + being + V3`

Perfect passive: `have + been + V3`

Modal passive: `modal + be + V3`

Modal perfect passive: `modal + have been + V3`

Passive infinitive: `to be + V3`

Reporting verbs: `It is said that… / He is said to…`

Prepositional verbs: keep the necessary preposition.

<details>
  <summary> <b> Advanced Transformations and Tricky Cases in Passive Voice </b> </summary>

<br/>

So far, we've learned how to change most common active sentences into passive voice.
Now we'll focus on tricky sentences where changing the voice requires more than simply moving the object to the beginning.

#### 1. When the object becomes the subject, the meaning must remain the same

```
Active: Everyone considers Ravi intelligent.
Passive: Ravi is considered intelligent by everyone.
- Notice that intelligent remains in the sentence.
- It describes Ravi, so removing it would change the meaning.
```

Examples:
| Active Voice                           | Passive Voice               |
|----------------------------------------|-----------------------------|
| They found the room empty.             | The room was found empty.   |
| People consider her honest.            | She is considered honest.   |
| They elected him president.            | He was elected president.   |
| The committee declared the match over. | The match was declared over.|

Rule: **When the object has a complement, retain that complement if it is necessary to preserve the meaning**.

#### 2. Sentences with two verbs

Sometimes a sentence contains a main verb followed by another verb. You must identify which action is being made passive.

**Example A: The main clause changes**
```
Active: They asked Ravi to complete the assignment.
Passive: Ravi was asked to complete the assignment.
- Here, asked becomes passive.
- Ravi still performs the action of completing the assignment.
```

**Example B: The second action changes**
```
Active: They wanted someone to complete the assignment.
Passive: They wanted the assignment to be completed.
Here, the assignment becomes the subject of the passive infinitive.

Compare these carefully:

Ravi was asked to complete the assignment.
They wanted the assignment to be completed.
- The first uses an active infinitive;
- the second uses a passive infinitive.
```

#### 3. Verbs of perception: see, hear, watch and notice

These verbs follow special patterns.

When an active sentence uses an object followed by the base verb, the passive often introduces to.

| Active Voice                   | Passive Voice                    |
|--------------------------------|----------------------------------|
| I saw Ravi cross the road.     | Ravi was seen to cross the road. |
| They heard her sing.           | She was heard to sing.           |
| We watched him enter the room. | He was watched to enter the room.|

However, the last example sounds less natural than many alternatives. 
For a specific event, `He was seen to enter the room` is generally more idiomatic.

When the active sentence uses an `-ing` form, that form can remain:
```
Active: I saw Ravi crossing the road.
Passive: Ravi was seen crossing the road.

Active: They heard her singing.
Passive: She was heard singing.
```

Remember: With make, the passive also introduces to:
```
Active: They made Ravi apologize.
Passive: Ravi was made to apologize.
```
But let usually changes to be allowed to:
```
Active: They let Ravi enter.
Passive: Ravi was allowed to enter.
```

####  4. When the agent should be omitted

In passive voice, the person performing the action is called the **agent**.

We often omit the agent when it is unknown, unimportant, obvious, or unnecessary.

| With agent                                | Without agent                |
|-------------------------------------------|------------------------------|
| The window was broken by someone.         | The window was broken.       |
| English is spoken by people worldwide.    | English is spoken worldwide. |
| The thief was arrested by the police.     | The thief was arrested.      |
| The results were announced by the school. | The results were announced.  |

The shorter form is often more natural. <br/>
Do not force `by + agent` into every passive sentence.

#### 5. Sentences that cannot normally be changed into passive

A standard passive construction generally requires a suitable object.

**Intransitive verbs**
```
Active: The baby slept.
Passive: No natural passive form.

Active: The guests arrived.
Passive: No natural passive form.

Active: The sun rose.
Passive: No natural passive form.
```
These sentences do not have a direct object that can become the passive subject.

**Linking verbs**
```
Active: She became a doctor.
Passive: No natural passive form.

Active: He seems tired.
Passive: No natural passive form.
```
These verbs describe a state, identity, or condition rather than an action performed on an object.

Important distinction: A verb may be intransitive in one sentence but transitive in another.
```
The door opened.         - No ordinary passive.
Someone opened the door. - The door was opened.
```

#### 6. Passive meaning without passive grammar

Some sentences have passive meaning even though their verb form is active.

Examples:
```
This book is easy to read.
The problem is difficult to solve.
The food is ready to eat.
The instructions are simple to follow.
```
These are correct as written. <br/>
Avoid automatically changing them to easy to be read or difficult to be solved.

The grammatical structure is active, but the meaning focuses on what can be done to the subject.


#### 7. The tricky difference between `is closed` and `is being closed`

**A. `The shop is closed.`**

This usually describes the shop's current state. Closed may function as an adjective.

**B. `The shop is being closed.`**
This describes an action currently taking place. It is present continuous passive.

**C. `The shop was closed by the manager.`**

This normally describes an action performed by the manager, in the past simple passive.

Context matters. <br/>
For example, `The shop was closed when I arrived` may describe its state at that time, rather than explicitly identifying who closed it.

#### 8. Advanced exam traps

Here are some common transformations that learners get wrong.

| Active sentence                | Correct passive               | Common mistake               |
|--------------------------------|-------------------------------|------------------------------|
| They made him leave.           | He was made to leave.         | ~~He was made leave.~~       |
| Someone has stolen my phone.   | My phone has been stolen.     | ~~My phone has stolen.~~     |
| They are repairing the road.   | The road is being repaired.   | ~~The road is repaired.~~    |
| They explained the rule to me. | The rule was explained to me. | ~~I was explained the rule.~~|
| People say he is honest.       | He is said to be honest.      | ~~He said to be honest.~~    |

Note: **The key is to identify the complete grammatical structure before changing the voice.**

#### 9. Practice test

```
Active:  They made the students rewrite the essay.
Passive: The students were made to rewrite the essay.

Active:  People believe that the scientist discovered a new element.
Passive: It is believed that the scientist discovered a new element.
Passive: The scientist is believed to have discovered a new element.

Active:  They found the door unlocked.
Passive: The door was found unlocked.

Active: The children are playing in the garden.
- There is no natural ordinary passive transformation.

Active:  I saw Ravi enter the building.
Passive: Ravi was seen to enter the building.

Active:  This problem is easy to solve.
- No change is needed.
- already has the correct active infinitive with passive meaning.
```

#### Final revision

Before changing any difficult sentence into passive voice, ask yourself:

1. Does the sentence have a suitable object?
2. Which action or clause should become passive?
3. Does the verb require a special structure, such as `to + V1`?
4. Must I retain an object complement or preposition?
5. Would the resulting sentence preserve the original meaning and sound natural?

<details>
  <summary> <b> Common Passive Voice Mistakes in Exams and Interviews </b> </summary>

<br/>

**Knowing the rules is not enough** - we must also be able to **identify and correct mistakes quickly**.

#### 1. Mistake: Using V2 instead of V3

Passive voice requires the **past participle (V3)**, **not the simple past (V2)**.

| Incorrect                 | Correct                     |
|---------------------------|-----------------------------|
| The letter was ~~wrote~~. | The letter was **written**. |
| The work was ~~did~~.     | The work was **done**.      |
| The window was ~~broke~~. | The window was **broken**.  |
| The food was ~~ate~~.     | The food was **eaten**.     |

**Rule: After the passive auxiliary, use V3.**

#### 2. Mistake: Forgetting `being` in continuous tenses

| Incorrect                   | Correct                           |
|-----------------------------|-----------------------------------|
| The road is repaired now. <br/> (if an action is happening now) | The road is being repaired now. |
| The house was painting.     | The house was being painted.      |
| The documents are checking. | The documents are being checked.  |

**Present continuous passive: `am/is/are + being + V3`** <br/>
**Past continuous passive: `was/were + being + V3`**

Be careful: `The road is repaired` can be correct when describing a completed repair or a general condition, depending on context.

#### 3. Mistake: Forgetting “been” in perfect tenses

| Incorrect                   | Correct                          |
|-----------------------------|----------------------------------|
| The work has completed. <br/> (when the intended meaning is passive)| The work has been completed. |
| The letter had written.     | The letter had been written.     |
| The results have announced. | The results have been announced. |

**Present perfect passive: `has/have + been + V3`** <br/>
**Past perfect passive: `had + been + V3`**

#### 4. Mistake: Using the wrong form of `be`

The form of be must agree with the new subject.

| Incorrect                           | Correct                             |
|-------------------------------------|-------------------------------------|
| The books ~~is~~ arranged.          | The books **are** arranged.         |
| The student ~~were~~ selected.      | The student **was** selected.       |
| The results ~~has~~ been announced. | The results **have** been announced.|


#### 5. Mistake: Keeping “do, does, or did”

In ordinary active questions and negatives, these auxiliaries often disappear when converted into passive voice.

| Active Voice                | Passive Voice                    |
|-----------------------------|----------------------------------|
| Did Ravi write the letter?  | Was the letter written by Ravi?  |
| They do not sell milk here. | Milk is not sold here.           |
| Does she teach English?     | Is English taught by her?        |
 
Do not write `Did the letter was written?` or `Milk does not sold here`.

#### 6. Mistake: Forgetting to change pronouns

When an object becomes the subject, its pronoun form changes.

| Object form | Subject form |
|-------------|--------------|
| me          | I            |
| him         | he           |
| her         | she          |
| us          | we           |
| them        | they         |
| whom        | who          |

Example:
```
Active: Ravi helped me.
Passive: I was helped by Ravi.
Not: Me was helped by Ravi.
```

#### 7. Mistake: Changing the tense accidentally

The tense should be preserved during a direct transformation.
```
Active: They are building a bridge.
Passive: A bridge is being built.     [Correct]
Passive: A bridge was built.          [Incorrect]
- The last sentence changes the time reference.
```

#### 8. Mistake: Forgetting the preposition

Some verbs require a preposition or particle even in passive voice.

| Active Voice                | Correct Passive             |
|-----------------------------|-----------------------------|
| They laughed at him.        | He was laughed at. <br/> He was laughed. [Incorrect]    |
| She looked after the child. | The child was looked after. |
| They called off the meeting.| The meeting was called off. |
| They dealt with the issue.  | The issue was dealt with. <br/> The issue was dealt. [Incorrect]  |

#### 9. Mistake: Using passive with an intransitive verb

A normal passive transformation usually requires a direct object.
```
Active: The baby slept.
Passive: No ordinary passive form.

Active: The guests arrived.
Passive: No ordinary passive form.

But compare:

Active: Someone opened the door.
Passive: The door was opened.
- The second active sentence has an object: "the door".
```

#### 10. Mistake: Forgetting `to` after certain verbs in passive voice

Some verbs take a bare infinitive in the active voice but require to in the passive.

| Active Voice              | Passive Voice                  |
|---------------------------|--------------------------------|
| They made him apologize.  | He was made to apologize.      |
| I saw him cross the road. | He was seen to cross the road. |
| They let her enter.       | She was allowed to enter.      |

Note: **Remember the special patterns for `make`, perception verbs, and `let`.**

#### 11. Mistake: Using the wrong passive structure with two objects

Some verbs allow two passive forms, but not every verb does.

```
Active: She gave me a book.
Passive: I was given a book.
Passive: A book was given to me.

However:

Active: She explained the problem to me.
Passive: The problem was explained to me. [Preferred]
Passive: I was explained the problem      [Generally not appropriate]
- In standard English, It is generally not the appropriate transformation.
```

#### 12. Mistake: Incorrect modal passive

**The standard structure is: `modal + be + V3`**

Examples:
```
Active: You must complete the form.
Passive: The form must be completed.

Active: They should follow the rules.
Passive: The rules should be followed.
```

For **modal perfect passive: `modal + have been + V3`**

Example:
```
Active: Someone may have stolen the bag.
Passive: The bag may have been stolen.
```

#### 13. Mistake: Creating double negatives

Avoid adding a second negative when the first already expresses the intended negative meaning.
```
Active:  Nobody opened the door.
Passive: The door was not opened by anyone. [Correct]
Passive: The door was opened by nobody.     [Correct]
- although this sounds less natural in many contexts.

Avoid: The door wasn't opened by nobody when you mean that nobody opened it.
```

#### 14. Mistake: Making every passive sentence include `by`

The **agent is optional when it is unknown, obvious, or unimportant**.

```
Active:  Someone stole my phone.
Passive: My phone was stolen.     [Natural]

Active:  People speak English worldwide.
Passive: English is spoken worldwide. [Natural]
```
**Use `by + agent` when the identity of the person or group performing the action matters.**


#### 15. Mistake: Forcing an unnatural passive

Some sentences have passive meaning without requiring passive grammar.

```
This book is easy to read. 
- This book is easy to be read [Unnatural in standard English.]

The problem is difficult to solve.
- The problem is difficult to be solved. [Unnatural in standard English.]

The food is ready to eat.
- The food is ready to be eaten. [Unnatural in standard English.]
```

The objective is not merely to produce a passive sentence; <br/>
it is to preserve meaning and use natural English.

<br/>

To identify Active/Passice statement ask **Who is doing the action?**
- If the **subject is doing the action**: **`Active Voice`**
- If the **subject is receiving the action**: **`Passive Voice`**

```

The cat was chased by the dog.
- Who receives the action? -> The cat -> Passive

<details>
  <summary> <b> Golden Formula </b> </summary>

<br/>

```
 ACTIVE : Subject + Verb + Object
                     ↓ 
PASSIVE : Object + Helping Verb + V3 + by + Subject
```

`The boy opens the door.`
1. Subject? -> The boy
2. Verb? -> opens
3. Object? -> the door
4. Bring object forward -> The door...
5. Helping verb? -> is
6. V3? -> opened
7. Add by + subject -> by the boy

`The door is opened by the boy.`

<details>
  <summary> <b> Rules: Active to Passve </b> </summary>

<br/>

### 1. The tense does not disappear

When changing active to passive, the tense remains the same.

**Present -> is/am/are + V3** <br/>
**Past -> was/were + V3** <br/>
**Future -> will be + V3** <br/>

```
Present
Active:  Ravi writes a letter.
Passive: A letter is written by Ravi.
Past
Active:  Ravi wrote a letter.
Passive: A letter was written by Ravi.
Future
Active:  Ravi will write a letter.
Passive: A letter will be written by Ravi.
```

### 2. Pronoun Changes

When the original subject moves after by, its pronoun usually changes from the subject form to the object form.

| Active Subject | After "by" |
| -------------- | ---------- |
| I              | me         |
| we             | us         |
| you            | you        |
| he             | him        |
| she            | her        |
| they           | them       |
| it             | it         |

```
Active:  I wrote the letter.
Passive: The letter was written by me.
Active:  She cleaned the room.
Passive: The room was cleaned by her.
Active:  They built the house.
Passive: The house was built by them.
```

### 3. What happens to the Object?

The active object's position changes. Active Object becomes Passive Subject

```
Active:  Rahul kicked the ball.
Passive: The ball was kicked by Rahul.

So, Active Object -> Passive Subject
```


### 4. What happens to the Subject?

The active subject generally moves after by.

```
Active:  Rahul kicked the ball.
Passive: The ball was kicked by Rahul.

So, Active Subject -> by + agent
```

> **The person/thing performing the action in the passive sentence is called the agent.**

### 5. What happens to the Verb?

The main verb changes to V3. <br/>
The helping verb changes according to the tense and subject.

| Active Verb | Passive Verb |
| ----------- | ------------ |
| writes      | is written   |
| wrote       | was written  |
| eats        | is eaten     |
| ate         | was eaten    |
| makes       | is made      |
| made        | was made     |
| takes       | is taken     |
| took        | was taken    |
| breaks      | is broken    |
| broke       | was broken   |

### 6. `by` + Subject(Agent) is not always necessary

Sometimes the agent is unknown, obvious, or unimportant.

```
Active:  Someone stole my phone.
Passive: My phone was stolen.
We don't need: My phone was stolen by someone.
```

> Note: **by + agent is optional when the agent isn't important or is obvious/unknown.**

**Mistake 1 - Forgetting V3**
```
The letter was write by Ravi.      write(v1)

```
They are repairing the car.

The car is being repaired by them.    be (being)
```

**Mistake 4 - Changing the preposition**
```
They laughed at him.
He was laughed by them.        missing preposition 
He was laughed at by them.     preposition
```

**Mistake 5 - Trying to passivize an intransitive verb**
```
He slept.
A sleep was slept by him.               Incorrect
No normal passive construction exists.
