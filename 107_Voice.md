# Voice


## Level 1 - Foundation

<details>
  <summary> <b> What is Voice? </b> </summary>

<br/>

> Voice tells us **whether the subject performs an action or receives an action**.


The term `voice` is a term that is used to denote the `form of the verb` **which shows if the subject in a given 
sentence is the doer or receiver of the action**. 

The voice of a verb describes the **relationship between the action and the participants (subject or object) in a 
sentence**.

</details>
<!------------------------------>


<details>
  <summary> <b> Types of voice </b> </summary>

<br/>

In English, the two primary voices are `active voice`, where the subject is the agent and `passive voice`, 
where the subject is the patient.

Examples:
```
Ravi writes a letter.
- Here, Ravi performs the action.
- So, it is Active Voice.

A letter is written by Ravi.
- Here, the letter receives the action.
- So, it is Passive Voice.
```

While most languages focus on these two, some grammatical frameworks also recognize a **`middle voice`,
where the subject is affected by the action or performs it for themselves**.

Examples
```
1. Active Voice:  The cat chased the mouse.
2. Passive Voice: The mouse was chased by the cat.
3. Middle Voice:  The book sells well.
```

| Voice in English Grammar                                                                             |
|------------------------------------------------------------------------------------------------------|
| **Active Voice**: `Subject + Verb + Object`; emphasizes the doer.                                    |
| **Passive Voice**: `Object + "to be" + Past Participle (+ by Agent)`; emphasizes the receiver.       |
| **Middle Voice**: Subject is both agent and patient, or the action reflects on the subject's state.  | 


#### The choice of voice impacts clarity and emphasis: 

`active voice` is generally preferred for directness and clarity, while <br/>
`passive voice` is useful when the actor is unknown, irrelevant, or when emphasizing the result of the action. 


</details>
<!------------------------------>


<details>
  <summary> <b> 1. Active Voice </b> </summary>

<br/>

> The active voice, in a sentence, denotes that the noun/pronoun that acts as the subject in the sentence is the
doer of the action. 

In other words, the **subject performs the action or acts upon the verb**.


> Basic structure: **`Subject + Verb + Object`**

Examples:
```
1. Riya reads a book.
Subject = Riya
Verb    = reads
Object  = a book
Riya(Subject) -> performs the action (reads).
Therefore, Active Voice.

2. The boy kicked the ball.
3. She cooked dinner.
4. Rahul opened the door.
5. The teacher teaches English.
6. They built a house.
- In every sentence, the subject is doing the action.
```

</details>
<!----------------------------->

<details>
  <summary> <b> 2. Passive Voice </b> </summary>

<br/>

The passive voice, on the other hand, represents that the subject is one acted upon by the action/verb in 
the sentence. 

It can also be said that the passive voice indicates that **the subject in the sentence is no longer active
but passive**.

In Passive Voice, the **subject receives the action**

> Basic structure: **`Object + helping verb + V3 + by + Subject`**

Examples:
```
Active:  Ram reads a book.
- Ram -> reads -> a book
Passive: A book is read by Ram.
- A book -> is read -> by Ram

```
**The object of the active sentence becomes the subject of the passive sentence.**

<details>
  <summary> <b> Transitive vs Intransitive verbs </b> </summary>

#### Transitive Verb

A transitive verb takes an object.
```
Ram opened the door.
Ask: Ram opened what?
Answer: the door.
Therefore, opened is transitive.
```
A normal passive construction is possible:
```
The door was opened by Ravi.
```

#### Intransitive Verb

An intransitive verb does not take an object.
```
The baby slept.
Ask: The baby slept what?
Answer: There is no object.
Therefore, there is normally no passive voice.
```

Examples:
```
He sleeps.
She laughed.
The baby cried.
They arrived.
The sun rose.
The children played.
```

It is not necessary that every active sentence can be converted into passive.
> **No object -> normally no passive voice.**

</details>

<details>
  <summary> <b> Pronoun changes </b> </summary>

<br/>

When we add `by`, the subject changes to its **object form**.

| Active Subject | Passive form |
| -------------- | ------------ |
| `I`            | `me`         |
| `We`           | `us`         |
| `You`          | `you`        |
| `He`           | `him`        |
| `She`          | `her`        |
| `They`         | `them`       |
| `It`           | `it`         |
| `Who`          | `whom`       |

Example:
```
She writes a letter.
      |
A letter is written by she.    Incorrect
      |
A letter is written by her.    Correct
```

```
ACTIVE:
I cleaned the room.
You should follow the rules.
He has completed the work.
She writes a poem.
They will build a house.
They are repairing the car.

PASSIVE:
The room was cleaned by me.
The rules should be followed by you.
The work has been completed by him.
A poem is written by her.
A house will be built by them.
The car is being repaired by them.
```

<details>
  <summary> <b> Basic conversion </b> </summary>

#### How to change Active into Passive? 

**Active `Subject + Verb + Object`** <br/>
**Passive `Object + Helping Verb + V3 + by + Subject`**

Example:
```
The cat catches the mouse.
Subject = The cat
Verb = catches
Object = the mouse

The mouse is caught by the cat.
```

`Ravi writes a letter.`

> **Step 1 - Find the Subject**

Subject = Ravi

> **Step 2 - Find the Object**

Object = a letter

> **Step 3 - Bring the Object to the beginning**

New Subject (was object)  = A letter ...

> **Step 4 - Choose the correct helping verb**

 Add helping verb = A letter is ...

> **Step 5 - Change the main verb to V3 and add `by`**

Add main verb (v3) + `by` + Object (was subject) = A letter is written by Ravi.

`A letter is written by Ravi.`

</details>
<!-------------Basic conversion----------------->


<details>
  <summary> <b> Why and when passive voice is preferred? </b> </summary>

<br/>

Passive voice isn't simply a "conversion exercise." It has a purpose.

We often use passive when:
1. **If the action is more important than the person**
```
The road was repaired yesterday.
```

2. **If the person is unknown**
```
My phone was stolen.
His car was broken.
```

3. **If the person is obvious**
```
The suspect was arrested.
The theif was caught by police.
```

4. **If we want a formal/scientific style**
```
The samples were tested in the laboratory.
```

</details>
<!------------------------------->


<details>
  <summary> <b> Sometime <code> by </code> is not necessary in passive voice </b> </summary>

<br/>

Sometimes we don't need to mention who performed the action.

Active: `Someone stole my bicycle.` <br/>
Passive: `My bicycle was stolen.` <br/>
Here, We don't know or don't care who stole it.

Active: `People speak English all over the world.` <br/>
Passive: `English is spoken all over the world.` <br/>
We don't need `English is spoken by people all over the world.`


```
Active:  Someone broke the window.
Passive: The window was broken.
We don't need: The window was broken by someone.

Active:  People speak English here.
Passive: English is spoken here.
```
The agent is either unknown, obvious, or unimportant.

</details>
<!-------------Passive without by---------------->

<details>
  <summary> <b> Not every sentence can become Passive </b> </summary>

<br/>

A sentence generally needs an object to form a normal passive construction.

```
Active:  Rahul kicked the ball.
         Object = the ball
         So, Passive is possible
Passive: The ball was kicked by Rahul.

But:     Rahul sleeps.
         Object = ? There is no object.
         So we don't normally make a passive sentence from it.
```


</details>

## Level 4 - Special Structures



<details>
  <summary> <b> Modal verbs </b> </summary>

<br/>

Modal verbs include: **`can, could, may, might, must, shall, should, will, would, etc`**.

Passive: **`Object + modal + be + V3 + by + Subject`**

Examples:
```
Active:  She can solve the problem.
Passive: The problem can be solved by her.

Active:  You should follow the rules.
Passive: The rules should be followed by you.

Active:  We must obey the law.
Passive: The law must be obeyed by us.

Active:  They might cancel the match.
Passive: The match might be cancelled by them.
```

<details>
  <summary> <b> Verb + Preposition + Object </b> </summary>

<br/>

Some verbs are followed by prepositions.

Examples: `look at, laugh at, speak to, talk about, look after, listen to, rely on, believe in`

The **preposition can remain with the verb in the passive construction.**

```
Active:  Everyone laughed at him.
Passive: He was laughed at by everyone.

Active:  They looked after the child.
Passive: The child was looked after by them.

Active:  We should listen to the teacher.
Passive: The teacher should be listened to by us.
```

Verb + Preposition -> keep the preposition in the passive construction. <br/>
This is sometimes called a **prepositional passive**.

<details>
  <summary> <b> Di-transitive verbs </b> </summary>

<br/>

A di-transitive verb can take two objects:
1. Direct object
2. Indirect object

Common verbs: `give, send, offer, tell, teach, show, lend, buy, bring, etc`

```
Ram gave me a book.
- me = indirect object
- a book = direct object
```
There are two possible passive constructions.
```
   Active: Ram gave me a book.
Passive 1: I was given a book by Ram.
Passive 2: A book was given to me by Ravi.

   Active: She sent me a letter.
Passive 1: I was sent a letter by her.
Passive 2: A letter was sent to me by her.

   Active: The teacher taught us English.
Passive 1: We were taught English by the teacher.
Passive 2: English was taught to us by the teacher.
```

**Two Objects + Passive** <br/>
Let's go deeper into ditransitive verbs.

```
Active: The manager offered Rahul a job.
- Rahul -> indirect object
- a job -> direct object
Passive 1: Rahul was offered a job by the manager.
Passive 2: A job was offered to Rahul by the manager.
```
Active: `Subject + Verb + Indirect Object + Direct Object`
```
The manager offered Rahul a job.
```
Passive 1: `Indirect Object + Verb + by + Direct Object + by + Subject`
```
Rahul was offered a job by the manager.
```
Passive 2: `Direct Object + Verb + to + Indirect Object + by + Subject`
```
A job was offered to Rahul by the manager.
```

<details>
  <summary> <b> "To be" constructions </b> </summary>

<br/>

Forms of to `be` include: `is, am, are, was, were, be, being, been`

`be` can function as a main verb as well as a helping verb. So, It becomes complicated while looking at it for 
making passive.

Examples:
```
She is a teacher.
- Here, is = main/linking verb.
- There is no object receiving an action.
- So, There is no passive transformation here.
```

But `be` can also appear in passive constructions.
```
The door is opened by Ravi.
- Here: is = helping verb
- opened = V3/main verb
```

`is + noun/adjective` -> often linking verb <br/>
`is + V3` -> can form passive

## Summary

<details>
  <summary> <b> How to identify Active/Passive statements </b> </summary>

<br/>

To identify Active/Passice statement ask **Who is doing the action?**
- If the **subject is doing the action**: **`Active Voice`**
- If the **subject is receiving the action**: **`Passive Voice`**

Example:
```
The dog chased the cat.
- Who did the action? -> The dog -> Active

The cat was chased by the dog.
- Who receives the action? -> The cat -> Passive
```

Exercise:
```
Ravi plays cricket.                   - Active
My bicycle was stolen.                - Passive
The letter was written by Priya.      - Passive
The teacher teaches English.          - Active
The food was prepared by Mother.      - Passive
They built a bridge.                  - Active
The bridge was built by them.         - Passive
Someone stole my bicycle.             - Active
English is spoken all over the world. - Passive
```

</details>
<!----------Identification Active/Passive-------------------->



<details>
  <summary> <b> Golden Formula </b> </summary>

<br/>

```
 ACTIVE : Subject + Verb + Object
                     ↓ 
PASSIVE : Object + Helping Verb + V3 + by + Subject
```

`The boy opens the door.`
1. Subject? -> The boy
2. Verb? -> opens
3. Object? -> the door
4. Bring object forward -> The door...
5. Helping verb? -> is
6. V3? -> opened
7. Add by + subject -> by the boy

`The door is opened by the boy.`

<details>
  <summary> <b> Common mistakes </b> </summary>

<br/>

**Mistake 1 - Forgetting V3**
```
The letter was write by Ravi.      write(v1)
The letter was written by Ravi.    written(v3)
```

**Mistake 2 - Wrong helping verb**
```
The books is written by her.      is(helping verb)
The books are written by her.     are(helping verb)
```

**Mistake 3 - Forgetting "being"**
```
They are repairing the car.
The car is repaired by them.          be (being is missing)
The car is being repaired by them.    be (being)
```

**Mistake 4 - Changing the preposition**
```
They laughed at him.
He was laughed by them.        missing preposition 
He was laughed at by them.     preposition
```

**Mistake 5 - Trying to passivize an intransitive verb**
```
He slept.
A sleep was slept by him.               Incorrect
No normal passive construction exists.
```
